# Mailbox Lined Paper Options

## Shared Constraints

Use case: stylized-concept
Asset type: square game UI mailbox reading-panel background texture
Primary request: a plain, understated horizontal-lined letter-paper background
Composition/framing: exact front-facing orthographic view; the paper surface fills the complete 1:1 canvas edge to edge; straight evenly spaced horizontal rules continue fully across the image; crop-safe for CSS `background-size: cover`; no focal point
Lighting/mood: flat, soft, quiet, highly readable; no directional lighting
Text: none
Constraints: subtle low-contrast paper fibers; dark interface text must stay readable; no visible sheet boundary; no perspective; no objects; no decorative motifs
Avoid: borders, frames, corner decorations, paper scraps, tape, pins, clips, flowers, leaves, envelopes, stamps, notebook holes, torn or deckled edges, folded corners, shadows, layered sheets, stains, splashes, vignettes, gradients, handwriting, printed text, logos, watermarks

## Option 1 — Classic Blue Rules

Scene/backdrop: warm ivory writing paper filling the entire canvas
Style/medium: gently hand-painted 2D paper texture with very subtle natural fibers
Color palette: warm ivory `#fff8e8`; pale desaturated blue rules `#bdd3db`; one extremely faint muted-red vertical margin line `#d8a1a1`
Materials/textures: clean matte stationery paper; barely visible fiber variation; no aging marks
Rule layout: horizontal rules spaced approximately 64–72 pixels apart at a 1254-pixel reference size; one thin vertical margin line about 13% from the left edge

Rule layout: horizontal rules spaced approximately 64–72 pixels apart at a 1254-pixel reference size; no vertical margin line
