# 霞鹜字体字号可读性审查

日期：2026-10-21。基于 `891600da` 后的当前工作区，包含既有未提交的资料窗口改动。本轮完成审查与建议，未修改产品代码、字号或布局。

结论：确实还有应该放大的文字。最严重的是商店整卡缩放，其次是手机对弈操作与身份信息。上轮改动改善了长正文的字重和间距，但没有覆盖许多小标签、按钮和辅助说明；不能据此认为全站文字已经适配霞鹜。

## 覆盖和方法

- 静态扫描 `src/styles` 下全部 749 个 CSS 文件：有 409 处固定 `px/rem` 声明低于 14px，分布于 195 个文件。这个数字仅用于排查入口，包含被覆盖、未启用和例外区域，不能直接当成 409 个可见问题。
- 使用真实生产组件和完整主题，以模拟 API 数据渲染。检查玩家端 36 类页面/状态和 21 个后台页，保存了 97 组去重后的有效字号快照；另检查了 320px 的对弈、注册、战绩和回放界面截图。
- 主视口为桌面 1440×1000、手机 390×844，重点补查 320×844。后台只检查桌面。
- 数据包含计算字号、字重、行高、字距和祖先 `transform/zoom`。下文“实际字号”是名义字号乘以累计缩放的近似值，浏览器缩放为 100%；不是字形墨迹高度或物理毫米数。
- 覆盖登录/注册、加载、大厅、匹配/选人/陪练、主要窗口、角色详情、普通对弈/结果、剧情，以及有数据的排行榜、好友、邮件、公告、回放和商店。
- 现有 WuWa（包括棋钟数字）和整个 IRIS 入口/窗口按用户要求排除。已停用的成就/个性化玩家窗口不作为现行界面整改对象。特殊黑化剧情、所有后台编辑子状态和所有浏览器/DPI 组合未逐一重放，相关 CSS 扫描不等于实测通过。

## 建议的字号分层

1. 连续阅读的说明：**16px**，正文常规字重，保留 1.65 行高和轻微字距。
2. 功能标签、用户名和普通按钮：**14–16px**。
3. 辅助状态、日期、表头：**13–14px**。
4. 空间严格受限的对弈辅助标签：**12px 左右**，同时去掉过强合成粗体；更小字号不用于需要阅读的中文说明。

这是本项目的调整建议，不是对任何字体都适用的绝对标准。字号验收必须看最终屏幕效果，并计入容器缩放。标题、主操作、已清楚的大号数值和正文不需要再整体放大。页脚版权等非操作信息可维持较低优先级。WuWa 与 IRIS 继续保留。
