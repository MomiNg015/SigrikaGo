# 标准立绘交互样板

新增[完善版剧情引导样板](./guide.html)，专门审阅当前引导的正式构图：11 个情境使用现有台词、选项和表情，包括独立剧情、三项分支、长规则对白、两角色接话、棋盘讲解／问答／答错反馈、指定落子、无立绘纯选项、技能前后与首页入口指引。桌面、390 竖屏、360 竖屏均可切换。

对弈对白把透明立绘与聊天纸张放为兄弟元素，人物盖住左边框并超过框顶；正文和姓名避开人物。手机让棋盘、对白、操作区分段占位，人物向上出框的空间来自棋盘下方留白。落子／技能节点收起对白并放大棋盘，不能用继续按钮绕过指定操作。独立剧情沿用教室背景与左人物、右下对白的原样板构图；手机叠放在人物下方，长文正文独立滚动，选项固定可见。

`sync-guide.mjs` 从默认发布快照及现有作者表情配置导出 `guide-data.js`；只插值样板用户名，不改写台词。重点局面由 `createTutorialGameState`、`applyTutorialNodeAction`、`applyTutorialSkillAction` 在导出时纯内存生成，含提子、劫点、技能抹除点与反色结果。样板默认关闭自动推进以便观察，可开启原节点自动推进；选项沿用原 reveal/transition delay。长对白的 `...` 选项在 2 秒后可用，不等全文打字完成。

此页是离线构图审阅，不执行真实对局、奖励、账号或后台写入。技能横幅与少量窗口仅作演示；不替代完整教学引擎。爱弥斯素材已准备，但现有引导没有她的台词，此样板不增加出场。更新源数据后执行 `node docs/prototypes/character-sprites/sync-guide.mjs`。

入口：`docs/prototypes/character-sprites/index.html`。在项目根启动静态服务：

```powershell
py -3 -m http.server 8769 --bind 127.0.0.1
```

打开 http://127.0.0.1:8769/docs/prototypes/character-sprites/index.html 。

- 七场景：部员手册、首页学生证、履历，以及剧情舞台、对局与技能、队际头像、结算。链接可用 `#handbook`、`#student`、`#resume` 直接打开对应场景。
- 支持西格莉卡九张图（八种差分加原图）、半身／膝上／全身对比、桌面／手机竖屏、长对白、技能、试下与胜负切换。
- 手册提供三名角色的九种表情、全身查看、Esc／按钮关闭及本地出战切换。列表采用横版学生证，左侧胸口以上近景、右侧单行角色名与独立旗子图标，不重复显示学院文字。桌面卡片 1.85:1、按可用宽度两至三列；竖屏卡片 1.65:1、固定一排两张。其余六名角色使用当前 Q 版图作对照，详情仅实现三名有新立绘的角色。
- 证件底图由内置 imagegen 生成，手绘笔触参考现有 `student-id-hanging.png` 与 `student-id-nameplate.png`，左右布局参考用户提供的学院学生证。浅底、少量科技线条与星标，名字使用深色；西格莉卡暖橙、达妮娅淡紫、爱弥斯浅青。背景色相滤镜仅作用于底图，原角色 PNG 和文字不受影响。来源与完整提示词见 [底图说明](./assets/cards/README.md)。
- 首页学生证沿用现有挂卡及照片框比例，点击打开履历；履历身份头像为桌面 164×152px、手机 108×96px，角色切换、模式切换与空状态均为本地演示，头像固定微笑。
- 来源 `amis` 目录映射为项目 `aemeath`。27 张 PNG 原样复制到本样板 assets，合计 34,061,305 bytes；复制后 SHA-256 核对一致。没有修改图像或生成正式头像派生图，当前构图通过 CSS 完成。
- `catalog-data.js` 只提取正式默认快照 `server/adminDefaultSnapshot.js` 中的九名角色必要展示字段，包含三名角色的真实介绍、CV、获得途径和技能描述；不访问数据库，不加载整个后台配置或剧情。账号与战绩为示例数据。
- 字体与教室背景引用仓库已有 public 资源，需保留项目相对目录结构。页面不调用真实 API、不修改账号或游戏数据。

样板确定裁切后，再将用途配置与轻量派生图接入正式资源集合。

证件卡的详情按钮和出战按钮是兄弟节点，不嵌套按钮。旗子为透明底纯图标：描边为可出战，实心为已出战；屏幕阅读器名称和鼠标提示保留出战含义。桌面点按区域 48×48px，手机 44×44px，图标分别为 36／28px。列表出战通过 `data-value` 指定角色，留在列表、保持原滚动位置，已出战按钮禁用。所有状态仅保存在当前样板页面。

卡片近景仅改 CSS，不裁改源 PNG：桌面西格莉卡／达妮娅／爱弥斯图像宽度为照片框的 240%／238%／280%，手机为 270%／270%／312%；沿用原角色横向锚点，保证不同卡片比例显示相近的胸像范围。

横版卡另验证 320×800、360×800、390×844、900×900、1440×960：浅色主题、图片加载、姓名／旗子间距、桌面两至三列／手机两列布局均通过，卡片行不压缩、无横向滚动。320px 姓名保持完整，旗子触区不遮头像；保留原角色图透明度，未更改正式资源。

已在浏览器检查 1400×920 桌面、900×900 中等窗口、390×844 和 360×800 手机竖屏：九种表情加载、剧情推进及返回、三种构图、长对白滚动、落子禁用、技能横幅、角色切换和胜负切换通过；页面与场景均无横向溢出，控制台无错误。窄屏棋钟与技能按钮分别保留空间。三个脚本的 `node --check` 通过。

新增三场景另在 1440×960、900×900、390×844、360×800 检查：三角色表情切换、头像与完整立绘、详情滚动、Esc 返回、学生证进入履历、模式／空状态及原技能还原流程通过。窄屏自动采用竖屏，桌面按钮禁用；宽窗口仍可主动查看手机构图。浏览器图片需要加载和绘制完成后再评审截图。
