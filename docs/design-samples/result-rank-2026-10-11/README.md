# 星级与段位变化 · 三套视觉样板

Vite 访问 `/docs/design-samples/result-rank-2026-10-11/index.html`。切换三种方向、得星／失星／升段／降段、桌面／手机竖屏；“重播变化”可重新观察一次性动画。

| 方向 | 表达 | 取舍 |
| --- | --- | --- |
| 星轨点亮 | 新星带小加号和虚线环，失星空位带减号；升降段由旧段位指向强调的新段位 | 最紧凑，变化集中在已有星槽 |
| 段位徽章 | 圆形纸质徽章、挂角星标或双箭头，配当前星槽 | 更有奖励感，竖屏占用略高 |
| 前后对照 | 星槽上下对照，段位左右对照，以小标签区分前后 | 信息最明确，但多一行参照 |

使用生产 ResultModal、ResultCharacterPortrait 和完整主题，仅在样板内隐藏原段位内容并 portal 替换。固定示例沿现有四星／六星容量；奖励解析不变，生产界面现已采用方案 1。新增／失去的星同时有形态和加减号区分，升降段有方向箭头和前后数字，不只依赖颜色。动画一次播放，减少动态效果下静态呈现。

验证命令：`node docs/design-samples/result-rank-2026-10-11/verify.mjs`。显式套用项目 ESLint；检查三方向 × 四状态 × 四视口，含 1440×900、390×844、360×640、320×568；检查段位元素不侵入金币列、面板边界、隐藏旧文字、控制切换、重播、本地双按钮、减少动态效果。结果见 verification.json，desktop/mobile PNG 为真实主题截图。

设计钩子中的金色／蓝灰色与纸色均为独立样板的语义色探索，5px 圆角是小型纸质标记的局部几何，仅用于结果段位标记。真实圆形徽章被旧 span 重置覆盖的问题已通过降低样板重置选择器优先级修复；未新增检测忽略配置。

已选定方案 1 并接入生产 `ResultRankProgress`，使用有作用域的金色／蓝灰色标记。生产验证见邻接 result-window 目录的 verify-production.mjs，另两套保留为设计参考。

生产接入验证：121 项定向测试、40 组真实组件浏览器状态（含 320px 手机、八星、无变化、双按钮和减少动态效果）、显式 ESLint、构建及构建 CSS 检查通过。全仓 CSS 清单保留已有两项失败：字节预算超出 822，以及 match-mode-title-layout.css 的 360px 查询未登记；本次仅登记自身增量。
