# 观战窗口三版设计

[打开比较页](./index.html)。三版均移除左侧类型选项卡，将类型放入每行的独立列；保留原标签图片标题、窗口边框、方格纸背景、阴影和项目配色。

## 现状审查

- `src/modals/WatchModal.jsx` 按类型切换请求，用户比较不同类型的对局需要反复切换；当前表格本身没有类型列。
- 当前列表的每一行都是粗描边圆角容器，房间号、人数和玩家信息的权重接近。整行可点击，但没有明确的观战入口。
- 窗口内容少时留下较大空区；数量增加时应把滚动限制在列表内，保持标题、搜索和刷新位置稳定。
- 玩家身份应继续复用 `UserIdentity` 和角色资源解析，保留头像、黑白方及暂离状态。`onlineCount` 是房间人数，不能改标成观众人数。

## 三个方向

| 版本 | 设计 | 取舍 |
| --- | --- | --- |
| 1 赛事名册 | 连续横线表格、黑白方分列、类型文字下划线 | 同屏信息最多，适合快速找房间 |
| 2 对阵看板 | 放大双方角色、中央 VS、类型纸签、薄荷绿观战按钮 | 游戏感更强，单行占用较多高度 |
| 3 观战票根 | 方形纸票、虚线分隔票根、上下排列玩家 | 更有校园物件感，视觉分组最明确 |

桌面统一 700px 高，竖屏以 740px 为上限，均受标签标题安全可用高度约束；内部列表滚动。手机重新排布行内容，保留类型字段，避免横向滚动。

## 样板范围

`preview.html?view=ledger` 使用已选定的正式 `WatchModal` 与拦截的样板响应；原始截图 `current-*.png` 保留作为对照。`ledger`、`duel`、`ticket` 为三个提案，支持搜索房间／玩家、刷新、选择、关闭及重开。正式名册中的观战按钮执行关闭窗口的真实回调，但样板拦截加入，不连接真实对局；另两版仍为本地选择。数据包含四种模式、进行中／结束及暂离；添加 `&long`、`&many`、`&empty` 可查看边界状态。

用户已选第 1 版并要求手机更紧凑。正式版手机使用三行结构，并排展示双方，单行从约 181px 缩至 116px。新增 `mode=all` 查询，仅此显式值返回所有合资格房间，省略或无效参数保留原默认模式规则；练习／剧情局排除逻辑不变。

## 验证

运行 `node docs/design-samples/watch-2026-10-12/verify.mjs`：覆盖三版 × 1440／390／360／320px × 正常／长昵称四位手数／30 条／空状态，共 48 组；检查无横向溢出、数值完整、固定高度、四种类型、图片解码、末行可达、搜索、刷新、选择、键盘及关闭重开。桌面与 390px 截图保存在本目录。

设计扫描复核：角色图片的属性展开由正式 `characterPortraitImageProps` 提供资源地址，浏览器检查实际解码；票根左侧色条已移除；类型和状态下划线属于无圆角文本，未应用于圆角卡片，相关圆角边线提示不适用。

正式接入验证：观战、接口与房间查询相关 26 项测试通过，包含搜索、失败重试、全部类型和加入关闭。浏览器继续覆盖三版 48 组；正式手机行高不超过 116px。全局 CSS 清单保留既有 889 字节超额及 match-mode-title-layout.css 的 360px 未登记断点，本次只登记自己的 CSS 增量。
