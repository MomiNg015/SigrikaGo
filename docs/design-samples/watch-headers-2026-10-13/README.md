# Desktop watch column headers

Three isolated treatments rendered on the production WatchModal with local fixtures: marker strokes, torn paper tape, and a mint club score sheet. Preserve the window artwork, palette, population column order, move placards and native whole-row entry. Only desktop column headers change. No production CSS or account APIs are modified. Open index.html to switch variants; preview.html?style=marker|tape|scoresheet opens each directly. On narrow devices the comparison retains a desktop canvas for deliberate horizontal inspection.

Validation: three styles at 1440/1160/390px, local search, close/reopen via row entry, picker switching, image decoding, no live API requests, and scoped ESLint passed. Desktop screenshots and header crops are included.
