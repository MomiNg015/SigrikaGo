# 准时宝难度窗口样板

设计已获确认并接入正式 `PracticeDifficultyDialog`；本页保留为独立交互样板，通过 Vite 打开 `index.html`。

- 右上关闭按钮替代底部返回，出战框在关闭按钮左侧。
- 移除顶部说明；保留三档难度和独立开始按钮。
- 底部对白使用用户指定原文，西格莉卡默认 Q 版原图由共享解析器取得，仅在预览容器中裁为胸像。
- 胸像裁切框延伸至窗口外边缘，两者 bottom 坐标差为 0，避免 padding 或边框留下底部缝隙。
- 窗口底边及底部圆角在胸像上方重绘，确保完整边框线不被立绘覆盖；重绘层不拦截点击。
- 复用正式角色选择组件，但选角及开始只更新页面局部状态，不创建对局、不写缓存。

## 验证

1440×1000、390×844、360×640、320×640：窗口与开始按钮完整可见，无横向溢出，胸像与窗口底边误差 0px。截图为本目录 `preview-*.png`。

检查难度切换、选角后窗口保持打开、关闭选角回到难度页、指定角色与难度的本地开始确认、关闭／重新打开、Escape。正式接入后另用真实 HomeScreen 检查相同布局及开局参数，截图为 `production-*.png`。

样式 hook 的 side-tab 提示针对聊天框尾巴的旋转边线；这是对白箭头而非卡片侧边装饰，属于误报，未添加忽略配置。
