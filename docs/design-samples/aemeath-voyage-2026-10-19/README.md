# 远航星：巨型光剑与地裂样板

这是爱弥斯「远航星」的独立演出研究页。采用**抽象巨型光剑**：青色、紫色光刃围住窄亮芯，上端伸出画外；没有自创机械护手、装甲或刻纹。机甲不出镜，重量通过落剑加速度、触地停顿、棋盘震动和地块受力来表现。

- 开发服务器运行时打开：[交互样板](http://127.0.0.1:5173/docs/design-samples/aemeath-voyage-2026-10-19/index.html)。服务器未运行时，在项目根目录执行 `npm run dev:client`，使用终端输出的地址加上本页路径。
- [带原横幅、变身、语音与 BGM 的视频](./preview.mp4)，1280×720、25 fps、约 8 秒。
- [桌面截图](./preview-desktop.png)、[手机竖屏截图](./preview-mobile.png)。

## 当前演出为什么显得轻

审查范围是 `src/room/boardSkillEffectRegistry.js` 的 `playVoyageStar`、`drawVoyageStarEarthquake`、`drawVoyageStarSword`：

1. 剑主要由白色多边形和矩形构成，没有足够的明暗层次；提升亮度本身不能补足体量。
2. 震动主要作用在 `quakeLayer` 特效容器，底下真实棋盘没有一起受力，剑和地面的关联偏弱。
3. 地震主要是椭圆波纹和小圆尘粒，缺少裂缝、被掀起的整块地面和带重力轨迹的碎石。
4. 触地后遮罩很快放大，击中瞬间和地面形变没有充分停留。

因此样板优先补地面反应与节奏，而不是堆更多亮圈。

## 参考与取舍

官方来源：[鸣潮 Bilibili 战斗演示](https://www.bilibili.com/video/BV1qZ6yBXEVv)、[Wuthering Waves YouTube — Aemeath Combat Showcase](https://www.youtube.com/watch?v=psq5Izh9GHM)。核对了官方页面及公开分镜预览帧，用于巨型尺度、冷色能量和瞬间强反差的方向研究；没有完成原片逐帧动作还原，也没有把参考片段打包进样板。

用户明确要求「要么几乎一致，要么抽象光剑」。本轮选择后者，已弃用中途生成的机械剑素材。当前图形全部由 Canvas 绘制；不是隧者重剑模型的近似替代。

## 默认节拍

| 时间 | 画面与声音 |
| --- | --- |
| 0–3.20 s | 真实 `SkillBanner`，包含原立绘、故障变身及技能名；同时启动技能 BGM 与施法语音 |
| 3.20–3.40 s | 棋盘显露、落点蓄光、轻微推近 |
| 3.40–3.82 s | 巨型光剑加速下坠 |
| 3.82 s | 剑尖触地；冲击低频和破裂声同时开始 |
| 3.82–3.905 s | 约 85 ms 触地停顿；短闪光 |
| 3.905–4.62 s | 棋盘震动、裂缝扩展、整块地面抬升，碎石先后喷出 |
| 后续至 8.02 s | 尘浪、火星与余震衰减，棋盘恢复 |

3.82 s 是根据现有音频振幅变化选出的首轮试听值，不是已经确认的最终音乐拍点。可用「提前／延后 0.05 s」调整触地，或改变音乐起播位置；关闭冲击音效可单独听原曲。三种演出预设共享音乐与横幅：重剑撼地、星辉爆裂、对局收敛。

## 复用与播放边界

- 横幅直接使用项目 `SkillBanner` 和 `AEMEATH_BANNER_DURATION_MS`，完整播放固定原速。慢放、暂停和拖动时间轴用于 3.2 s 之后的棋盘段，避免破坏原横幅的计时器与换立绘时刻。
- BGM 由 `MUSIC_TRACKS['aemeath-voyage-star-default']` 解析，即 `lhl_intro_once.ogg` 接 `lhl_loop.ogg`。语音由 `resolveSystemVoice(skillCast, voyage-star)` 解析。样板静音横幅内部声道，防止同一句语音叠播。
- 浏览器 `AudioContext` 作为音画共享时钟；所有源按同一原点调度。停止、重播、切走页面及卸载会停止旧音源；异步解码以代次校验防止过期请求重新开播。音频只在用户点击后创建。
- 冲击声是样板内合成的低频与噪声，独立开关，非原作音效。慢放会同时降低音乐速度和音高，供动作定位；判断最终音乐卡点请用完整播放。
- 固定种子保证任意时刻重绘一致。粒子数量固定，DPR 上限 1.65，尘雾使用一次生成的离屏纹理。
- 减少动态效果时取消镜头抖动、推近、闪光与飞散粒子，剑改为渐显，保留轻量地裂示意；支持系统偏好与手动开关。
- 视频使用同一浏览器播放与音频总线录制，按音频开始标记对齐，25 fps 的视频对齐精度受约 40 ms 帧长限制。精细卡点以交互页为准。

## 接入正式对局前

本轮没有替换正式 Pixi 特效、改棋子数据或改变服务端结算。当前正式约束仍是：横幅 3200 ms、棋盘特效 1800 ms、权威结算 4136 ms（横幅后 936 ms）。样板刻意留了更长的碎裂观察时间，不能把约 8 秒的总时长直接拷进正式演出。

后续接入需要把同一套动作压缩到正式生命周期，或成套调整服务端、教程、回放时序；同时处理消失棋子的视觉遮挡、边缘落点和真实棋盘的容器震动。Canvas 投影棋盘用于演示受力，并非当前游戏棋盘组件。
