# 校园物件 · 游戏界面交互样板

通过 Vite 打开 `/docs/design-samples/game-feel-2026-10-11/`。顶部可切换设置、仓库、好友，以及 390px 手机预览。重置按钮恢复当前样板初始状态。

用户要求：减少重复的圆角矩形，但必须保留游戏感，不能变成纯数据交互。三套样板因此采用同一校园纸张基底、三种物件组织方式：

- **社团音响台**：爱弥斯与项目现有手绘播放器，四条竖向拨杆、按压静音键。试听真实本地提示音，受主音量与提示声音量共同控制；背景音乐和语音仅示意调节状态。
- **随身道具箱**：道具直接放在托盘内，选中时抬起并显露纸签。支持分类、道具说明、选择糖果接收角色、数量减少、取消和库存耗尽。
- **部员联络册**：左侧通讯目录与右侧角色纸页；手机改为横向头像翻选。支持搜索、空结果、状态筛选、资料翻看、离线禁用及约局／观战入口反馈。

## 范围

所有人物昵称、数量及交互结果均为本地演示数据。约局、观战、资料、招募和道具使用不调用 API，不修改账号，不创建真实房间；正式接入时需复用现有业务组件与权限。切换样板会重置该样板的演示状态。只展示声音设置，尚未覆盖界面／关于、完整库存业务及黑名单管理。

组件与 CSS 完全独立；生产页面不导入样板。角色图通过 `characterChibiSource` 使用当前资源；物品图、教室背景、播放器和标题字体均来自 `public/assets`。音频仅在用户点击后播放，切换窗口或样板时停止。

## 设计检查

沿用项目的纸白、墨色、粉色、蓝色、薄荷色和 LXGW Marker Gothic 标题字体。设计钩子对字体别名的提示已通过改回 `Sigrika Window Title` 解决；主操作粉色和拨杆颜色也已对齐现有配色。纸张、托盘、音响面板、墨线和阴影的局部材质色阶属于此隔离样板的有意探索，判为上下文误报；不修改全局 DESIGN.md、不添加忽略规则。普通正文使用系统中文 UI 字体。

此轮改变的是信息与物件的关系，而非把所有圆角一律清零：通用内容框被删除；按钮仍有边界和压下反馈；库存用托盘、选中纸签与物品图形成层次；角色与印章承载社交状态。没有添加在线总人数、收藏度、稀有度或其他虚构业务指标。

## 验证

桌面 1440×1000、手机竖屏 390×844 与 360×640；短屏自然滚动，不将界面整体缩小。检查图片加载、页面横向溢出、可见焦点、减少动态效果和所有主要交互。拨杆保持原生 range 键盘行为与至少 44px 可操作宽度；停用状态有文字与 native disabled。

项目 lint 与本目录显式应用项目规则的 ESLint 检查均通过。浏览器检查结果记录在本任务 PRD；正式界面没有变化，因此不扩展游戏规则或服务端测试。
