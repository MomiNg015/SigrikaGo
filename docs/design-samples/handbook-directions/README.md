# 部员手册三个视觉方向

2026-10-03。图片用于选择设计方向；正式手册尚未按这些图片修改。基于当前真实手册、角色详情截图、项目 DESIGN.md 和西格莉卡／达妮娅／爱弥斯标准微笑立绘生成，每张为独立桌面样板。图片中的次要角色、手写旁白和文字仅用于构图；实现时使用正式角色素材、名称、技能与原介绍，移除额外装饰文案。

对话中显示顺序与编号：

1. [横版学生证册](./student-card-roster.png)：推荐作为高频入口。头像／胸像、姓名、技能名与独立出战旗帜放在横版卡片中，便于扫视和直接选人。桌面两至三列、手机两列；详情继续独立打开并加大标准立绘。旧 Q 版与新图按各自裁切方式共用容器。
2. [展开式部员档案](./open-dossier.png)：左侧角色索引，中间大立绘，右侧技能阅读。角色与技能更突出，但同屏列表容量较少。手机改为选人条、立绘和技能上下排列。需要明确区分正在查看与实际出战状态。
3. [竖版角色照片册](./portrait-album.png)：人物画幅最大，姓名和旗帜在独立照片底栏。适合强调角色欣赏，但浏览与滚动成本较高。手机两列，姓名不能隐藏。

三套均保留角色／装饰分类、服装／语音／技能音乐入口，以及未获得状态。列表表情稳定，详情可使用现有差分；不自动轮播表情，不添加等级、好感度、战力、战绩等无对应数据的功能。未知角色的情报保持隐藏；糖果、服装、黑化造型优先级沿用正式逻辑。姓名和出战按钮不遮脸，移动操作区至少 44px。

建议采用横版册的高频列表，同时参考展开档案的详情立绘与技能阅读比例。此建议不是已选方案，待用户确定。
