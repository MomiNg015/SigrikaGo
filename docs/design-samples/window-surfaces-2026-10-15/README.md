# 窗口背景与用户资料卡片审查

普通校园窗口统一使用现有浅纸色 `--theme-bg` 和 20px 蓝色方格 `--theme-paper-grid`。保留每个窗口的布局、装饰、内容与交互，商店及其二级窗口保留专用背景。

## 实际检查范围

| 窗口 | 本轮处理与验证 |
| --- | --- |
| 仓库、部员手册、成就、个性化、好友、信箱、公告、排行榜、观战、设置、留言、确认框 | 统一格距与底色，逐个核对桌面／手机实际计算样式与截图；本地仓库原先已有方格，本轮纳入同一最终背景所有者 |
| 履历、用户详情 | 修复纯色外框以及覆盖方格的身份卡／战绩纸页；使窗口整体使用同一张方格纸 |
| 招募普通界面 | 外层窗口采用统一纸底，内部告示板与信纸插画保留 |
| 角色详情、衣柜、服装详情、举报窗口 | 实际打开二级窗口核对背景，原关闭与焦点恢复行为保持 |
| 匹配、结算 | 普通对局窗口统一纸底；移除结算窗口覆盖统一背景的旧纯色声明 |
| 商店 | 桌面／手机外框背景与修改前一致；明确排除商店内部详情和购买确认 |

源代码同时审查了小窗口、嵌套窗口、房间浮层、组队阵容选择及 IRIS 数据库窗口的背景入口，统一规则采用明确的窗口类清单。后台不使用玩家主题；剧情／教学场景、招募电影和黑化演出保留独立舞台，不作为普通纸窗重绘。

## 用户身份卡

点赞、好友、黑名单、举报改为一排纯图标按钮，44×44px，卡片右下角对齐。头像和用户名在身份行垂直居中；手机上操作区单独一行靠右。点赞数与动作／关系／忙碌状态保留在 `title` 和 `aria-label` 中。确认、举报、禁用、焦点返回以及个人履历的个性化操作保持。

旧 dossier 样式通过多个 `:not()` 获得高优先级，覆盖了新的图标按钮圆角。已将它的身份操作匹配范围收窄到个人履历，由新的社会资料工具条独立管理几何与状态，避免继续堆叠覆盖。

## 验证入口

`npx playwright test --config tests/e2e/window-surfaces.config.js`：46 项场景检查，覆盖 16 类主窗口的两种视口，角色详情／衣柜／服装详情、匹配／结算，以及 1440／800／390／320px 下的普通姓名和长姓名铭牌、四个按钮同排与相同边框、举报关闭后焦点恢复。

本轮只新增两份最终样式所有者，并收窄旧工具条规则、移除结算纯色覆盖；CSS 净增加 3173 个规范化字节、33 条 important，新增两个 important 文件和一个既有断点媒体文件，无新颜色、层级或动效。设计钩子报告的是原有测试调色常量与结算窗口既有 10px／5px 圆角，均未由本轮引入，保持原设计且不禁用检查规则。

最终验证：46 项浏览器场景均已通过（失败修复后按受影响用例重跑）；资料卡、履历、通用窗口、结算以及 CSS／主题契约共 167 项单元测试通过。`npm run lint`、`npm run build`、`npm run check:built-css`、`npm run docs:system-design` 与 `git diff --check` 通过。构建仍提示两项既有公共资源占位符和大分块警告。
