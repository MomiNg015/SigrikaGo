# 技能释放横幅样板

## 正式接入

修正后的方案已应用到 `src/modals/SkillBanner.jsx`；`production.html` 直接渲染正式组件并加载完整项目 CSS，可重播、切换角色和验证长名称。原 index.html 保留为设计样板。正式组件保留共享外观解析、服装快照、糖果效果与两秒阶段，新 cast ID 重启动画，同 ID 快照不重播语音；黑化决战继续使用独立旧组件。

正式接入验证：140 项相关测试通过，项目 lint、生产构建及构建后 CSS 检查通过。完整主题下，九名新版角色图片均解码成功；320/360/390px 无水平溢出，手机姓名与斜线包围盒间距约 15.5px；人物框在横幅上方突出 52px、下方突出 54px。1440px 桌面、长名称和减少动态效果已实看，减少动态效果下横幅动画数为零。截图为 production-desktop.png、production-mobile.png、production-long.png。

全局 CSS 清单仍报告与本次无关的既有 899 字节预算超额，以及 `mobile-adaptive/match-mode-title-layout.css` 的未登记 360px 断点；本次仅登记两个新增 owner 的精确增量，没有吸收其他改动。构建另有既有资源占位符与大 chunk 警告。设计钩子的图片提示来自 JSX spread 无法静态推断 src，实际共享解析及全部资源解码已验证；RoomScreen 测试中的旧颜色断言为既有测试文本，不是新视觉规则。

通过运行中的 Vite 访问 `/docs/design-samples/skill-banner-2026-10-10/index.html`。

- 当前新版 Q 版全身立绘在窄横幅上下出框，背景、人物与文字分别入场。
- 西格莉卡、长离、仇远切换；文案复用 `FALLBACK_CHARACTERS`，不调用线上接口。
- 重播为 2000ms 演出，末尾保留 200ms 空档后恢复定格，便于审图。
- 默认静态构图；可切手机宽度，真实窄屏自动适配。
- 不接入生产 SkillBanner，不播放语音，不改变技能结算。

## 验证

Chromium/Chrome 实际渲染 1440×1000、390×844、360×800；三角色资源均加载成功，360px 文档无水平溢出。已操作重播、定格、角色切换及桌面/手机切换，JS 无运行错误。减少动态效果模式下实际动画数量为 0。`node --check`、样板 JS ESLint 及 `npm run docs:system-design` 通过。

截图为 desktop.png、mobile.png、mobile-qiuyuan.png。未接入游戏，无需重复运行完整游戏测试套件。

## 设计检测复核

检测器把 `Marker` 识别为未登记字体：此名称只是现有 LXGWMarkerGothic-Regular.ttf 的本地别名，没有增加字体资源。`#262c41` 与 `#e9edf2` 用于独立样板的墨色与工作台底色，角色主色为本次明确的视觉探索，未写入生产主题；三项均为样板上下文中的有意选择，不添加全局豁免、不改设计系统声明。

正式接入仍需使用运行时外观解析、处理服装和糖果资源、核对特殊对局变体以及服务器阶段生命周期。此轮未引入新的共享规范合同。

## 用户复核修正

立绘改由 characterChibiSource(id, 'full') 解析当前新版完整资源，初始图片和剪影同步更换。移除技能发动标签；手机真实窄屏和桌面手机模拟均将斜线限制在文字左侧，避免分界线穿过角色名及技能名。

修正后逐一复核三名角色在 360px、390px 及桌面 390px 模拟视口：图片全部解码成功、标签节点为零、文档无水平溢出，角色名与斜线完整变换后包围盒的间距为 15.4–15.6px。截图已全部更新为新版资源。
