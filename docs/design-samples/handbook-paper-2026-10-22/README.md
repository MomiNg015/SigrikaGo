# 部员手册：角色详情三版游戏展示样板

[打开比较页](./index.html)。本轮为独立样板，未替换正式角色详情或修改生产样式。

## 审查现有窗口

以当前 `CharacterDetailDialog`、完整生产 CSS 和 2026-10-22 本地公开角色目录为依据，保存了 [桌面现状](./current-1440.png) 与 [手机现状](./current-390.png)。

1. **信息被小框打散。** 技能名、超频分别使用圆角标签，获得途径又使用方框；说明区自身还有圆角外框、描边及阴影。多层框线与角色名争夺注意力。
2. **手机的阅读空间偏少。** 立绘固定占据最高 260px 的区域，下面还需容纳姓名、CV、音乐。短竖屏常常刚读到技能就需要滚动。保留全身立绘，并让姓名、音乐与立绘共用紧凑的顶部场景，给技能留出空间。
3. **原有功能值得保留。** 立绘、实体收音机、衣柜入口及可点按的特性词都有项目辨识度；本轮直接复用这些组件，不增加身份字段、章节标签、装饰口号或新的业务功能。
4. **主题残留可见。** 当前关闭按钮仍会显示旧 HUD 的青色伪元素叉号。本轮样板清除该伪元素并显示现有 Lucide 墨色叉号；正式样式不变。

## 三版区别（游戏角色展示方向）

首轮被反馈为「太素、像说明文」，本轮重新组织三种构图，让角色立绘、专色和硬阴影成为视觉中心。没有添加虚构数值、身份标签或装饰口号。

| 方案 | 布局与取舍 | 预览 |
| --- | --- | --- |
| 1 角色展示台 | 放大、轻微倾斜的完整立绘，叠在角色专色和圆形展示台上；右侧是大姓名、厚阴影技能卡与倾斜对白纸。手机将身份与立绘并排收进顶部，正文独立滚动。 | [桌面](./spread-1440.png) / [手机](./spread-390.png) |
| 2 战术卡册 | 深墨角色卡内集中展示姓名、CV、立绘及音乐；专色环纹与原阵营图案强化角色身份，右侧突出技能内容。手机转为上方角色卡与下方说明。 | [桌面](./banner-1440.png) / [手机](./banner-390.png) |
| 3 漫画分镜 | 角色网点底纹、爆发形状、倾斜大字和带尖角的对白框；桌面图文错开，手机保留紧凑图文场景，技能以下沿整页滚动。 | [桌面](./reading-1440.png) / [手机](./reading-390.png) |

三版均不使用技能名、超频、CV、获得方式的胶囊或圆角矩形标签；信息分区使用完整技能面板、字级与留白。整体、技能面板和操作控件保留墨色硬阴影，衣柜、关闭与可点按语音段落有悬停／按下反馈。减少动态效果时取消语音段落位移。原收音机是现有实体插画控件，不是新增标签。

立绘继续使用共享解析；阵营纹样只读取 `CHARACTER_FACTIONS` 和 `FACTION_EMBLEMS` 的既有映射，未映射角色不生成阵营图案。没有新资源或生产主题接入。

比较页提供原版对照、九名角色、桌面／手机竖屏以及重新打开入口。`preview.html?view=spread|banner|reading|current&character=aemeath` 可直达；`&long`、`&noMusic`、`&unowned` 为边界检查状态。

## 复用与隔离

- 直接挂载正式 `CharacterDetailDialog`、`CharacterCostumeDialog`、共享立绘解析、技能描述及音乐组件。布局变化仅位于本目录 CSS，并由 `#root[data-design]` 门控。
- `catalog.json`、`traits.json` 来自本机公开 `/api/characters`、`/api/skill-traits` 的只读快照，不含账号数据。衣柜素材复用既有 2026-10-15 样板的公开服装目录，非实时衣柜快照。
- 假设用户可预览所有角色，服装默认未拥有；音乐选择和默认服装调整只存于当前页面内存。刷新即可复位。页面拒绝真实 API 请求，不写本地存储、账号或数据库。
- 语音按点击调用现有详情语音播放，关闭／卸载时停止；保留正式父手册出战语音的生命周期，不修改 `HouseModal`。
- 选版后才考虑生产 owner 的拆分和接入；本轮不增加生产 CSS debt，也不改正式交互契约。

## 验证

启动本地 Vite 后执行 `node docs/design-samples/handbook-paper-2026-10-22/verify.mjs`。

验证涵盖三版的 1440、800、390、360、320px，短竖屏、派生技能、长姓名和长技能、无音乐、未拥有状态，共 27 组布局；检查完整图像加载、16px 正文、阴影安全区、无横向溢出、标签样式清除、操作按钮与音乐不重叠、长姓名不挤出顶部场景和末段可达。另覆盖六组桌面／手机的特性浮层 Escape、曲目单、衣柜返回焦点、关闭重开、比较页切换及减少动态效果。输出为 `verification.json` 和同目录截图。


设计扫描的侧边线提示经人工复核为展示台分栏墨线与漫画对白尖角，属于构图边界，不是圆角卡片的彩色侧边装饰；保留这些边界，未加入忽略配置。
