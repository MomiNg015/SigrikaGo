# 部员手册：角色详情三版纸面样板

[打开比较页](./index.html)。本轮为独立样板，未替换正式角色详情或修改生产样式。

## 审查现有窗口

以当前 `CharacterDetailDialog`、完整生产 CSS 和 2026-10-22 本地公开角色目录为依据，保存了 [桌面现状](./current-1440.png) 与 [手机现状](./current-390.png)。

1. **信息被小框打散。** 技能名、超频分别使用圆角标签，获得途径又使用方框；说明区自身还有圆角外框、描边及阴影。多层框线与角色名争夺注意力。
2. **手机的阅读空间偏少。** 立绘固定占据最高 260px 的区域，下面还需容纳姓名、CV、音乐。短竖屏常常刚读到技能就需要滚动。保留全身立绘，但根据版本压缩到 175／182／185px 左右的首屏区域。
3. **原有功能值得保留。** 立绘、实体收音机、衣柜入口及可点按的特性词都有项目辨识度；本轮直接复用这些组件，不增加身份字段、章节标签、装饰口号或新的业务功能。
4. **主题残留可见。** 当前关闭按钮仍会显示旧 HUD 的青色伪元素叉号。本轮样板清除该伪元素并显示现有 Lucide 墨色叉号；正式样式不变。

## 三版区别

| 方案 | 布局与取舍 | 预览 |
| --- | --- | --- |
| 1 并页手册 | 左侧较大的完整立绘，右侧连续说明。接近原使用习惯，清除内层阅读卡与小标签，推荐作为稳妥方向。手机上下分区，正文独立滚动。 | [桌面](./spread-1440.png) / [手机](./spread-390.png) |
| 2 横幅档案 | 立绘、姓名、CV 和音乐合为上方横幅，技能获得整个窗口的行宽。信息最紧凑，角色图相对较小。手机横幅仍保留图文并列。 | [桌面](./banner-1440.png) / [手机](./banner-390.png) |
| 3 连续阅读页 | 紧凑立绘与身份并排，正文沿同一张纸自然排列；窗口按内容收缩，长内容整页滚动。适合多技能和长说明，手机无单独固定立绘区，关闭按钮保持可达。 | [桌面](./reading-1440.png) / [手机](./reading-390.png) |

三版全部去掉技能名、超频、CV 和获得途径的标签底色、边框与圆角，改用文字大小、间距和细分隔线。仅整体纸面与真实操作控件保留短硬阴影。衣柜、关闭和语音段落保留悬停／按下反馈与键盘焦点；减少动态效果时取消语音段落位移。原收音机是实体插画控件，不是新增胶囊标签。

比较页提供原版对照、九名角色、桌面／手机竖屏以及重新打开入口。`preview.html?view=spread|banner|reading|current&character=aemeath` 可直达；`&long`、`&noMusic`、`&unowned` 为边界检查状态，不作为正式产品文案。

## 复用与隔离

- 直接挂载正式 `CharacterDetailDialog`、`CharacterCostumeDialog`、共享立绘解析、技能描述及音乐组件。布局变化仅位于本目录 CSS，并由 `#root[data-design]` 门控。
- `catalog.json`、`traits.json` 来自本机公开 `/api/characters`、`/api/skill-traits` 的只读快照，不含账号数据。衣柜素材复用既有 2026-10-15 样板的公开服装目录，非实时衣柜快照。
- 假设用户可预览所有角色，服装默认未拥有；音乐选择和默认服装调整只存于当前页面内存。刷新即可复位。页面拒绝真实 API 请求，不写本地存储、账号或数据库。
- 语音按点击调用现有详情语音播放，关闭／卸载时停止；保留正式父手册出战语音的生命周期，不修改 `HouseModal`。
- 选版后才考虑生产 owner 的拆分和接入；本轮不增加生产 CSS debt，也不改正式交互契约。

## 验证

启动本地 Vite 后执行 `node docs/design-samples/handbook-paper-2026-10-22/verify.mjs`。

验证涵盖三版的 1440、800、390、360、320px，短竖屏、派生技能、长姓名和长技能、无音乐、未拥有状态，共 27 组布局；检查完整图像加载、16px 正文、阴影安全区、无横向溢出、标签样式清除、操作按钮不重叠和末段可达。另覆盖六组桌面／手机的特性浮层 Escape、曲目单、衣柜返回焦点、关闭重开、比较页切换及减少动态效果。输出为 `verification.json` 和同目录截图。

确定性设计扫描仅剩比较导航 `border-bottom: 3px` 提示：该导航明确为 `border-radius: 0`，是活动方案下划线，非圆角卡片，属于误报。字体、颜色已对齐现有设计系统，衣柜按钮角度改用既有 4px 值，立绘底板为直角；未添加忽略配置。
