# 设置窗口三套设计样板

开发服务中打开 `/docs/design-samples/settings-2026-10-15/index.html`。比较页支持三版、正式组件对照和 390/320px 预览。

| 方案 | 特点 | 取舍 |
| --- | --- | --- |
| 1 纸页清单 | 主音量独立强调，其余按行排列，明确静音按钮 | 最容易使用，视觉变化较克制 |
| 2 社团调音台 | 复用手绘播放器，四根纵向推杆，数值与通道逐列对应 | 游戏感最强；更适合以音频为主的设置窗口 |
| 3 折页设置册 | 桌面左侧分类、右侧双列音量便笺，手机顶部分类 | 分区清楚，手机滑轨较短 |

原界面的音频、界面、关于分类与四个声道都保留。原来点击音量标题静音不够显眼，三版改为明确的静音按钮，并保留静音前的音量值。现有手绘设置标题继续使用正式 `WindowTitleSticker`，调音台使用原有手绘播放器图片。

## 边界

本页为局部 React 状态，不读取或写入账号音频配置，不调用接口，不实际播放声音。当前主题与未来主题取自正式配置；未来主题保持“敬请期待”，色块只展示设计中的配色占位，不宣称未来主题已经实现。关于文案取自项目默认配置，未读取线上管理内容。正式组件和全局主题样式未改动。

## 验证

- 1440px 桌面、390/320px 竖屏 × 三版 × 三分类，共 27 组检查无页面或内容区横向溢出，图片正常加载。
- 核验静音后数值保留、Home 改变音量后取消该声道静音、分类方向键切换、未来主题反馈、Escape 关闭及重新打开。
- 原生 range 保留键盘控制；关闭后焦点回到重新打开按钮，弹窗中限制 Tab 循环；页签方向随手机／桌面布局更新。
- JSX 使用项目维护文件的 ESLint 配置通过 stdin 校验；默认 docs 目录不在 ESLint 配置中。
- `npm test -- src/modals/SettingsModal.test.jsx src/audio/audioSettings.test.js`：15 项通过。
- 已同步系统设计入口并运行 `npm run docs:system-design`。

## 设计检查复核

Arial 仅用于百分比数字，沿用项目数值字体语义，不承担装饰标题。深蓝绿滑轨是校园蓝的可辨识深色派生，灰轨与纸页配色用于未填充状态；未来主题色块是明确标记不可用的方案占位。比较工具栏的同级按钮故意使用统一间距，产品内分类、字段和声道具有不同间隔。检测器的字体、派生颜色与工具栏间距提示在该隔离探索中判为有意设计，不设置检测豁免；接入时再收敛到正式语义 token。
