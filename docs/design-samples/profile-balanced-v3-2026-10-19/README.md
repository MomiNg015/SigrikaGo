# 履历 / 详细资料：三版折中设计

[打开交互比较页](./index.html) · [三版总览](./overview.png)

本轮保留用户认可的布局关系，让内容和色彩回到 SigrikaGo。参考图用于确定身份主次、左右分区、明暗比例和角色记录的节奏；不再移植其世界观栏目。三版都是独立样板，正式窗口尚未替换。

## 三版取舍

| 方案 | 保留的布局特点 | 与项目的融合 | 手机竖屏 |
| --- | --- | --- | --- |
| [薄荷档案](./mint.html) | 左侧角色 / 右侧身份和战绩；四张角色记录 | 薄荷方格承接当前 Q 版形象，主体暖纸，粉色只用于选择和操作 | 角色区在上，身份和战绩向下；角色记录两列 |
| [墨纸分栏](./ink.html) | 左侧身份段位 / 右侧战绩；强弱对比清楚 | 深色改为项目棕墨，仅占身份区域；右侧暖纸，薄荷星级、粉色操作 | 身份和段位组成紧凑深色顶部；战绩及角色两列在下 |
| [晴蓝名片](./blue.html) | 上方身份横栏 / 下方总览和角色列表 | 信息蓝混合暖纸，细线取代重黑板；小幅展示角色 | 紧凑身份卡和纵向记录行，胜负和直接可读 |

推荐先看墨纸分栏：它保留了参考图的层次，但暖纸主体、棕墨边界、原有书签和当前 Q 版头像已有统一的材质关系。薄荷版更重角色展示；晴蓝版更重快速阅读。

## 内容依据

| 现有入口 / 字段 | 正式来源 | 三版处理 |
| --- | --- | --- |
| 用户名、头像、展示角色 | `ResumeModal.jsx`、`UserProfileCard.jsx` | 身份为首要信息；不增加 UID、编号、日期、签名或组织信息 |
| 成就、个性化 | `ResumeModal.jsx` | 仅保留操作入口；成就弹窗以现有名牌资源预览，不增加首页奖章展板 |
| 点赞、加好友、黑名单、举报 | `UserProfileCard.jsx` | 保留四个直接操作，样板仅演示本页状态和确认 |
| 星炬 / 标准 / 其它 | `WindowBookmarkTabs.jsx`、共享书签 CSS | 复用现有 SVG 纸面、轮廓和样式；桌面横写、手机左侧竖写 |
| 常规匹配 / 吃子挑战赛 / 队际赛 | `ProfileResumeView.jsx` | 保持分支含义；标准 / 其它不显示技能角色记录 |
| 段位、星数、总对局、胜负和、胜率 | `ProfileResumeView.jsx` | 重新安排层次，内容等价；队际赛使用独立出场统计 |
| 最近十盘、回放 | `ProfileResumeView.jsx` | 保留旧到新的结果条和回放入口；回放只预览示例列表 |
| 角色出场、胜负和、胜率 | `ProfileResumeView.jsx` | 每个字段直接显示；点击可预览详情 |
| 吃子纪录、排名、纪录角色外观 | `ProfileResumeView.jsx` | 单独显示挑战成绩，不混用常规段位和角色统计 |

取消借来的“光荣之路”、入社 / 苏醒 / 入职日期、奖章陈列、UID、账号后缀、章节和签名。没有用新字段补满删掉的区域。

数据是样板固定值，页面外的控制条明确注明“示例数据”；不读取或写入真实账号数据。

## 资源与视觉约束

- `data.js` 调用正式 `resolveCharacterPortrait`，全身和完整头部头像分别请求当前 `full` / `avatar` 变体。
- 使用当前 `handbook-chibi-sprites`；验证器拒绝任何废弃 `handbook-sprites` 请求。
- 原有书签直接导入正式的 `window-bookmark-shells.css`、`window-bookmark-paper.css` 和 `window-bookmark-mobile.css`。
- 色彩来源为 `DESIGN.md`：暖纸 `#fffbf2`、棕墨 `#3d2b25`、粉 `#ff9ebb`、蓝 `#9ad3de`、薄荷 `#bfe8dd`。浅色区域用这些原色混合暖纸，不照搬参考图的青色 / 荧光黄 / 大面积炭黑。
- 窗口标题和书签使用现有霞鹜漫黑；只保留外层短硬阴影，身份与头像无投影，内容靠细线和留白分组。
- 比较页的方案名称是选择器，不是产品字段。取消尺寸切换动画，让 iframe 直接切换真实视口宽度。

## 验证

启动项目 Vite 后执行：

```sh
node docs/design-samples/profile-balanced-v3-2026-10-19/verify.mjs
node docs/design-samples/profile-balanced-v3-2026-10-19/export-overview.mjs
```

`SAMPLE_ORIGIN` 可覆盖默认 `http://127.0.0.1:5173`。

- 三版 × 1440×900、768×1024、390×844、320×568，共 12 组完整检查，结果见 [verification.json](./verification.json)。
- 检查书签左侧几何和方向键、玩法、挑战成绩、角色统计、角色切换、社交确认、空战绩、长用户名、关闭重开、焦点恢复及减少动态效果。
- 检查内容白名单边界、12 个角色胜负和数值、当前头像 / 全身资源、无横向页面溢出、无资源 / 控制台 / 账号 API 错误。
- 额外检查 800px / 1024px 中间宽度的记录卡、指标及操作区，无内部横向溢出。
- 实际查看全部桌面、390px 完整页面和 320px 长名字截图；墨纸分栏不展示额外全身立绘，其他两版使用正式当前全身资源。
- 设计扫描发现的 6px 非标准圆角统一为既有 8px 控件圆角；去掉比较页无必要的编号标记和 width 过渡，扫描结果为空。

本轮只增加 docs 样板，不改变运行组件、API、账号状态、正式样式或资源解析规则。验证以实际浏览器布局 / 交互、仓库 lint 和系统设计文档测试为主；未宣称正式功能已完成接入。
