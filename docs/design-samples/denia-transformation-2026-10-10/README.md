## 动作参考

已逐帧检查[官方战斗演示](https://www.bilibili.com/video/BV1scL768EPf/) 00:46–00:52，重点检查 00:49–00:51 的近景纸人掠镜。[官方 YouTube 来源](https://www.youtube.com/watch?v=aKWE-ON3XSM) 可作备用链接。参考视频只用于研究，不随项目分发。

采用的运动特征：远处纸片稀疏、中景纸片成簇顺着弧线穿行、近景纸片靠近镜头时放大并弯曲翻面，短暂遮挡后缩远离开。保留用户要求的左向右方向。近景纸片为 14 张，其他纸片沿三条松散流线分布，不平均铺满画面。小人细描边与星形面纹按参考重绘，变身 PNG 原样采用用户附件。

## 当前时序

- 0 ms：正常全身横幅入场。
- 1000 ms：纸片开始由左向右进入。
- 1750 ms：近景掠镜遮挡中同步切换横幅和信息区立绘。
- 2500 ms：纸片清空，继续展示新立绘。
- 3200 ms：横幅结束；正式泡泡翻子保持 4240 ms 结算。

## 性能与验证

最多 174 张纸片；390×844 下为 65 张。缓存三张景深精灵，近景预绘精灵为 448×448，其余为 112×112。近景使用 12 段仿射绘制模拟柔性弯曲，总绘制调用最多 328 次；屏幕外纸片不绘制。单 Canvas，无逐纸片 DOM；渲染尺寸限制 1920×1200，DPR 不超过 1.5。减少动态效果不创建绘制上下文。

本机 Chrome 的 90 帧离屏采样：1440×900 与 390×844 的 CPU 绘制提交 P95 均约 1 ms。桌面在 1400/1500/1750/2000/2150 ms 的半不透明像素覆盖约 6%/20%/95%/26%/3%，手机约 3%/6%/94%/14%/4%。这些仅为绘制提交和遮挡窗口检查，不等同 GPU 完成耗时或真机帧率。

截图检查真实 RoomScreen 下的两处图片加载、同步切换、技能结束保留与重置恢复。15 项聚焦测试覆盖三层运动、掠镜缩放、绘制预算，以及已有形态生命周期。此次不调整 CSS 或既有服务端时序。
