# 履历／详细信息：三版实色卡片

第一版已获确认并实装到正式履历与用户详情。正式组件直接渲染书签，不再使用样板的 DOM 转接器；正式窗口保留屏幕高度上限和内部滚动。

第一版书签标签已简写为“星炬／标准／其它”，书签右端贴合窗口左边框，在窗口外沿裁切纸面，消除可见空隙的同时完整保留窗口边框。

预览入口：开发服务器运行时打开 `/docs/design-samples/profile-cards-2026-10-15/index.html`。底部切换三版，数字 1／2／3 和左右方向键也可切换；玩法标签上的方向键保留原导航。URL 保存版本，顶部切换我的履历／他人详情和空数据。

## 设计方向

| 版本 | 样式与适用方向 | 取舍 |
| --- | --- | --- |
| 暖纸手账 | 统一米白实心纸卡、略不对称圆角、棕色短硬阴影，少量粉色标记选中项 | 层次较轻，视觉变化最克制 |
| 社团档案 | 白色索引卡、直角工具按钮、侧边与顶边索引、双层叠纸阴影 | 分区清楚，但气质更规整 |
| 徽章面板 | 彩色面板、厚描边、深色硬阴影、凸起按钮 | 游戏感更强，也更醒目厚重 |

三版保持身份区、玩法分类、段位／战绩、最近十盘、角色战绩的现有顺序和基本布局。身份卡、段位卡、战绩卡、最近十盘及角色战绩外框均使用不透明填充和阴影。方格纸仅在窗口底纸与区域间隙可见。社会资料按钮仍为右下角纯图标；个人履历保留成就与个性化入口。

用户选定第一版方向后的配色修订：移除身份区橙、段位绿、最近战绩黄和表头深黄的分区配色，全部回归 DESIGN.md 的 sheet／ink；按钮使用白底，仅选中项使用校园粉混白。胜负记录和星级仍保留原语义色。阴影使用同一棕色混纸底，消除原先偏黄的阴影。此次只更新样板，尚未落地正式窗口。

后续调整：第一版的三个模式移到窗口左侧，直接复用设置的 `WindowBookmarkTabs` 纸书签、选中状态、上下键导航和移动端竖排。样板适配器转发到原模式按钮，数据与操作仍由真实组件负责，不改生产组件。正文只保留具体玩法。默认操作颜色：点赞浅粉；加好友薄荷绿／解除好友浅黄；加入黑名单浅红／移出黑名单薄荷绿；举报较深浅红；回放浅蓝；成就浅黄；个性化浅粉。禁用按钮使用灰纸色，已选定的区域卡片仍保持统一米白。

## 实现边界

直接复用真实 `ResumeModal`、`UserProfileCard`，三份独立变体 CSS；生产代码不导入样板。样板页拦截全部 `/api/` fetch，使用固定演示账号和数据，点赞、好友、黑名单、举报、玩法切换均只改变本地演示状态。回放入口展示空列表。成就／个性化使用简化演示面板，头像选择仅写入演示账号专用的本地键，不修改真实账号。

样板为展示全部区域允许页面纵向展开；正式窗口仍保留原滚动规则。切换版本取消窗口进场动画，以便直接比较实色与阴影；按钮保留短距离按下反馈和键盘焦点，支持减少动态效果。

## 正式接入验收

- `tests/e2e/profile-paper.spec.js`：履历／详情在 1440、800、390、360、320px 下验证实色与阴影、书签裁切边界、键盘切换、空数据切换和长列表末行可达。
- 现有窗口审查回归确认方格纸、头像／用户名居中、长用户名／名牌、34px 社交按钮、举报关闭后的焦点恢复。
- 第一版不对称卡片圆角和 9px 按钮圆角为用户确认的样板设计，保留该样式；样式契约测试中的既有颜色字面量属于断言文本，并非新增界面颜色。
- 正式组件截图：`production-resume-1440.png`、`production-profile-1440.png`、`production-resume-390.png`、`production-profile-390.png`。

验证结果：22 项浏览器回归通过；全量单元测试 3282 项通过，唯一的生成文档差异已重新生成并通过该文件全部 4 项复验。Lint、立绘检查、生产构建通过。聚合检查另发现后台默认快照的 characters 与当前来源不同步，该内容不属于本次界面实装，未重新导出覆盖。

### 实装后修正

点赞显示实时数量并使用薄荷绿，加好友浅蓝，解除好友／加入黑名单为警示黄，移出黑名单为绿色，举报为红色。身份卡片和头像框取消阴影，其它区域保留。补足主体绘制留边，将宽表滚动限制在战绩卡片内，清除表头负边距并保留圆角边框。18 项窗口回归及 129 项组件／样式／文档检查通过；Lint、构建及构建后 CSS 检查通过。

### 最终身份卡片布局

按钮容器绝对定位于卡片右下角，不参与网格布局；头像和用户名相对整张卡片垂直居中。手机履历卡片最小高度 160px，四按钮详情卡保留 200px，避免窄屏重叠。手机仅点赞保留数字，其他操作保留图标及无障碍名称。参见 `identity-compact-mobile.png`。

提交前复验：全局 lint、162 项相关单元／DOM／样式测试、生产构建及构建后 CSS 契约通过；最后一次尺寸调整的 8 项浏览器回归通过。后台默认角色快照差异仍存在，未修改该配置。
