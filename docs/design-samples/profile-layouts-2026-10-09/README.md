# 履历三套布局样板

## 查看

在仓库根目录运行 `py -3 -m http.server 5194 --bind 127.0.0.1`，然后打开：

`http://127.0.0.1:5194/docs/design-samples/profile-layouts-2026-10-09/index.html`

顶部按钮或键盘 1 / 2 / 3 切换布局。「手机预览」在桌面显示 390px 的竖屏样板；真实窄屏自动适配。使用独立演示数据，无账号和接口请求。

| 样板 | 布局 | 取舍 |
| --- | --- | --- |
| 侧栏档案 | 左侧固定身份与竖向模式，右侧段位、战绩与角色表 | 战绩浏览清晰；左侧占用一定宽度 |
| 横排履历 | 顶部紧凑身份与段位，下面全宽战绩及角色表 | 信息阅读直接，手机转换自然；手帐感相对弱 |
| 双页手帐 | 左页身份、段位与总战绩，右页模式及角色统计 | 校园社团手帐感最强；两页之间需要视线移动 |

成就、个性化、段位规则及回放列表可打开演示窗口。个性化仅修改页面演示姓名；回放仅展示列表。五子棋提供空战绩样例。三套共享一致统计，方便比较布局。

## 验证

`node docs/design-samples/profile-layouts-2026-10-09/verify.mjs`

使用已安装 Chrome 及 Playwright，服务器须先运行。覆盖 1440×900、390×844、360×640 共 9 个布局/视口组合。检查页面无横向溢出、姓名不压到数字列、本地头像和标题字体加载、模式与空状态切换、详情窗口、演示改名、回放列表、键盘及手机预览。结果见 `verification.json`，每种布局/宽度保存一张 PNG。

人工复核三个桌面样板与手机截图，避免只依据加载成功判断构图。正式组件和全项目测试不涉及此独立 HTML 样板。

## 设计规则复核

设计钩子提出的字体命名与圆角偏差已修正：标题使用 DESIGN.md 中的 `Sigrika Window Title`，链接同一 LXGWMarkerGothic 字体资源；交互和框体采用现有 4/8/14px 圆角。

其余浅色字面值是隔离样板内有意使用的纸面、墨线及语义色衍生色：薄荷胜、粉色负、蓝色和，以及灰棕分隔线、装订与硬阴影。它们不构成新主题配色，正文继续使用 #3d2b25 与 #6a554d。字体旧别名的再次提示为钩子缓存，实际 CSS 已统一。没有修改共享设计系统或添加钩子忽略规则。

本轮没有新的运行契约，不修改 `.trellis/spec/`；仅在系统设计入口记录样板范围。正式实现待选定布局后进行。
