# 队际赛阵容 · 三个视觉样板

打开开发服务器的 `/docs/design-samples/team-lineup-2026-10-09/index.html`，顶部切换三个方向。样板共用真实 `TeamLineupPicker`，支持移出成员、填补空位、确认、关闭和重置。视觉覆盖仅在样板入口加载，不进入正式页面。

| 方向 | 布局 | 取舍 |
| --- | --- | --- |
| 横向名册 | 桌面人物左、Round 和姓名右；手机上下排布 | 最紧凑，给下方选角列表更多空间 |
| 人物舞台 | 完整人物占主体，姓名及回合信息位于底部浅色纸签 | 人物存在感最强，占用更多高度 |
| 回合时间线 | 三轮信息由横线连接，人物在共同纸面上展示 | 顺序更清晰、边框更轻，单个槽位边界较弱 |

正式界面已改为 Round 1/2/3 并移除点击移出文本及其空白行。用户已选择第 3 套“回合时间线”，其造型已接入正式界面；样板继续保留作设计记录。
