## 浏览器渲染修正

旧版 CSS keyframes 切换 SVG backdrop-filter URL 在 Chromium 连续播放时可能不重绘，暂停动画截图却会显示正确结果。本轮改为 11 个离散定时节点直接切换背景滤镜，首节点等待 defs 挂载后 24ms；CSS 只控制遮蔽、噪块和噪点。单一 body portal、三套固定 SVG 滤镜、36 个固定噪块，没有逐帧 React 更新、页面复制或屏幕捕获。结束、取消及减少动态效果均清理定时器。

`cinematic-preview.mp4` 为 390×844 连续实播录像，已逐帧检查真实撕裂；桌面关键帧为 1440×900。实播 MutationObserver 记录信息区、横幅与横幅残影更换 src 时遮蔽 opacity 均为 1；手机无横向溢出，结束后滤镜完全卸载。暂停关键帧仅用于检查布局，不作为连续渲染是否生效的唯一证据。

60 项形态、横幅生命周期、共享时长、服务端、教学测试通过；lint、构建和构建后 CSS 检查通过。CSS 清单仍有两项本任务外的已有问题：字节预算漂移和另一文件未登记的 360px 查询，本轮只增加本效果实际 569 字节预算。

补充验收：71 项横幅 SSR / 样式合同测试、4 项桌面/手机真实对局技能稳定性测试通过。桌面实播同样确认三处 src 更新时遮蔽 opacity 为 1，结束时图片解码成功、滤镜卸载。
