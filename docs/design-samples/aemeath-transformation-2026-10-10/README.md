## 影视故障风修订
研究 [Maxon Universe Glitch](https://www.maxon.net/en/product-detail/red-giant/universe/glitch) 的损坏画面与色彩分离说明，并实际播放及检查 [Motionstash Glitch Hit](https://www.motionstash.io/c/glitch-hit) 的撕裂峰值帧。参考重点是原画面被破坏、短促冲击与快速恢复，不复制示例素材。Creation Effects 的官方 YouTube 演示在本环境播放失败，未作为已观看的视频证据。

三套确定性 SVG 滤镜以非均匀节奏切换：纵向分段位移图只移动横向像素，R/B 通道偏移，绿通道保持，减少整屏漂浮感。原版文字条全部移除。故障期间根层滤镜真正采样场景；不得仅凭 computedStyle 有滤镜名称判定可用。桌面与 390px 竖屏截图、实播录像均已更新。Chromium 桌面一次短采样的故障窗口 RAF 间隔 P95 为 7.5ms、最大 20.9ms，仅为本机无头浏览器观测，不代表真机 GPU 帧率。

设计钩子的近黑色提示属于信号缺口使用的特效颜色，不改变产品主题；保留该效果颜色且未添加忽略规则。

本轮 13 项形态/生命周期测试、4 项文档测试、lint、构建及构建后 CSS 检查通过。CSS 清单仍为 18 项通过、两项原有失败。
