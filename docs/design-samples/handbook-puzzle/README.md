# 部员手册 · 群像拼图样板

2026-10-03。用户选定群像拼图方向后的可点击样板，入口为 http://127.0.0.1:5188/ 。正式部员手册尚未接入。

一块连续画板分成十个不规则多边形，每块面积约十分之一；桌面与手机使用不同的分区。已拥有角色显示彩色头像和真实角色主题色边框；未拥有角色用原图透明轮廓生成纯灰剪影，加问号，隐藏面部与服装细节。拼块的点击区域与多边形一致，不以重叠矩形接管点击。点击打开独立详情，返回／Esc 恢复原拼块焦点和滚动位置。

上方“查看状态”是样板审阅工具，可切换拥有8人、全部拥有、全部未拥有，不是新增游戏功能。列表不放出战按钮；将选人移到模式选择中的方案另议。详情展示默认角色目录中的介绍、CV、技能和获得途径，未拥有时展示锁定档案。装饰、服装、语音、音乐与真实账号流程不在本次样板范围。

## 素材

用户附件依次映射为琳奈、娜波摩、莫宁、仇远、西格莉卡、爱弥斯、长离、千咲、达妮娅。九份832×1216透明PNG原样保存于 `assets/characters/`，逐份SHA-256与源附件一致，见 [素材清单](./assets-manifest.json)。猪小仙引用已有 `public/assets/characters/portraits/baconbits.webp`。原图不裁改，显示裁切由用途配置和拼块容器完成；莫宁保留光环。透明像素内的RGB杂色不会显示。

[视觉参考](./visual-reference.png)由ImageGen基于实际手册截图、九角色头像合览和现有猪小仙图生成，用于纸面与群像构图。生成图中人物不是最终素材，其“8/10”与实际着色数量也不一致；交互样板使用原始角色图片，并严格显示八块彩色、两块剪影。几何分区按“十块面积大致相同”的用户要求重新计算；生成图附带的花纹、摆件和装饰标签不作为正式功能。

## 预览与维护

样板由Product Design自带React/Vite模板建立，使用项目已有字体、教室背景及猪小仙肖像。当前已启动本地服务。重新运行时，在 `app/` 执行 `npm install`、`npm run dev -- --host 127.0.0.1 --port 5188 --strictPort`。构建不复制整个项目public目录，预览仍需保留仓库资源布局。

默认文案更新后，在项目根执行 `node docs/design-samples/handbook-puzzle/sync-catalog.mjs`。只导出十个角色必要字段，不访问数据库、游戏API或整个后台运行配置。
