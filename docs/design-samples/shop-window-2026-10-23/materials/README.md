# 商店局部改良：保留现有布局

本轮针对用户指出的三处问题：商品卡片朴素、对白框突兀、顶部栏不够协调。第一轮更换布局的方向已否决。

**当前迭代：用户选择 A 继续细化。** 扎希拉棋子商品预览已移除可见虚线框与原底色，仅保留棋子本身；透明边框占位保持原有几何。残星会单独采用暗红舞台绒布、炭黑五金与银灰边线：方角工具和钱包、深红价格签、深红方角对白、炭黑窗框。价格及钱包数字单独覆盖为浅字，避免原主题子元素的深色字降低对比度。B／C 未重新设计，仅供上轮对照。

开发服务运行后打开 [交互比较页](http://127.0.0.1:5173/docs/design-samples/shop-window-2026-10-23/materials/)。点击「查看原版」在同一批商品、同一店铺中直接对照，支持桌面、390px、320px、长对白、金币不足与空货架。

## 三套局部设计

| 样板 | 商品卡片 | 对白框 | 顶部栏 | 取舍 |
| --- | --- | --- | --- | --- |
| A 紫绒金签（建议先看） | 双层旧金细边、纸质底纹、紫色分类签与购买按钮 | 暖纸底、细金边，削弱粉色外框的跳脱感 | 深紫店招、细金收边、浅色标题，钱包与工具统一材质 | 与帐篷和扎希拉服装最协调，气氛较沉稳 |
| B 手绘货签 | 虚线票签、纸张错角、暖色购买区 | 带缝线感的纸便笺 | 纸质店招、棕色工具描边 | 更轻松、更贴近手绘主题，浅色面积较大 |
| C 彩边珐琅 | 紫粉双层彩框、椭圆商品衬底、独立价格底片 | 深紫绒色底与浅色字 | 柔和紫色拼接、浅色工具按钮 | 道具辨识感强，整体更偏游戏界面 |

三套保持现有字体；标题收紧字距。对白装饰只在原元素边界内绘制，不移动店主或改变对白文字的盒模型。当前 A 的服装商店使用独立赤黑银材质，保留原透明角色商品构图。

## 实现边界

- `sample.jsx` 直接挂载正式 `ShopModal`，先导入正式 `src/styles.css`，再导入限定在 `#shop-materials` 下的样板材质。原版模式不应用材质覆盖。
- 保留现有上二下三排布、卡片大小、缩放、旋转、浮动、背景、店主、店铺切换路牌、header 控件布局。未改生产源码；此次没有解决或改变原有小屏整卡缩放。
- 商品目录来自上一轮保存的默认快照 `../catalog.json`，不是实时商品或库存。固定随机种子仅用于样板，使初始位置可比较。切换材质不重新挂载商店。
- `fixtures.js` 仅拦截本页 `/api/` 请求，购买、装备与余额变化只存于当前页面内存；未知 API 返回模拟 404，不转发服务端。加载图片、字体和源码仍走正常静态请求。
- 原版开关、三套材质与店铺切换保留当前购买结果；「重置演示」或刷新页面恢复夹具。

## 验证

运行 `node docs/design-samples/shop-window-2026-10-23/materials/verify.mjs`，需要开发服务。

- 18 组对比：3 套材质 × 2 家店 × 1440×900／390×844／320×568。与同页原版逐一比较窗口、header、控件、卡片层、舞台、店主、对白和路牌的矩形与动效声明，完全一致。测试仅为稳定截图暂停浮动，样板本身未暂停动效。
- 三套均验证商品详情、购买扣币、服装购买与装扮、刷新冷却、关闭重开、余额不足、长对白和空货架；没有实际 API 网络请求。
- 浏览器截图检查商品、店主加载与文字覆盖。长对白仍遵循现有组件的扩展方式，320px 的原布局约束仍然保留。
- 实际样式的按钮／对白对比度：A 7.89／8.98，B 6.00／7.39，C 5.22／6.63。详见 `contrast-check.json`；标题使用浅字深紫或深字浅纸。
- 检查记录：`verification.json`；对照截图：`original-*`、`velvet-*`、`ticket-*`、`enamel-*`；比较页截图：`comparison-page.png`。

## 设计钩子复核

局部扫描的颜色／圆角 advisory 详见 `design-hook-findings.json`。它们属于可比较材质方案的有意差异：紫与旧金取自扎希拉场景，残星会按本轮要求采用独立赤黑银色盘，纸签使用不等圆角，珐琅框使用柔和轮廓；因此在本次独立设计探索中判定为上下文允许的提示，保留样板值。没有修改全局设计系统或添加忽略规则。正式接入时再整理为商店局部 token。

实际发现并修正了全局 `!important` 清理规则吞掉装饰伪元素、SVG 子路径颜色不随按钮继承、装饰星形与商品名相叠的问题；不以忽略规则掩盖这些渲染缺陷。
