# 仓库纸卡内容模板

日期：2026-10-22。根据用户保留厚阴影、悬停和按下反馈的意见，对仓库内容做一版独立模板，并重新整理数量显示。**仅模板，尚未接入正式仓库。**

开发服务器运行时打开[预览页](http://localhost:5173/docs/design-samples/warehouse-paper-2026-10-22/)，可以切换新模板／现有窗口，以及手机预览。页面中的库存与使用过程均为本地演示，不读取账户、不调用 API。

## 这版调整

- 保留原仓库外框、标题贴纸、方格纸背景及目录＋详情结构。
- 道具条目改成完整纸卡：2px 墨色边框、3px／4px 硬阴影；悬停轻抬，按下下沉、缩短阴影。详情区也采用有厚度的纸面。
- 数量统一为「持有 + 数字」，取消列表下划线和详情倾斜印章。桌面与手机都靠目录右侧对齐；详情数量与使用按钮处于同一信息行。数字不遮挡道具图。
- 手机每行只显示一种物品，缩略图、名称、持有数量横向排列；长名称最多两行，选中后在详情中完整阅读。只有目录和必要的详情正文滚动。
- 详情图保留圆形底纹、虚线圆环及原来的 -7° 倾斜；放大展示区域，手机详情图也独占一行。短竖屏优先保证数量和使用按钮完整可见。
- 移除顶部分类选项卡、道具种类计数、详情分类文字和底部页码／左右切换按钮，通过目录选择物品。
- 继续使用项目真实道具图片、标题贴纸、马克笔下划线、霞鹜字体和现有配色。

这里有意让卡片承担厚度，让数量只承担信息，不给数字再套一层徽章或装饰框。数量只是库存读数，也不会看起来像可点的按钮。

## 验证与边界

运行 `node docs/design-samples/warehouse-paper-2026-10-22/verify.mjs`。复用项目 ESLint 配置，检查桌面、390／360／320px、短竖屏，以及四位数、长名称和空仓库。验证手机单列、圆纹与旋转、分类及翻页控件移除、图片加载、卡片与数量边界、末行阴影、选择／使用、悬停／按下／减少动态效果和预览切换。结果保存在 `verification.json`。

样式只由本目录模板导入，生产 `src/` 没有修改。外观取自当前 `DESIGN.md`，纸卡为用户指定的项目风格；没有新增颜色或圆角尺度。模板确定后再考虑正式接入。
