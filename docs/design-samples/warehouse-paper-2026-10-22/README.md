# 仓库纸卡内容模板

日期：2026-10-22。根据用户保留厚阴影、悬停和按下反馈的意见，整理仓库纸卡、数量和手机布局。**用户确认后已接入正式仓库，模板保留供追溯。**

开发服务器运行时打开[预览页](http://localhost:5173/docs/design-samples/warehouse-paper-2026-10-22/)，可以切换设计模板／正式效果，以及手机预览。[正式效果](./production.html)直接渲染生产 `WarehouseModal`，复用已有隔离库存预览，不读取真实账户或向服务器发送道具请求；正式游戏继续使用服务器库存与原使用流程。

## 这版调整

- 保留原仓库外框、标题贴纸、方格纸背景及目录＋详情结构。
- 道具条目改成完整纸卡：2px 墨色边框、3px／4px 硬阴影；悬停轻抬，按下下沉、缩短阴影。详情区也采用有厚度的纸面。
- 数量统一为「持有 + 数字」，取消列表下划线和详情倾斜印章。桌面与手机都靠目录右侧对齐；详情数量与使用按钮处于同一信息行。数字不遮挡道具图。
- 手机每行只显示一种物品，缩略图、名称、持有数量横向排列；长名称最多两行，选中后在详情中完整阅读。列表按可用高度容纳整数行卡片，原生滑动停止后自动对齐完整卡片，首尾卡片与硬阴影均留有空间。普通手机显示 3–4 行，短竖屏显示 2 行。
- 详情图保留圆形底纹、虚线圆环及原来的 -7° 倾斜。桌面保留大图；手机详情收紧至约 196–226px，图文并排、操作置底，把更多空间留给列表。长详情正文可以独立滚动，数量和使用按钮始终可见。
- 移除顶部分类选项卡、道具种类计数、详情分类文字和底部页码／左右切换按钮，通过目录选择物品。
- 继续使用项目真实道具图片、标题贴纸、马克笔下划线、霞鹜字体和现有配色。

这里有意让卡片承担厚度，让数量只承担信息，不给数字再套一层徽章或装饰框。数量只是库存读数，也不会看起来像可点的按钮。

## 验证与边界

运行 `node docs/design-samples/warehouse-paper-2026-10-22/verify.mjs`。复用项目 ESLint 配置，检查桌面、390／360／320px、短竖屏，以及四位数、长名称和空仓库。验证手机详情高度、单列、圆纹与旋转、分类及翻页控件移除、图片加载、卡片与数量边界、末行阴影、选择／使用、悬停／按下／减少动态效果和预览切换；实际执行滚轮与触摸滑动，并检查任意停靠、首尾、缩放及重新打开后的整卡边界。结果保存在 `verification.json`。

生产与模板共用 `useWarehouseListRows`，用 `ResizeObserver` 按容器高度分配完整行，关闭时释放监听。仅设置滚动吸附无法保证上下两个边缘同时完整，因此行高与可见行数必须配合。

生产样式替换现有三份 `warehouse-field-guide*.css`，保留原导入顺序和角色选择弹窗规则。`WarehouseItemGrid` 继续使用实时库存和原动作回调，没有引入模板的虚拟确认框。正式验证命令：`npx playwright test --config tests/e2e/window-surfaces.config.js warehouse-paper.spec.js warehouse-team-match.spec.js`。单元／DOM 回归覆盖选中、移除、数量刷新、并发防重、请求失败重试和角色目标流程。设计钩子命中的 `#d8d4cc` 是原有禁用色的测试断言，不是本次新增配色，保持不变。
