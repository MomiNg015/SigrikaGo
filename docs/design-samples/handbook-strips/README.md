# 部员手册斜切拼接

本目录保存当前正式 `HouseModal`／`HouseCharacterGrid` 的渲染截图，替代此前群像拼图的审阅结果。预览夹具仍为 `tests/e2e/fixtures/handbook-puzzle.html`，它直接使用生产组件与完整样式，不修改账号。

角色沿用目录显示顺序，包括后台排序。桌面从左到右，恢复较大的胸像，各人物眼线按原图逐一校准，仇远另放大10%、娜波摩另缩小9%；悬停或键盘聚焦扩宽当前条带，人物尺寸与纵向裁切保持固定，只横向挪动，为右下无底色大号姓名留出空白。默认桌面状态不显示姓名。

手机从上到下，立绘左、右交替，对侧显示无底色大号中文姓名。所有平台点击角色直接进入对应详情，独立“查看详情”按钮已移除。窄屏鼠标悬停／键盘预览可扩高显示胸像，保留原站位，姓名靠近头像水平；鼠标移开及时恢复普通高度。手机触摸不锁定预览，关闭详情后回到普通高度。姓名中文采用现有霞鹜漫黑（LXGW Marker Gothic，手册标题同款），英数字保留项目霞鹭字体：后者实际没有中文字形。小纸缝与淡主题色背景保持，手机长列表由纸窗内滚动区承载。

浏览器回归覆盖1440×1024、1440×768、390×844、360×640、桌面固定大胸像与校准标记、手机交错姓名、匿名无素材状态、直接点击详情、触摸取消、混合输入下半区域点击和旋转后的焦点恢复。展开截图表示窄屏悬停或键盘预览，真实触摸点击直接打开角色详情。
