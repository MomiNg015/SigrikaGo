# 排行榜审查与设计样板

## 唯一名次与三席领奖台

最新规则已取消并列名次：保持原成绩条件优先，全部相同时按达成时间先后排列。领奖台只取前三位，固定金银铜，其他同分玩家进入第四名起的名单。吃子赛结算、个人资料及固定个人排名采用同一规则。多人同分预览现在模拟五个相同成绩，截图见 `production-390-equal-scores.png`。

此轮 139 项相关测试、13 项启动／队际／迁移合同测试及 40 组浏览器验证通过。普通历史数据没有精确达成时间，兼容采用玩法最后更新时间；吃子赛从历史结算回填最早同分纪录。新增成绩均持久化达成时间，重复相同成绩不改先后。

## 方案 2 手机第六版

用户确认三人并排、冠军居中的构图。最新修订移除默认显示第一名的共享详情行及台座选择按钮，胜局／胜率直接显示在各自台座内，吃子赛直接显示提子数；下方名单直接从第四名开始。名单收成两个区域：左侧放大头像与姓名／段位，名次收进头像角标；右侧以较大的胜率和次一级的胜局建立层级，不再拆成数个相近的小列。段位星槽压缩为一颗星与当前／上限，使用共享 normalizeRankProgress 与 rankStarLimit；九段仍显示积分。长名字最多两行。桌面完整战绩、已确认的名单布局及另外两套方案维持本轮开始时的展示。

本轮 hook 中的头像来源展开仍为误报；颜色和 6px 小圆角沿用已存在的局部样板风格，未扩展正式设计令牌，未增加忽略配置。

[打开比较页](./index.html)。需要项目 Vite 服务；默认地址为 `http://127.0.0.1:5173/docs/design-samples/leaderboard-2026-10-14/index.html`。可切换三版／现状、手机预览及边界状态。数据均为模拟。

## 现状审查

以当前 `LeaderboardModal`、`LeaderboardRow`、完整生产样式和隔离模拟数据进行实测，截图见 `current-1440.png` 与 `current-390.png`。

1. **桌面列宽分配不均**：“常用角色”在 1440px 样例中换行，而用户名与段位之间留白较多。头像和姓名分成独立列，辨认玩家时需要横向跳读。建议合并为身份列，保留段位及数据独立对齐。
2. **视觉主次接近**：前三名有金银铜底图，但行内字号、粗细与普通行差异有限；粗框、硬阴影、纸格和底图共同抢注意力。建议保留窗口纸质轮廓，用名次和身份建立重点，减轻行内装饰。
3. **手机阅读路线分散**：用户名与段位集中在卡片上中部，战绩和胜率靠右下，头像与大量留白分离。原样例 390px 可见约四张完整普通卡。建议身份居左、段位居右、战绩单独占下一行，避免在狭窄空间叠塞标签。
4. **个人排名占高**：现状底部完整复制约 130px 的卡片。建议沿用同一行组件和固定位置，但压缩到约 96px（短屏长名字允许自然增长），让名单保留更多可滚动空间。
5. **实现维护风险**：段位在行内渲染两份后按断点隐藏；基础、主题与移动安全层重复接管尺寸及对齐，多处 `!important` 和 `nth-of-type` 依赖。正式接入时应明确一个最终样式 owner，保留服务端 `ranking`、共享身份／服装解析及段位规则。

## 三个方向

| 样板 | 设计重点 | 优点 | 代价 |
| --- | --- | --- | --- |
| 校园荣誉榜 | 轻纸卡、名次牌、身份组合、薄荷个人排名 | 与现有校园风衔接自然，信息层级平衡 | 每屏人数少于成绩单 |
| 领奖台 | 前三名集中陈列、冠军居中放大、其余为简洁名单 | 荣誉感和角色表现最突出 | 手机首屏更多空间用于前三名 |
| 竞技成绩单 | 横线分隔、隔行底色、紧凑数据、缩小头像 | 扫读和多行比较效率最好 | 美术表现和领奖仪式感较弱 |

建议先比较校园荣誉榜：保留现有窗口识别度，同时改善身份与数据的组织。希望排行榜成为荣誉展示入口时可选领奖台；常用来查数据则选竞技成绩单。

## 范围与行为

方案 2 已按用户最终确认接入正式排行榜。“正式版”页使用真实 `LeaderboardModal` 配隔离数据，三套探索样板继续保留用于对照。正式版保留原窗口和书签外观；手机普通战绩只显示胜局／胜率，前三名各自展示数据，第四名起采用头像角标＋姓名段位＋右侧战绩。名牌按可用宽度整体等比缩放，缺失／加载失败头像使用首字占位。

- 四模式切换、关闭／重开、方向键／Home／End 切换模式、Escape 关闭、失败重试均为本地交互。
- 保留现有数据含义；常规榜额外显式呈现现有 `draws` 与总局以避免胜负之和误解。吃子赛展示纪录角色与提子数。
- 所有样板复用 `RankProgress`、`UserIdentity` 与 `characterPortraitImageProps`。没有添加赛季、奖励、趋势或虚构实时排名差距。
- 名次已取消并列。多人同分样板展示五人相同成绩、按达成先后唯一排序为 1／2／3／4／5，前三位进入金银铜领奖台，其余进入名单。
- 正式组件仅在“正式版”页载入全局 CSS，API 被页面内专用令牌桩隔离。设计页无账号请求，不使用真实用户数据。
- 正式弹窗复用生产对话框、身份、头像和段位合同；保留吃子赛服装快照、并列排名及过期请求保护。
