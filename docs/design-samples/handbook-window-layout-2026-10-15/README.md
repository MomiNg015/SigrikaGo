# 现有角色详情与衣柜布局修复

按用户反馈回到现有设计修复；前一轮三版样板不接入。样式改动仅在三份既有 CSS 所有者内，另修正曲目单 Escape 事件处理。保留手绘纸框、人物、音乐播放器、两列手机衣柜和原换装流程。

## 实测与修正

| 问题 | 原因与修正 |
| --- | --- |
| 电脑衣柜入口右边阴影被削掉 | 入口 right:0，所在立绘容器 overflow:hidden；将右侧内缩为 6px，保留按钮与悬停阴影 |
| 320/360px 角色名与播放器重叠 | 固定两列为播放器预留宽度后，姓名实际宽度超出剩余列；改为可换行的标题行，放得下时仍同排，放不下时播放器另起一行 |
| 手机衣柜整体偏右、偏下 | 通用 .nested-modal 的 inset:8px 作用于 relative 衣柜，再次偏移；清除位移与外层内边距，保持遮罩已有安全留白 |
| 长服装名直接被卡片边缘切断 | 手机网格居中对齐时，文字保留自身内容宽度；限制到触发按钮宽度后正确省略，读屏标签保留全名 |
| 曲目单按 Esc 时角色详情一起关闭 | 原 document 冒泡监听晚于父窗口处理；改为捕获并消费按键，先关闭曲目单，再次 Esc 才关闭详情 |

衣柜在 320px 屏幕上的右边缘由 316px 回到 308px，留出完整阴影。修改前 8 项回归中 6 项失败，定位到上述阴影、标题和偏移问题；修改后同组检查通过。

已核对原窗口层级：衣柜与服装详情分别为 161、162，真实嵌套链路在过渡完成后正常显示；没有为了截图隐藏父窗口。截图及测量等待有限入场动画结束，避免将淡入中的叠影当成层级故障。
