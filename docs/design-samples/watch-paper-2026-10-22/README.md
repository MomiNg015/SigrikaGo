# 观战窗口 · 正式纸卡效果

预览：`http://localhost:5173/docs/design-samples/watch-paper-2026-10-22/`

用户已确认实装，正式 `WatchModal` 使用本方案。本页直接挂载生产组件与完整主题，保留本地虚构房间隔离；可切换全部对局、结束状态与手机宽度。需要完整手机视口时直接打开 `preview.html`。

## 设计

- 搜索框沿用好友窗口的纸色、2px 墨边、8px 圆角、3px/4px 硬阴影和 16px 输入文字。没有搜索按钮，聚焦不增加边框或发光。
- 对局卡保留厚阴影；桌面悬停抬起并浅染薄荷色，按下下沉；沿用项目的减少动态效果设置。
- 已结束对局使用浅灰背景，悬停和按下始终保持灰色，仍可进入观战。
- 桌面保留对齐表头；手机每场一张卡，首行为玩法／房号／人数／状态，下方是双方头像和名称，右侧保留手数吊牌。
- 保留真实角色图、共享身份渲染、暂离与结束状态，不添加玩法分类、装饰横梁或新的业务字段。
- 列表按可用高度安排完整卡片，长名称先按自然高度测量，再分配行高；原生滚动吸附保留滚轮、触摸及键盘操作，边缘预留阴影空间。纸张伪元素和内容一起移动，吸附容器自身不位移，避免悬停干扰停靠位置。

布局与字段由 `watch-ledger.css`、`watch-ledger-mobile.css` 管理；搜索及卡片材质由 `watch-ledger-paper.css` 管理；`useWatchListRows` 直接观察正式列表。样板的重复样式和测量 hook 已移除。

## 交互与隔离

直接挂载生产 `WatchModal`，因此仍使用原有房间号／双方玩家名的 trim、大小写归一和即时本地匹配。不会把输入操作改成提交搜索。

房间复用 `watch-mobile-2026-10-13/fixtures.js` 的虚构数据。页面 fetch 替身只接收带预览标识的 `/api/rooms/watch?mode=all`，其余 API 请求拒绝。点击卡片只显示房间号和重开按钮，不连接真实房间。无真实账号、Socket 或数据写入。

`?finished` 演示结束状态；`?empty`、`?many`、`?long`、`?error` 分别演示空态、30 个房间、长名称／四位手数／三位人数，以及加载失败。旧 `template-*.png` 和 `current-1440.png` 保留为确认时的历史截图，最新正式效果见 `production-*.png`。

## 验证

启动本地 Vite 后运行：

```sh
node docs/design-samples/watch-paper-2026-10-22/verify.mjs
npx playwright test --config tests/e2e/window-surfaces.config.js watch-paper.spec.js
```

预览脚本包含 scoped ESLint 和九组 Edge 浏览器验证：1440、1024、800、390、360、320px，短竖屏、长名称、多房间；即时搜索、无焦点外框、刷新、空态、失败、整卡入口、Escape、重开、悬停／按下、减少动态效果、灰色结束卡、滚轮和真实触摸事件。停靠检查等待滚动真正结束，不能将平滑滚动经过某个完整位置当成最终状态。输出见 `verification.json` 和同目录截图。

`watch-paper.spec.js` 从真实 `AppOverlays` 入口验证桌面与手机的即时筛选不会增加请求、刷新转为结束时变灰、悬停／按下保持灰色且按钮可用。DOM 回归保留入场、关闭与错误恢复，hook 回归覆盖尺寸／内容变化、空态、主题门控、观察器回退及卸载清理。接口与后端规则没有变更。
