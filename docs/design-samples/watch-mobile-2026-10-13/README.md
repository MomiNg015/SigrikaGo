# 移动端观战布局复审

[三版并排比较](./index.html)。桌面浏览器直接展示手机宽度；手机使用顶部方案按钮切换。支持 320／360／390／430px 和长昵称／大数值切换。

## 现状证据

正式 `WatchModal` 的 `watch-ledger.css` 将手机一行拆成六等份：房间、类型、状态在上，双方各占半宽，手数、人数、操作分散在下。实际 390px 下每条 116px，昵称 12px、状态 10px；头像和棋子进一步占据昵称空间，320px 或长昵称时省略号损失识别信息。鼠标悬停标题不能解决手机阅读需求。

本轮不把“更矮”作为唯一目标：保持 14px 完整昵称，辅助标签至少 12px；合并相关信息，保留手／人单位和 44px 操作目标。长昵称自然换行，允许条目增高。原图片标题、窗口边框、背景和阴影保留。

## 三版：计分牌与角色视觉修订

用户否定纯文字密排，要求人数图标和对弈 Header 的手数牌。现复用正式 `.room-move-placard` 的双挂环、方形纸面、描边和硬阴影，样板内缩放；人数使用 `Users` 图标加数字，并提供“房间人数”的无障碍标签。接口没有提供当前行棋方，因此牌面保持中性，不按手数奇偶伪造黑白回合。三位、四位数分别缩放以适应牌面。

| 方案 | 视觉与布局 |
| --- | --- |
| 1 计分牌名册 | 玩家与头像上下排在左侧，右侧倾斜手数牌，人数紧跟房间号，类型纸签位于行首 |
| 2 中央对阵牌 | 更大的双方角色围绕薄荷色计分牌，人数紧跟房间号，强调对阵关系 |
| 3 赛程票签 | 左侧为手数票根，右侧两位玩家，底部纸签／房间与人数／状态；虚线与硬阴影强调纸票质感 |

三版都保留完整昵称换行；普通无铭牌身份移除无意义内边距，避免昵称被额外挤压，装备铭牌的留白不覆盖。黑白方以头像角落棋子表示，暂离头像灰显。整体沿用奶油白、浅粉、薄荷与蓝色，人数图标与数字始终位于房间号旁；对局中使用绿色文字与圆点，已结束使用灰色文字与圆点。

## 范围与验证

三版布局仍为隔离样板；绿色对局中／灰色已结束同步到正式观战列表的桌面和手机样式，数据接口不变。三版均使用本地同组样板数据，搜索、刷新、关闭重开可操作。按用户修订，移除独立观战按钮及操作列，整行原生点击区触发入口；样板点击后关闭列表，不访问真实账号或加入真实对局。支持 Enter／Space 和整行焦点提示。

`node docs/design-samples/watch-mobile-2026-10-13/verify.mjs` 通过 48 组布局／内容组合：四个手机尺寸（含 320×568）× 三版 × 正常／长昵称大数值／30 场／空列表。检查无横向溢出、完整昵称换行、字号、触控尺寸、固定窗口、三位／四位手数不溢出牌面、人数图标及语义标签、图片解码、末行触达、搜索、整行点击、刷新、Enter／Space 与关闭重开。比较页的方案、宽度和长昵称切换单独验证通过，局部 ESLint 通过。

设计扫描的缺图提示是属性展开造成的误报：`characterPortraitImageProps` 返回真实 `src`，所有头像经浏览器解码验证。未添加忽略规则。桌面比较图、390px 与 320px 样板及 320px 长昵称截图保存在同目录。

视觉扫描复核：新增状态色已改为现有色板混合值，不引入独立色值或忽略规则。
