已按用户确认的功能 C 方案接入正式主题。覆盖履历、他人详情、好友、仓库、观战、角色详情、成就与公告。原有七种构图及各卡片的大小和留白保留；按后续要求，段位将授章图形左右镜像后放在左下，成就继续使用原图放在右下。

## 正式实现

- 八个 SVG 位于 `public/assets/ui/card-prints/`：七种功能图形加段位镜像。`rank.svg` 仅对图形执行 `translate(600 0) scale(-1 1)`，不翻转文本、星级或卡片本身。
- `src/styles/mobile-adaptive/card-screenprints.css` 为唯一正式 owner，在最终主题入口导入。只设置五个背景绘制属性，保留背景色、边框、阴影、动效与布局，采用明确窗口／卡片白名单。
- 主题作用域只允许普通 Bright School，排除黑化。好友和仓库的选中色、观战灰色结束态保持原有语义；观战纹理附着原有 `::before` 纸卡底层。
- 人物技能标题声痕、简介棋子、阵营徽记、立绘与音乐控件未修改。详情预览在主题壳挂载后打开 Portal，与实际打开窗口的生命周期一致。
- 正式预览只加载应用 CSS，不加载样板材质或样板根标记；旧 A/B/C、功能样板和纯色对照通过样板专属覆盖继续可用。预览数据仍在本地模拟，生产组件和接口没有变化。
- 精确 CSS 增量：1 个文件、4308 个规范化字节（含 import）、5 个背景用 important、1 个媒体查询文件；无新颜色、层级或动画。没有吸收工作区中其它履历改动的 CSS 数值。
