# 对弈引导：右侧阶梯选项正式预览

通过项目 Vite 服务访问 `index.html`。`scene.html?scenario=normal|long|many|single|quiz|continue` 直接挂载正式 `TutorialBattleScreen`；样板只提供文案和视口控制，不模拟选项组件或剧情记录。

## 已接入行为

- 五键功能区保持原位；回答独立绝对定位、透明容器、等宽单列、左对齐、从上到下向右阶梯错落。移动端按棋盘完整外框下沿定位，可覆盖我方信息和功能区；桌面在我方信息下方的右侧空间。
- 最终按用户要求恢复 3px 墨色轮廓和硬阴影，使用浅绿实底与暖纸分隔边。沿用原引导按钮的正常 `#e4f8dc`、悬停 `#d7f5ca`、按下 `#ffd6e7`，设计钩子的三项颜色提醒属于既有功能色复用，不是全局调色板扩张；未新增忽略规则。
- 单行入场 210ms，总错峰不足 90ms；减少动态效果时直接显示。回答阶段不压暗，原落子与功能键引导仍聚焦。
- 剧情记录在桌面／手机都位于 header 退出左侧，复用真实 ChatBox 向下展开。两按钮同为 44px，尺寸、圆角、边框、阴影及按压相同，仅颜色和图标不同。
- 点击走原分支、防重复提交和错误重试；单独的“继续”仍在功能区。退出确认或记录弹窗打开时回答不可操作，关闭记录保留入口焦点。

## 空间取舍

优先利用宽度，再压缩高度、字号、内边距和行间距。390×844 普通三回答为 15px；360×640 可紧凑至 12px、27px 最小高度、7px 行间距，三回答完整展示。320×568、短屏长文案或六条长文案可能需要内部滚动，保留全部文字和末项可达。局部紧凑档位不是全局触控尺寸规范。
