# SigrikaGo 系统设计

`AppOverlays` 的懒加载窗口各自使用独立 `Suspense` 边界。履历打开成就、个性化等新窗口时，仅新窗口等待模块加载，已打开窗口保持可见及原有状态，不会闪隐后一起重现。

玩家常规校园主题窗口统一使用左侧手绘书签选项卡：履历、设置、成就、排行榜、观战、好友、首页玩家详细资料、公告和招募。外轮廓为不随 SVG 缩放变细的 2.5px 描边，文字使用霞鹜字体；桌面单行横排、手机单列竖排，长招募道具名按文字长度展开并保留图标及数量。`WindowBookmarkTabs` 将书签挂载到显式启用窗口外层，内部内容与书签分别滚动，保留未读点、原回调和加载禁用状态，观战书签仅显示模式名称。手机窗口受安全视口限制，履历与详细资料随内容收高；黑化、其他主题、房间内资料及底部功能栏保持原控件。当前商城的双店铺切换不改，未接入现行入口的旧商城分类和扭蛋组件不重新启用。

手机首页以匹配插画为主体：挂式学生证布局内匹配入口向两侧各扩展 16px，高度为 `clamp(248px, 70vw, 300px)`；顶部栏取消旧最小高度并收紧内边距，六项功能区使用三行 `max(52px, 13.5vw)` 的实际行高，移除旧逐行上移偏移。底板保留末行图片与阴影所需的底部留白，短屏自然滚动，桌面布局保持原样。

首页米黄色底板保留原纸纹与外框，内部叠加低对比浅棕色手绘方格：由 `main-panel-material.css` 的底板伪元素重复绘制 `home-paper-grid.svg`，桌面格距 48px、手机竖屏格距 36px；装饰位于内容下方、不接收指针事件，黑化首页不启用该层。

好友状态标签文字双轴居中；手机端使用等宽状态列，立绘与左对齐用户名靠拢，操作按钮保持行末，避免不同状态字数导致列错位。

贴纸标题头预留 52px 最小高度、12px 底部内边距及 10px 内容间隔，避免虚线与控件阴影、正文重合。

好友与黑名单列表按自然行高从顶部排列，少量好友不会拉伸填满列表；去掉列标题头，行顺序统一为状态、角色立绘、用户名、操作；桌面好友窗口宽度上限收紧至 760px，保留列表滚动及阴影留白。

窗口阴影边界：设置内容滚动区保留右侧、底部阴影留白，主题表面清理不得清空该内边距；商店卡片排布为旋转、浮动及硬阴影预留安全空间，商品区继续保留裁切和绘制隔离。

主界面窗口六项精修：手机商店气泡清除桌面 bottom 定位与固定比例，按台词自然增高；音量滑条使用校园薄荷色、墨色轮廓及原生范围输入交互，手机采用标题与数值同排、滑条独占下一排；桌面好友将头像和姓名靠拢，状态置于立绘前、操作置右；排行榜桌面仅显示专用段位列，手机姓名采用明确省略；个性化窗口按内容收紧，已装备与试穿分别显示勾选和眼睛标记；登录／注册选中项保持蓝底和内描边，不依赖悬停。

剧情与对弈引导的“继续／立即继续”操作统一在文字左侧显示 18px 空心播放三角（`Play`），图标不参与无障碍名称；普通回复仍显示对话图标。

剧情窗口的“继续／完成”按钮铺满操作区整行，不再限制为 280px；底部操作行按实际内容高度占位，选项换行后仍保留窗口内边距；选项列表高度上限为 `min(34dvh, 260px)`，超出时内部滚动，并预留按钮流光、焦点框与阴影空间。

宽屏首页的学生证横向位置由 `HomeStage` 根据中央内容区左缘及内边距计算，取该位置与木板原 8% 挂点中更靠内的一侧；部员手册随后居中于学生证与对弈入口之间。窗口变化时同步重新计算，手机竖屏清除桌面定位变量，保留既有布局。

观战选项卡的房间数标签保持等宽等高，并禁止 Flex 收缩，防止窄屏或标签内容挤压时圆形变成椭圆。

桌面端履历与详细资料的段位、积分、总对局、胜率四张摘要卡片采用等宽布局、统一内边距和数值字号，标题与数值分别对齐；总对局右侧保留回放按钮，移动端沿用原有两列紧凑布局。履历与详细资料的角色战绩为空时，保留卡片底色、边框、圆角和阴影，在卡片内居中显示紧凑的“暂无”标签；仅隐藏表头及表格内容，不预留大块空白。剧情与对弈引导操作按钮采用柔金色纸签底、与校园控件一致的 3px 描边和轻阴影，回复选项配对话图标、左对齐文字与右箭头；多选项在桌面使用等高网格行，手机竖屏单列等宽并按文字自然增高；仅可用按钮边缘的一小段彩光持续流动。禁用状态不显示流光，减少动态效果时保留静态高光。最终样式由 `mobile-adaptive/guided-actions.css` 管理，保留原有按钮交互与竖屏换行。

云端测试期间，`NODE_ENV=production` 下彩虹豆豆跳跳糖禁止对西格莉卡使用。`server/items.js` 统一提供 `disabledCharacterReasons` 库存字段及服务端 403 校验，仓库按该字段禁用目标并显示“暂不可用”；校验早于剧情读取、扣道具和用户状态写入。本地开发与其他角色保持原规则，已有剧情恢复和取消效果能力保留。详见 [部署环境说明](./deployment.md#环境变量)。

履历与他人详细信息共用同一套精简战绩呈现：不显示“角色战绩”和“最近十盘”可见标题，保留语义区域名称；最近十盘居中显示一行结果，回放入口统一为“总对局”右侧的 44px 图标按钮。共用摘要、表头与手机列宽样式覆盖 self/social 两种上下文，社交操作及各自滚动方式保持独立。

手机端他人“详细信息”由 `.profile-resume-view-social` 统一承担正文纵向滚动，角色战绩区与表格按内容自然撑高，避免资料、社交操作和摘要占满短视口后把列表压到零高。窗口标题仍留在正文外，支持普通标题与纸签标题；自己的履历及桌面布局保持既有滚动方式。

首页学生证进一步统一为铅笔描边与水粉手绘质感，包含挂钩、铆钉和卡套边缘；它作为木板容器的直接子元素挂在原左侧位置上方的木板上沿，使用挂点与轻投影体现垂挂。绝对定位显式清除旧 `grid-area: player`，避免父网格把证件挤到右上角；桌面与手机使用自适应宽度，内容网格预留垂挂空间，部员手册位于其右侧稍低处。

学生证在精细指针悬停时以挂钩顶端（素材的 `50.8% 2%`）为轴逆时针旋转 3°，使用 220ms 过渡；禁用及减少动态效果状态不旋转。`HomeStage` 通过 ResizeObserver 读取铭牌右缘和对弈入口左缘，将桌面手册中心定位在两者中点；窗口或容器尺寸变化时重新计算，仅写入手册的横向偏移变量，保留对弈入口与功能区位置；手机端手册左移 12px 并靠首行底部排列，首行垂挂预留缩短 20px，使手册、学生证和下方对弈入口更紧凑。

学生证姓名区扩展至卡片宽度的 62%，定位于卡片左侧 28%、顶部 74.5%，使姓名及装饰整体略靠右上；常规用户名采用桌面 18px、手机 13px，装备个性化铭牌时沿用相同字号，装饰尺寸单独缩放，避免用户名随装饰被缩小。超长用户名保留原有缩小或省略处理。

首页用户铭牌改为带完整金属挂扣的竖版学生证：采用暖白、浅绿与浅杏色几何学院卡面，右侧窄照片框通过共享立绘解析器显示当前出战角色及已装备服装；照片框使用双轴居中与 contain 显示，保留服装的构图缩放和偏移。下方姓名区复用 `UserIdentity` 展示用户名及当前装备的个性化铭牌背景、字体和动效，不附加称号、徽章、段位或积分。姓名装饰按桌面和手机分别缩放，并单独约束文字字号；未装备时回退普通用户名。点击仍打开履历，特殊剧情禁用状态保持；`home-student-id.css` 管理独立卡片几何与桌面、手机竖屏布局，避免旧横条铭牌样式干扰。


移动端对弈的技能/数值点击说明挂载到 `.app-shell` 浮层，避开玩家卡片与棋盘容器裁切，并保留主题和浮层顺序；竖屏对弈视口与操作滚动区预留右下阴影空间。引导误点提示统一为“请在黄圈位置落子”。房间页不显示关闭倒计时，也不再运行显示用秒级计时器；服务端 5 分钟关闭逻辑保持不变。
移动端剧情对弈引导的回复选项由专属按钮规则显式设置 `height: auto`，覆盖普通操作按钮的固定高度；长文本换行后自然撑高，保留现有最小点击高度和外层操作区滚动。

移动端竖屏首页六个功能图片按钮采用两列三行紧凑网格，每行至少 52px，按实际行高压缩留白，不再对第二、三行单独施加位移；`entries-utility-footer.css` 保留图片宽度和按钮动效。


普通校园主题对弈模式卡片只显示单行模式标题与匹配人数，背景英文完整显示，背景模式图标隐藏。规则不在按钮内展示：仅在宽度超过 768px 且具备精细指针悬停能力时，于鼠标旁显示规则浮窗，跟随移动并避让视口边缘；移出、点击、滚动、改变窗口大小或 Escape 关闭，移动端在卡片右上角提供独立的 22px 小 ⓘ（图标 16px），绝对定位、不改变卡片布局；点击切换规则浮窗，点击空白处关闭，不触发匹配。`mobile-adaptive/match-mode-title-layout.css` 负责最终布局，模式选择与陪练入口行为保持原样。
本文档是系统设计入口。详细设计已经按主题拆分到 `docs/system-design/`，修改架构、运行行为、资源体系、样式主题、部署方式或技术债时，应更新入口摘要或对应分篇，并运行 `npm run docs:system-design` 同步 HTML。

## 阅读顺序

普通校园主题主界面纸签窗口的关闭、刷新、回退等标题栏图标按钮统一为 36px 方形，同排文字按钮统一为 36px 高并保留文字所需宽度；绝对定位关闭按钮距顶部 6px、右侧 16px，增加按钮与窗口边框之间的留白。履历标题贴纸脱离文档流，定位容器保持窗口全宽以保留原始贴纸尺寸，右上成就、金币和关闭控件统一 36px 高、顶部对齐；不再为贴纸预留手机标题栏空行。

登录后的资源加载页在进度条下方显示带下划线的小字“（首次加载需要1-3分钟，请耐心等待哦~）”，复用现有加载状态文字样式；该提示仅用于登录后预加载入口。

普通校园主题的首页固定功能标题统一为纸签：浅色横线纸底、白色裁切边、细棕描边、右下角小折角与清晰投影，标题直接使用项目霞鹭字体导出透明 PNG / WebP，保留左上角越界与轻微倾斜，同时压缩旧标题栏留白、上提虚线与正文。`WindowTitleSticker` 集中处理原始标题、尺寸与加载失败回退，内容由内部区域滚动；商店、IRIS、动态名称和特殊剧情保持原样，共用资料卡与回放仅由首页入口显式启用。资源与窗口边界详见第 5、6 篇。

部员手册的角色区与装饰区以直线虚线分隔；装饰卡片复用角色卡片的硬阴影、悬停与按下反馈，采用 80px 正方形、10px 内边距和黑子左上/白子右下的纯图标布局，移除底部状态文字与勾号，保留可访问名称、选中、忙碌和禁用语义。`mobile-adaptive/modal-control-gutters.css` 为窄窗口的内容滚动区预留按钮阴影空间；玩家弹窗隐藏滚动条外观，继续保留原生滚动、触摸与键盘操作。

普通 Bright School 按钮配色由 `quality-base/button-color-roles.css` 与 `button-color-states.css` 统一：纸白用于次要操作，浅蓝用于入口与工具，蓝色用于选中标签，粉色用于主要确认，薄荷色用于领取或和棋等操作，淡红用于退出、删除、认输。两个 owner 只修改背景、文字/图标和边框颜色，保留现有尺寸、布局、阴影、动效及文案；禁用态悬停不切换为可用态配色。首页两端的 `logout-action` 与对局 `draw-action` 仅提供语义配色钩子。手绘图片入口、部员手册出战旗帜、已有履历/商店/招募/IRIS 专属配色、黑化与特殊决战及后台管理均保留原有视觉。美化不自行增加提示、统计或装饰性标签，约束记录于 `PRODUCT.md` 和前端按钮配色规范。

## 当前架构摘要

- 西格莉卡黑化决战保留“有效房间优先续接”的唯一房间语义；当账号仍为 `duel-active`、但房间快照已经失效时，第一次开始请求会把账号条件回退到 `awaiting-duel`、清空旧房间号，并通过 `special_room_reset` 把恢复后的篇章状态同步到客户端，玩家再次点击后才创建新决战，避免账号永久卡死或把新局伪装成旧局续接。
- 黑化决战在当前单进程服务器内全服最多存在一盘未结束房间，`preloading`、开场演出、正式对局、玩家断线等待和启动恢复后的持久化房间都继续占用名额，进入 `finished` 或被清理后立即释放。只有仍处于黑化篇章的登录用户能通过专用 Socket 事件查询该状态或观战；普通观战列表、黑化首页通用“观战”入口和房间号加入路径均不暴露特殊房。模式选择窗打开期间持续校准：本人有局显示“继续”，无局显示红色挑战，别人占用时显示浅黄色“西格莉卡？正在对局中。。。”并直接进入该局观战。空闲态点击挑战会先显示“本对局为高难度对局，用时为30分钟包干制，确定参与吗？”，确认后才进入既有预加载/创建流程，并保留挑战意图；挑战与观战竞态分别只退回黄色观战态或红色挑战态，不自动替用户改变意图。观战者复用人数上限、安全房间投影、只读聊天和实时演出；结果确认只离房回到仍打开的模式窗，不进入房主恢复剧情。挑战者与西格莉卡？各自使用 30 分钟包干且没有读秒，任一方超时即判负；智子单次搜索上限仍为 5 秒。黑化棋钟由最终主题 owner 保证标题/数字高对比，竖屏按“标签、时间、弹性进度条”横排并让进度条占满余量。
