## Scope and signatures

`HouseCharacterGrid` owns both ordinary and corrupted handbook strips; `LegacyHouseCharacterGrid` is no longer selected by the active handbook. `resolveHandbookPortrait(character, { itemEffects, user })` returns the effective source, costume style, dimensions and a fixed crop focal point. This is a handbook presentation adapter over `characterPortraitImageProps`, not a replacement for the shared portrait catalog. The former polygon-puzzle contract is superseded by the user's ordered strip requirement; the filename remains a historical reference.

`handbookStripPage(characters, page)` preserves input order, clamps the page and returns `{ pages, currentPage, roster }` with at most ten characters. `handbookStripArtStyle(portrait, size, { mobile, expanded, count, index = 0 })` preserves the portrait aspect ratio and keeps desktop width, height and vertical placement independent of preview state. Built-in `headWidth` and pupil `focal` landmarks align the eye line and frame the larger desktop bust. Its head target is `min(width / count * 1.35, height * .38)`, with handbook-only `desktopScale` visual corrections (Qiuyuan 1.1, Nabomo .91). Desktop framing interpolates a 50% resting face anchor to a 30% expanded anchor using one width-dependent calc expression. Shared HANDBOOK_STRIP_LAYOUT values (28px slant, 3px gap, grow 6) feed CSS variables and the helper: available track width is board width plus (count - 1) * (slant - gap). The expression is identical before/after preview; flex width alone drives image motion. Do not independently animate a changing percentage anchor, which can reverse direction mid-transition. Mobile framing alternates its portrait side by absolute catalog index (`currentPage * HANDBOOK_STRIP_PAGE_SIZE + index`) and keeps a headwear-safe expanded bust. Custom/costume sources retain shared resolver framing on mobile and for unregistered assets; registered desktop art uses the visible-body exhibition rule above. The owned mascot keeps its existing geometry. The pure-import `handbook-puzzle.css` entry delegates to bounded `handbook-strip-labels.css`, `handbook-strip-frame.css` and `handbook-strip-paper.css` owners in that order; motion inventory points to these concrete owners.
