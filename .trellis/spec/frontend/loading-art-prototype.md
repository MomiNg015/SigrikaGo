## Mask and geometry validation
`prepare-assets.py` derives the interior from the bulb ink contour. Save the result as **RGBA with zero alpha outside the chamber**, not a grayscale PNG: CSS image masks default to alpha, so an opaque grayscale image would fill the entire bounding rectangle. The mask must exclude the screw base and canvas exterior.

The selected sample uses `bulb-selected.png` with `bulb-selected-interior.png`. Regeneration selects that input when it exists, otherwise `bulb.png` with `bulb-interior.png`; always regenerate `bulb-geometry.js` from the same contour as the displayed outline. A restyled contour may move even if its canvas dimensions are unchanged, so reusing the old mask would leak fill at the boundary.

Puzzle images inside a fixed grid slot require `minmax(0,1fr)` tracks and `min-width:0; min-height:0` on the image. Intrinsic min-content sizing can enlarge the track beyond a percentage-height slot despite `object-fit:contain`, causing the board to overlap the cloud contour.

The supplied near-square board uses a fixed inner slot at left 27%, top 29%, width 44%, height 44% of the cloud canvas. Verify the painted `object-fit:contain` rectangle, including corners, against each animated raster's inner contour. Current measured minimum frame clearance is 13px at 390×844 and over 10px at 360×640.

Verify 0/50/100 percent, completion timing, reset, tip freeze, image slot and reduced motion. Check desktop 1440×900, portrait 390×844 and 360×640, and landscape 932×430. Budget the full character-image bounds above the tip; rotated ray boxes can create overflow even when their painted strokes remain inside the viewport.
