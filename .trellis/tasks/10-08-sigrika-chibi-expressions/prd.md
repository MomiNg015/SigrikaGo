# Sigrika chibi expressions

## Goal and scope
Apply the same accepted eight-expression delivery to the supplied Sigrika chibi sprite: original, happy, serious, surprised, worried, sad, angry, embarrassed. Produce an independent asset work package; no replacement of existing runtime story art.

## Requirements
- Source canvas 832 x 1216, exact original PNG retained.
- Recalibrate facial crop, part masks, skin samples and orange bang protection for this character.
- Deliver transparent PNGs, layered PSD, lossless full/256px avatar WebPs, overview and source-protection reports.
- Built-in image editing generates candidates; installed VN Sprite Expression Workflow assembles and independently verifies them.
- Validate a small initial set before expanding. Review final faces, full-body grid and allowed mask.
- Zero alpha and outside-mask differences; protected source hair remains exact.
- Update system-design entry and generated HTML.

## Acceptance
Eight distinguishable expressions, reproducible sources/prompts/configuration, exact original default, one visible PSD expression group, technical verification passed. User art review and future runtime integration remain separate.
