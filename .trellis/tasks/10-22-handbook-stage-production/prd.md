# 实装部员手册角色详情展示台

## Goal
将用户确认的第1版角色详情样板及全部后续修订接入正式窗口。

## Requirements
- 双色叠层立绘背景，交界采用浅主题色细边与短实阴影并抗锯齿；手机切口偏离竖直约30度。
- 放大并裁切既有阵营徽记，保留圆形底台；信息区使用项目网格纸背景。
- 技能卡保留厚阴影；派生卡错位叠在父技能下方，标题与正文分色；不用标签式圆角矩形。
- 移除获得途径；CV及简介悬停无下划线，简介左上为已有无外围短线的黑白棋装饰。
- 收音机放大并外伸右下，播放/暂停悬停不变色；关闭按钮中心位于右上纸角，悬停无额外外圈。
- 手机立绘左、姓名/CV右下；服装按钮32px、18px图标，位于立绘区左下6px，减少遮挡。
- 保留既有肖像解析、换装、语音、曲目选择、特性浮层、Escape和焦点返回行为。

## Acceptance Criteria
- [x] 正式组件在1440/800/390/360/320px及短屏可用，外伸控件和阴影在视口内，末段文案可完整滚动。
- [x] 长姓名、派生技、无音乐、换装与阵营无映射状态检查通过。
- [x] DOM、浏览器、lint/build及CSS相关检查通过，系统设计与对应spec同步。

## Implementation
在现有角色详情CSS owner内整合布局，按绘制层/内容/控件拆为有限大小文件。复用真实CharacterDetailDialog和已有公开阵营映射，装饰资源迁移到public/assets/ui。样板保留作为已确认参考。保留工作区其它并行修改，混合系统设计文档只提交本任务段落。
