# 赛事入场演出与说明完善

## Goal
修复吃子挑战赛入场对决演出，并补全赛事卡片说明及队际赛选人窗口信息。

## Requirements
- 吃子挑战赛首次进入 opening 阶段时展示现有双方立绘对决演出；素材失败或时间不足时保留普通提示。
- 吃子挑战赛和队际赛子卡片桌面悬停显示指定说明，移动端右侧信息角标点击显示同文浮窗。
- 队际赛选人三个 Round 标题下分别显示 `(0-40手)`、`(41-80手)`、`(81手-终局)`。
- 队际赛选人窗口在普通校园主题使用既有图片便签标题。

## Acceptance Criteria
- [ ] 首次吃子挑战赛双方图片可加载时显示 `.opening-duel`。
- [ ] 桌面悬停和移动角标均显示指定文案；卡片点击操作保持原状。
- [ ] 三个阶段手数显示正确，选人前后窗口布局稳定。
- [ ] 图片便签标题显示，有文本回退；测试和系统设计文档更新。

## Scope
复用既有开场演出、规则浮窗和便签图片生成器；不改变赛事规则、计分或其他窗口。
