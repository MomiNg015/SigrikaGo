# 第二套主题：浅灰工业终端

## Goal

参考《明日方舟》《明日方舟：终末地》的界面设计语言，为 SigrikaGo 制作独立第二套主题样板。用户已授权先制作主界面、对弈界面、部员手册，生产主题接入不在本轮范围。

## Confirmed requirements

- 本轮交付可切换的主界面、对弈界面、部员手册样板，桌面与手机竖屏同时验证。
- 用户明确要求保留现有校园风，将新风格放到第二套主题。
- 用户已选择“浅灰工业终端”：偏终末地，灰白底、黑色模块、少量黄绿强调，角色醒目。
- 移动端以竖屏为主；管理员界面不纳入玩家主题改造。
- 借鉴排版、层级、几何、状态反馈和角色构图，使用项目自己的角色与品牌素材。

## Repository findings

- `src/app/visualTheme.js` 已有主题注册、可用性、作用域和本地保存机制；目前仅 `bright-school` 可用。第二项 `club-standard` 为不可用占位，不是完整第二主题。
- `src/app/useAppShellTheme.js` 已隔离管理员主题。
- `src/styles/themes/shared/player-theme-tokens.css`、`player-theme-wiring.css` 已有共享变量和控件接线，但默认值及部分结构仍具有校园风特征，不能只改配色宣称主题完成。
- `src/styles/themes/_new-theme-template.css` 提供扩展模板；`src/styles/themes.css` 后加载移动适配，需核对主题作用域与最终覆盖。
- 首页图片按钮、纸面学生证与手册、窗口纸签、手绘书签需要主题专属表现；业务状态和操作回调宜复用。
- 已有 `docs/design-samples/startorch.html` 三种科技风探索及说明，但仅为隔离样板，不能视为正式主题或本轮已选方案。
- 参考本地 2026-10-09 首页截图和 2026-10-13 正式观战组件样板截图；未将存档截图等同于当前浏览器实时状态。

## Proposed visual language (not yet a shipped specification)

- 冷浅灰背景，黑白分区，黄绿仅突出主操作、选中和关键状态。
- 严格对齐、细分隔线、直角或小圆角、有限切角；避免无意义密集假数据与装饰文字。
- 大幅原有角色立绘作为大厅及角色详情视觉中心；Q版用于引导、小头像等适配位置。
- 正文与控件使用清晰中文无衬线，数值使用稳定的等宽数字布局。
- 对弈维持棋盘、当前回合、时钟、技能状态的阅读优先级。
- 手机单独重排，不缩小照搬横屏游戏的三栏界面。

## Open decisions before implementation

- 正式接入范围待样板反馈；本轮三个样板范围已确定。
- 第二套主题展示名称，以及是否沿用或替换 `club-standard` 占位 ID。
- 选定画面后的主题素材清单与布局分离方式。

## Acceptance criteria for a future implementation

- [ ] 校园主题的视觉与业务操作保持可用，第二主题可切换并保留选择。
- [ ] 新主题使用独立作用域，含弹窗、浮层与移动最终样式；管理员隔离保持。
- [ ] 同一账号、角色、对局和背包数据在两主题一致，避免复制业务逻辑。
- [ ] 代表性桌面及 360/390px 竖屏界面可读，无裁切和横向溢出。
- [ ] 明确加载、禁用、选中、错误及键盘焦点状态，支持减少动态效果。
- [ ] 更新设计文档并完成与变更相称的主题契约、构建及视觉验证。

## Out of scope for current research

- 生产代码、主题启用、默认主题切换、资源替换、后端和对局规则修改。
- 将公开参考图直接作为项目运行时资产。
