# 角色展示台清晰双色切面

## Goal
将第1版立绘双色底板改为几张同色底板错位叠放的感觉，交界清晰且有面与面的层次。

## Requirements
- 移除交界透明渐变与柔化过渡，使用边界清晰的连续实色层。
- 用户否定浅白亮面加窄侧边的装饰条方案；去掉白边，保留双色与移动端约30度切割方向。
- 用户随后给出父技能卡压在派生卡上方的截图作为明确参考：采用细墨边与短实阴影表达前后遮挡，双色底板做成两层叠放。阴影边界清晰、没有模糊。
- 仅调整已选样板1，保持立绘、控件、网格及正式界面现状。

## Acceptance Criteria
- [x] 桌面与手机竖屏实色边界视觉核验通过，覆盖两种角色主题。
- [x] 样板验证与截图同步，系统设计摘要及HTML同步。

## Technical Notes
只修改stage.css的两层背景hard stops：顶层保留现有角度与50%分割，用2px墨边界定前层；后方用4px无模糊实色阴影表达压叠关系。底色依旧为70%和30%角色色混合纸色。已有样板验证覆盖布局与交互；无需新增镜像CSS实现的测试或正式spec。

## Open Questions
无；按用户最新视觉反馈执行。

- 1440px桌面、390/320px竖屏截图核验，覆盖西格莉卡与爱弥斯主题。
- 样板ESLint、27组布局及6组交互通过，无API请求与浏览器脚本错误。首次导航加载超时，复跑通过。
- 系统设计HTML已生成，4项文档测试通过，diff空白检查通过。
- 无正式组件/API契约变更；仅更新样板自身说明，不修改共享spec。
