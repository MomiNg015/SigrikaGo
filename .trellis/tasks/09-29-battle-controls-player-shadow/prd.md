# 对弈五按钮与成员列表阴影修复

## Requirements
- 后续要求：header 房间号前缀改为星炬／标准／五子棋／人机／吃子赛／队际赛，手数标签只显示当前手数。
- 双方信息卡随回合切换棋钟按键效果：当前行棋方抬起并有阴影，非行棋方下沉且无阴影，桌面与竖屏一致。
- 用户明确要求常规对弈功能区固定保留弃手、数子、技能、和棋、认输五个按钮；规则不支持的操作原生禁用并置灰。
- 修复房间成员列表滚动区域裁切按钮右侧、底部阴影的问题，保留滚动能力。
- 同步系统设计文档；保留其他未提交工作。

## Acceptance Criteria
- 陪练、吃子挑战、标准围棋、五子棋的常规操作区均有五个按钮，不支持的操作不可点击。
- 成员列表首尾与滚动末端均保留阴影空间；桌面与手机竖屏布局可用。
- 相关测试、lint、构建通过，浏览器核对完整样式层叠。

## Out of Scope
- 不改变棋局规则、观战回放、死子确认及教学专用操作区。

## Technical Approach
- ActionBar 将条件挂载改为 disabled 条件，沿用现有灰色禁用样式。
- room-people-table 在滚动区域内部预留阴影与悬停位移空间。

## Verification
- Header/PlayerInfo/RoomScreen 定向测试 62 通过、1 个既有标题栏列数断言失败；lint、构建、构建后 CSS 检查通过。
- Chrome 完整样式组件验证：1280、390、360px 宽度下黑白回合互换，当前方 3px 硬阴影及零位移，非当前方无阴影且右下位移 3px，卡片宽度不变且无页面横向溢出。桌面与竖屏截图已检查。
- 新增阴影复用 bright-border；设计 hook 报告的颜色均为该文件未改动的既有配色，保留原样，不添加忽略规则。
- ActionBar 20 项、RoomPeopleList 3 项测试通过；RoomScreen 37/38 通过，失败为原有标题栏三列断言，HEAD 样式已为一列，与本次修改无关。
- lint、生产构建、构建后 CSS 检查通过；系统设计 HTML 已生成。
- Edge 完整样式层叠组件验证：1280x800、390x844；两名玩家与十名成员滚动末端，右侧 6px、底部至少 6px 留白覆盖 3px 硬阴影。五按钮及和棋灰色禁用态截图已核对。
- 设计 hook 的旧颜色、圆角及测试源码提示属于未变更的历史样式/测试内容，不是本次 padding 与 disabled 修改引入的设计问题；不改既有视觉设计、不添加忽略配置。
- 全量测试：2694 项中 2686 通过、8 失败，分布于社交回放、履历/手册、商城、CSS 债务/主题及上述 RoomScreen 断言。本次 ActionBar 与 RoomPeopleList 测试全部通过；未扩大范围修改其他模块。
