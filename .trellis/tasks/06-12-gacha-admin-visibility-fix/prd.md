# 后台扭蛋管理窗口可见性修复

## Goal

修复后台管理里的扭蛋管理编辑窗口部分内容不可见的问题，让管理员在配置扭蛋池、奖项、概率和保存/删除按钮时，所有内容都能在窗口内访问。

## Requirements

* 后台扭蛋管理的编辑窗口/抽屉在内容超过视口高度时必须可以滚动。
* 奖项列表、底部取消/删除按钮、保存按钮不能被固定容器裁掉。
* 奖项行里的数量和概率输入必须直接显示字段名和单位，避免管理员看到裸数字。
* 装饰奖项资源必须同时包含内置棋子装饰和后台自建装饰。
* 修复应保持现有后台视觉风格，不改变扭蛋池业务逻辑。
* 修改后同步更新 `docs/system-design.md`。

## Acceptance Criteria

* [ ] 扭蛋管理编辑窗口在桌面高度较低时仍能看到并操作底部按钮。
* [ ] 多个奖项行不会撑破抽屉导致不可访问内容。
* [ ] 数量输入显示数量单位，概率输入显示 `/10000` 概率单位。
* [ ] 装饰下拉至少包含内置的两个棋子装饰，并保留后台自建装饰。
* [ ] 其他后台管理 tab 的抽屉布局不出现明显回归。
* [ ] 相关测试、构建和系统设计文档渲染通过。

## Definition of Done

* 代码变更聚焦在后台布局/样式和必要测试。
* `npm test` 或相关目标测试通过。
* `npm run build` 通过。
* `npm run docs:system-design` 通过。
* 提交代码并记录 Trellis 收尾。

## Technical Approach

优先复用现有后台抽屉模式，检查 `.admin-crud-drawer`、`.admin-character-form` 和 `.admin-gacha-prize-row` 的高度、overflow、grid 列宽和响应式行为。根因确认后只调整可滚动容器与扭蛋奖项布局，不引入新的弹窗框架。

## Out of Scope

* 不改扭蛋抽奖概率、后端接口或资源选择业务逻辑。
* 不重做后台管理整体视觉设计。
* 不处理与当前可见性无关的后台功能问题。

## Technical Notes

* 用户反馈：后台管理扭蛋管理的窗口会有部分看不见。
* 相关文件预计包括 `src/admin/AdminGachaPools.jsx`、`src/styles/admin.css`、`docs/system-design.md`。
