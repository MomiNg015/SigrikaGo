# 生成并接入黑化西格莉卡与玩家 Q 版立绘

## Goal

基于西格莉卡原始立绘与项目现有 Q 版角色立绘语言生成候选，将用户选定的西格莉卡图 4 接入为所有黑化西格莉卡立绘槽位的唯一正式资源，并将用户选定的玩家第三版围棋站姿接入所有黑化篇章中的玩家立绘槽位。

## Requirements

* 生成 4 张独立候选，不把多个姿势拼在同一张设定表里。
* 西格莉卡身份必须清晰：橙色多段辫发、白色尖角头饰、原服装的白/紫/金结构均应保留可辨识的简化关系。
* 黑化处理采用深炭黑、冷灰、暗紫与少量失真血红，不把角色改成完全不同的新衣装。
* 双眼必须为清晰、饱和的红色；表情冷静、疏离、压迫，禁止微笑、卖萌、哭泣或夸张暴怒。
* 姿势彼此不同，但都保持克制冷峻，不增加武器、翅膀、角、宠物或文字。
* 画风对齐项目现有 Q 版角色：约 2 头身、大头小身、圆润短肢、干净粗外轮廓、柔和赛璐璐明暗、简化但可读的服装纹样。
* 输出为 1:1 单角色居中构图，四周留安全边距，最终转为透明背景 PNG。
* 用户选定图 4 后，将其纳入角色立绘规范化流水线，运行时统一消费规范化 WebP。
* 黑化状态下，家园角色卡/详情、剧情播放器、特殊对局玩家卡、假技能爆发演出与回放必须使用该正式立绘；普通西格莉卡和其他角色不变。
* 黑化正式立绘优先级高于西格莉卡已装备服装及其构图参数，避免同一黑化状态混用普通/服装立绘。
* 玩家替身为无法区分性别的全黑 Q 版全身站姿，带白色描边，一手在脸侧捏持围棋棋子、另一手横于身前。
* 黑化通用加载页沿用既有角色立绘槽位显示玩家替身，并继续隐藏普通角色立绘及角色专属加载台词；特殊对局与回放的玩家信息位显示同一玩家替身。
* 结果弹窗没有玩家立绘槽位，继续保持无立绘，不为接图额外改版。

## Acceptance Criteria

* [x] 4 张 PNG 均为单独文件，具有 alpha 通道且四角透明。
* [x] 4 张都能一眼识别为西格莉卡，并且不是普通西格莉卡仅换红眼。
* [x] 每张双眼均为红色，表情和姿势均冷峻。
* [x] 角色比例、描线、明暗与项目当前 Q 版角色立绘属于同一视觉家族。
* [x] 没有文字、水印、场景、投影、绿幕残边或新增设定元素。
* [x] 图 4 已成为共享资源目录中的唯一黑化西格莉卡正式立绘，并生成符合项目立绘合同的 900×900 WebP。
* [x] 家园、剧情、特殊对局玩家卡、假技能演出与回放均通过共享常量或共享解析器消费该资源。
* [x] 黑化资源在登录态与特殊对局预加载边界中按需加载，普通状态不会额外加载。
* [x] 普通西格莉卡、服装立绘和非西格莉卡角色的解析行为保持不变。
* [x] 玩家第三版已保存为共享 PNG 源并生成符合项目立绘合同的 900×900 WebP。
* [x] 黑化通用加载页、特殊对局玩家信息位与回放玩家信息位统一消费玩家第三版；普通加载页和普通对局不变。

## Definition of Done

* 保留本次 Mode B 结构化提示词，方便后续复刻与单项迭代。
* 逐张检查身份、红眼、表情、姿势、裁切与透明边缘。
* 将最终候选保存到项目工作区的独立输出目录，不覆盖现有角色资产。
* 将选定的西格莉卡图 4 与玩家第三版保存为可追溯 PNG 源，并将规范化 WebP 接入运行时资源目录、预加载表与测试合同。

## Technical Approach

使用 `gpt-image-2` Skill 的 Mode B 提示词工程流程，向 Codex 内置图像生成器分别提交 4 个姿势变体。输入图中，原始西格莉卡全身图负责角色身份与服装细节，现有西格莉卡 Q 版负责角色简化规则，其余代表性 Q 版立绘负责统一比例、描线、眼睛、明暗和服装信息密度。先生成纯色绿幕版本，再使用 ImageGen Skill 自带的 chroma-key 工具转换为透明 PNG。

## Decision (ADR-lite)

**Context**: 用户需要多张候选，并要求结合当前角色立绘画风。

**Decision**: 采用 4 次独立生成而不是一张四宫格；所有候选共享同一身份/画风约束，只改变姿势与局部黑化节奏。用户选定西格莉卡图 4 后，以共享资源常量与共享角色立绘解析器为唯一接入口；用户选定玩家第三版后，也以独立共享资源常量接入通用加载页和 `PlayerInfo`，不在各 UI 中复制路径或依赖服务端空头像字段。

**Consequences**: 单图清晰度和后续挑选、重绘、接入都更好；运行时所有黑化立绘保持一致，且黑化期间不会被服装覆盖。新增资源必须随角色立绘规范化与预加载测试共同维护。

## Out of Scope

* 本任务不制作动态立绘、Live2D、表情差分或三视图。
* 不替换普通西格莉卡立绘，不改变黑化篇章、对局规则、服务端角色数据或后台配置。
* 不给原本无立绘槽位的结果弹窗或纯旁白剧情节点新增立绘布局。
