# 对局结算星炬券奖励

## Goal

确认真实对局结束窗口使用用户选定的星炬券图标，并提供桌面和手机截图。

## Requirements

- 复用已裁切的 827×746 星炬券，保持等比显示。
- 胜利、失败、零奖励显示服务端原奖励值；不修改奖励规则。
- 奖励项具有完整的可访问名称，保留返回棋盘与退出房间功能。
- 复用真实 ResultModal 与完整生产 CSS 截图，不以静态仿稿代替。
