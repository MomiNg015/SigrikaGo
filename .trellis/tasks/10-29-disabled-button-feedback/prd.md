# 统一不可用按钮反馈并暂停履历入口

## Goal
履历成就和个性化使用真正的禁用状态；项目内不可用按钮触发一致的既有音效与晃动，并始终阻止业务操作。

## Requirements
- 复用 PROFILE_CUSTOMIZATION_ENABLED，当前为 false，两个入口保留原位置并呈禁用状态。
- 全局覆盖 native disabled、aria-disabled 和已有锁定卡片，专用音效的 none 标记只抑制可用按钮确认音。
- 鼠标与触摸每次按下反馈一次，键盘/辅助技术点击同样有反馈；不执行禁用动作。
- 反馈不被主题 important 动画/位移重置覆盖，保留原 transform；快速重复按下重新开始，卸载清理。
- 减少动态效果使用轻微亮度变化；沿用音效音量/静音设置。

## Acceptance Criteria
- [x] 履历两个入口禁用且回调不执行。
- [x] 原生/ARIA 禁用、子元素、专用音效标记、键盘、连续点击及清理测试通过。
- [x] 浏览器在完整 CSS、桌面和竖屏下验证位移及无业务操作。
- [x] 项目检查逐项通过（全量中唯一旧 CSS 清单失败已修正并定向复测），设计文档与生成 HTML 同步。

## Scope
需求已由用户明确指定，按现有效果扩展，无待确认产品决策。不新增音效、启用成就服务或改变业务禁用条件。不吸收工作区已有修改。

## Technical Approach
扩展 InteractionFeedback 全局捕获；反馈期间临时设置 translate/filter 内联优先级，以避开主题静态按钮重置，结束恢复原值。保留原动效节奏和 1063ms 时间。原生 disabled 保留其浏览器语义。
