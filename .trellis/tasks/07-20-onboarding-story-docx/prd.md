# 入门者剧情按 Word 文档重制

## 目标

仅重制新手引导中“其实我完全不会下围棋...”分支。首次进入对弈前的既有剧情保持不变；进入棋盘后完整采用 `sigrikago入门剧情.docx` 的台词、选项、七个 13 路棋盘局面和操作顺序。“略懂一些”和“我超强的哦!”分支及其共享节点必须保持不变。

## 剧情要求

- 删除当前初学者“四章课程”子树，按文档顺序实现气、提子/禁入点/打劫、真假眼/死活、围空/数目、开局效率及技能演示。
- 精确保留文档台词、选项顺序、占位符和明显笔误，只按说话人拆分节点。
- 固定“用户：”台词用单选回复记录进对弈聊天；多选题错误答案循环回题目。
- 仅短反应和动作节点自动推进；长教学文本与剧情段落手动继续。
- 选项切换等待 0.2 秒；NPC 动作前约 0.7 秒、动作后 0.4–0.6 秒；正常换盘保留 3 秒加载和 0.8 秒看盘；答错局面立即静默复原。
- 不引导的落子不显示目标圈；只对 L9 和技能目标显示引导。
- 第一段对弈结束后回到剧情，再用独立节点复制现有 `story-51` 棋盘，完成西格莉卡 F3 技能、黑棋 G4、达妮娅 F5 技能和文档结尾。

## 运行时与数据

在现有剧情 JSON 节点上增加可选字段，不新增节点类型或数据库表：

- `targetHighlightEnabled`，默认 `true`。
- `wrongMovePointId`，留空表示任意非正确落子。
- `wrongMoveNextNodeId`。
- `applyWrongMove`，默认 `false`。
- `boardSetupLoadingEnabled`，默认 `true`。
- `boardSetup.lastMovePointId`，只提供初始末手显示标记。

错误落子分支支持：普通错误只提示并重试；A1 题允许错误实际落盘，随后西格莉卡 A4 提子并静默复原；B11 题只对 D11 实际落盘并由白棋 B11 反击，其他错误只显示指定提示。

## 编辑与兼容

- 服务端校验、后台节点表单、流程图可达性、预览路径、Excel 导入导出同步支持新增字段。
- 旧脚本及缺少新增列的 v1 工作簿保持默认行为。
- 后台仅在对应节点类型渐进显示设置，不增加新工作台面板。

## 验收

- 快照锁定七个棋盘、末手标记、全部文案与选项，草稿和发布版一致。
- 规则测试覆盖 D9、L9、A1、B11、M13、J3/L3、F3/G4/F5 及错误恢复。
- 运行时覆盖目标圈开关、特定错误分支、错误落盘、静默复原和末手标记。
- 后台/API/Excel 覆盖保存、发布、预览、流程图分支及旧工作簿兼容。
- 回归断言另外两个水平选项及共享节点完全不变。
- 验证桌面与竖屏移动端，运行针对性测试、`npm run docs:system-design` 和 `npm run check`。
