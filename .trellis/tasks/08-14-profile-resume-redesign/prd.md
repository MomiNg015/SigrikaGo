# 履历与他人详细资料界面重设计

## 目标

以“现代学院档案”为统一视觉方向，重构自己的履历与他人详细资料，使身份、模式战绩、最近结果和角色成绩具有一致的信息层级，同时严格区分自我管理操作与社交操作。

## 范围

- 抽取共享 `ProfileResumeView`，由 `ResumeModal` 与 `UserProfileCard` 复用。
- 统一身份页眉、固定顺序的模式页签、四项摘要、最近十盘和角色成绩表。
- 接入共享 `ModalDialog`，保留 Escape、焦点循环、关闭后焦点恢复与嵌套弹窗优先级。
- 重整现有履历/资料 CSS owner，删除被新共享结构替代的重复样式。
- 更新相关 DOM、状态、CSS 合同测试与系统设计文档。
- 不修改数据库、服务端接口、主题素材与既有名牌动画合同。

## 已确认的界面与行为

### 通用结构

- 本轮范围选择 C：行为与视觉完整重做；不仅调整表面样式，也修正模式异步状态、嵌套错误归属与危险操作确认。
- 桌面壳层选择 A：近全屏外壳，内部档案主体居中并限制在 1080–1180px；当前实现上限为 1160px。
- 桌面为近全屏学院档案窗口，身份页眉是唯一主视觉。
- 内容以留白和分隔线组织，减少厚边框、圆角卡片和重复阴影。
- 所有页面和视口的模式页签 DOM 顺序固定为：`星炬 → 标准 → 五子棋`。
- 页签数据来自 `modeOrderedEntries()`，渲染层用显式模式 ID 顺序锁定。
- 摘要固定为段位、积分、总对局、胜率；胜率由已有胜场和总局数派生。
- 最近十盘沿用现有结果标记与语义。
- 角色成绩固定表头：角色、对局、胜、负、和、胜率。
- 模式切换时保留旧内容至新数据返回，并阻止重复请求。
- 保留 Bright School 色板、窗口标题字体、名牌动画、角色特殊立绘及短硬影合同。

### 自己的履历

- 身份操作区只显示“个性化”。
- 不显示点赞、加好友、举报。
- “成就”保留为页眉独立次级入口。
- 页眉右侧严格依次为：成就、金币、关闭。

### 他人详细资料

- 身份操作区显示：点赞、加好友、举报。
- 点赞沿用现有数量、今日状态和请求中状态。
- 已是好友时显示“已是好友”并禁用；查看自己时相关社交操作禁用。
- 举报保留危险语义、请求中状态和现有举报弹窗。
- “加入黑名单”保留在底部低优先级关系操作区，不并入三个身份主操作。
- 对局回放入口保留。

### 竖屏

- 单列布局；摘要为 2×2。
- 角色成绩保留一行六列的可扫读表格，不把单个角色拆成上下两层，不换行且不产生横向滚动。
- 主要交互满足最小触控面积，窗口遵循安全区与移动端阴影边距合同。

## 非目标

- 不新增或修改 API、数据库字段或服务端逻辑。
- 不替换项目素材，不把生成探针作为资产。
- 不复制 Blue Archive、HoYoLAB 或 OP.GG 的品牌元素。
- 不重构履历与资料之外的房间或对局界面。

## 验收标准

- 两类页面页签文本和 DOM 顺序均为“星炬、标准、五子棋”。
- 自己的履历身份区只有“个性化”，页眉仍可打开“成就”。
- 他人资料身份区有点赞、加好友、举报且没有个性化；底部仍可加入黑名单。
- 好友、自身、已点赞、点赞请求中和举报请求中的按钮文案与禁用状态正确。
- 零对局、无最近战绩、无角色战绩、长名牌、多角色列表和模式接口失败均有稳定呈现。
- ModalDialog 的 Escape、焦点循环、关闭后恢复焦点和嵌套弹窗优先级不回退。
- 1440×768、1600×900、1920×1080 与 360×800、390×844、412×915 无关键遮挡或横向溢出。
- profile/modal DOM 测试、CSS 合同测试、构建、文档生成和 `npm run check` 通过。

## 视觉回归补充（2026-08-24）

- 履历头像和角色战绩头像使用独立裁切层；服装缩放、位移和特殊立绘不能越出头像框，连携徽章保持在裁切层外可见。
- Bright School 最终主题层必须明确重置终端/HUD 对角色战绩表的字体、行底色、切角、阴影和文字颜色污染，同时不得影响部员手册的 `.character-record-row` 合同。
- 桌面摘要、最近十盘与角色战绩行增加稳定的垂直节奏；窗口底部操作和列表末项在最大滚动位置完整可见。
- 360×800、390×844、412×915 继续使用单一正文滚动区，角色战绩行有足够触读间距且无横向溢出。
- 视觉色板收敛为冷白纸面、深墨文字和克制的粉蓝薄荷强调，不改变 Bright School 的语义色和身份。

## 第二轮精修反馈（2026-08-24）

- 履历主头像与角色战绩头像中的实际立绘必须在头像框内水平、垂直居中，统一占立绘区域约 70%；资料页不沿用服装在其他场景中的放大和偏移构图。
- 移动端角色战绩恢复为一行六列：角色、对局、胜、负、和、胜率；表头和每条记录都保持单行，角色名允许末端省略但整条记录不得换层。
- 模式页签拥有独立的上下留白和清晰选中指示，不沿用通用 Bright School 厚阴影、下压缩放与满底粉色按钮样式。
- 自己的履历和他人详细资料都把“对局回放”放在“最近十盘”标题行右侧，并保持水平居中对齐。
- 他人详细资料底部只保留低优先级“加入黑名单”操作，不显示“关系操作”标签。
- 视觉方向改为克制的现代学院档案：取消大面积蓝粉渐变和互相抢色的操作按钮，以干净纸面、细分隔线、单一粉色选中指示和更稳定的 8px 间距节奏建立高级感。
