# 重做西格莉卡角色专属手绘用户名铭牌（耙耙柑日轮版）

## Goal

把当前偏通用的橙紫能量铭牌重做为能够直接联想到西格莉卡的手绘插画铭牌。保留舒展的横向结构、清晰的用户名安全区和资产专属动效，但视觉语言改为温暖、认真、带有日光与探索感的角色叙事。

## Requirements

- 继续使用 `reward-sigrika-spark-100-wins-nameplate` 资产 ID、原图片 URL、`1125×240` 透明 PNG 与 `150×32px` 基础槽位，不改后端或数据库。
- 画面采用精致的手绘水粉 / 彩铅质感，不使用赛博霓虹、电竞金属、通用魔法徽章或写实角色头像。
- 用户已从概念稿中确认“耙耙柑日轮”方案：视觉锚点使用白紫金配色、太阳般展开的罗伊符文、耙耙柑果实 / 橘瓣、鲜绿叶片和气动风痕；禁止出现头发、发辫、发带、丝带、绳结或任何近似毛发的装饰。
- 构图保持“左侧识别核心＋中段用户名条＋右侧故事收尾”：左侧为日光符文和紧凑柑橘装饰，中段为低干扰的深紫手绘底，右侧以青紫风尾、星点和小橘瓣收尾。
- 不在底图中烘焙用户名、角色名、英文字母或品牌标志；用户名安全区约为 28%–88%。
- 动效由霓虹能量改为插画质感：日光符文与果实高光缓慢呼吸，青紫风尾只在自身区域轻微漂移，纸面星点错峰闪烁；不再使用明显的整圈机械旋转或穿过整段用户名的强扫光。
- 保持浅色高对比文字、合法用户名完整显示、历史超长用户名省略，以及 `prefers-reduced-motion` 静态降级。
- 普通图片铭牌、称号、独立徽章和其他展示场景语义不变。
- 接入成品前已产出多张互不重复的手绘概念图供用户选择；用户最终确认耙耙柑日轮第一版作为正式素材。

## Acceptance Criteria

- [x] PNG 为 `1125×240` RGBA，四角透明，主体覆盖足够高度且没有色键边缘。
- [x] 缩小到 `150×32px` 后仍能辨认日光符文、耙耙柑 / 橘瓣和右侧青紫风尾，不依赖细小文字表达角色。
- [x] 视觉为手绘插画感，不像电竞铭牌、UI 渐变条或通用奇幻徽章。
- [x] 四版方案均不出现头发、发辫、发带或毛发状装饰。
- [x] `moming`、`Alice_12`、4 个中日韩字符完整显示，历史超长名省略。
- [x] 1440×900、1024×768、375×812 无横向溢出、相邻统计区覆盖或点击遮挡。
- [x] reduced-motion 下停止呼吸、风带与闪烁，仍保留清晰的静态手绘高光。
- [x] 聚焦测试、CSS 合同、资源预加载测试与 `npm run check` 通过。

## Technical Approach

将用户确认的耙耙柑日轮概念图转为纯色色键源并本地去背；保留左右插画端点，通过只延长中部深紫安全区的九宫格处理匹配 `1125×240`，避免把圆形日轮或果实横向拉伸。现有 `UserIdentity` 三层结构与资产 ID 选择器不变，只调整该资产 owner 的色彩、效果层几何和关键帧，让运行时动效与新插画语言一致。同步更新测试、Trellis 规范和系统设计。

## Decision (ADR-lite)

**Context**: 当前铭牌虽然尺寸已经舒展，但橙紫能量核心、整圈旋转和扫光更像通用电竞装备，没有呈现西格莉卡的学生、符文解读者、昭日者候补和观鸟爱好者身份。

**Decision**: 用“日光符文＋耙耙柑果实 / 橘瓣＋鲜绿叶片＋青紫风尾”作为角色专属图形语汇，明确排除头发、发辫和丝带类装饰；动效从机械能量转为日光呼吸、果实高光、局部风尾漂移和星点闪烁。

**Consequences**: 识别度将来自角色特征而非亮度堆叠；需要在最终 32px 高度下验证图形简化与文字对比，避免手绘细节缩小后变脏。

## Out of Scope

- 不绘制完整角色肖像或复制官方立绘。
- 不修改数据库、奖励条件、后端资产字段或其他铭牌。
- 不改首页学生证、独立徽章、称号和通用 `UserIdentity` DOM 结构。
