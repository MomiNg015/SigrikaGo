# 西格莉卡角色视觉语言研究

## Sources

- 用户提供的库街区角色档案：<https://wiki.kurobbs.com/mc/item/1478089902761410560>
- 官方《鸣潮》3.2 版本说明：西格莉卡是星炬学院学生、罗伊符文共鸣者，气动属性、臂铠武器，为成为合格昭日者而全力以赴。
- 角色档案与故事页：共鸣能力为“语义解现 / True Name Manifestation”，擅长解读符文频率并把意义显现为力量；档案反复使用太阳、光、星、风与符文展开的意象。
- 珍贵之物与日常：记录生活与思考的日记、充满速写和笔记的观鸟手账、母亲缝制并装有糖果与发卡的小袋。
- 官方 / 图鉴立绘观察：橙色长发编辫、紫色丝带、白紫金服装，整体气质明亮、认真而亲切。

## Character synthesis

- 身份：星炬学院学生、罗伊族昭日者候补、符文解读者。
- 能力：语义解现；符文不是平面符号，而会像小太阳一样展开并释放意义与力量。
- 性格：认真、努力、对自己要求过高，但仍保持好奇、温暖与帮助他人的本能。
- 日常：喜欢观鸟、记录、拍照式的瞬间感；“三、二、一——茄子”体现轻快亲近的一面。
- 色彩：发色橙 / 琥珀，服装紫 / 白 / 金，气动可用低饱和青绿作为很小的空气高光，不应压过日光主色。

## Nameplate translation

- 左侧识别核心：手绘的太阳符文、学院印章或拍照快门，不使用通用宝石、字母徽章、头发、发辫或发带。
- 中段文字区：深葡萄紫的水粉笔触，边缘保留不规则纸张 / 颜料轮廓；中部纹理克制，保证用户名清晰。
- 右侧收尾：一缕气动风带带出金色星点，落到手账纸角、铅笔速写小白鸟或羽毛形状，表达学生与观鸟兴趣。
- 动效：太阳符文微呼吸，风带横向掠过，星点错峰闪烁；避免整圈机械旋转和强烈霓虹扫光。

## Avoid

- 完整角色缩略头像：32px 高度无法保真，也容易与独立徽章争夺视觉层级。
- 电竞金属、赛博霓虹、硬边渐变、通用魔法阵、字母徽章。
- 把角色名、成就名或品牌标志烘焙到图片。
- 过多细线符文或高频纸纹：缩小后会污染文字安全区。
- 任何头发、编辫、发带或毛发状飘带：离开角色肖像语境后会变成不明装饰。
