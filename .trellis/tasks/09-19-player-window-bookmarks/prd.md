# 推广玩家窗口左侧手绘书签选项卡

沿用用户已确认的履历方案：手绘纸边、霞鹜字体、2.5px 不随缩放变细的外轮廓、插入窗口边框的接缝，手机使用较宽紧凑竖排标签。

## 范围

- 设置、成就、排行榜、观战、好友、首页入口的玩家详细资料、公告、招募窗口接入共享组件。
- 检查商城和扭蛋的实际入口：仅现行可用选项卡接入，不为已停用组件新增功能入口。
- 保留数量、未读提示、图标、数据请求、原按钮回调、加载禁用和独立 Suspense 窗口边界。
- 常规校园主题启用；黑化、其他主题、对局功能栏、后台保持原行为。
- 窗口内部拥有滚动区域，外部书签独立可滚动，短屏/长标题不能截断入口。公告手机详情与列表切换保持正常。

## 验证

组件及实际窗口 DOM 回归；桌面与 320×568 / 390×844 窄屏视觉、长内容滚动、嵌套窗口和主题回退；运行相关测试、lint、build、文档生成和 CSS 合同检查。
