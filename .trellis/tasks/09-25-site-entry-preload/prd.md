# 进站预加载登录与加载页资源

## Goal
打开网站后先显示轻量加载页，准备登录／注册与登录后加载页所需公共资源，再挂载原有应用。

## Requirements
- HTML 首屏即显示校园配色的纯 CSS 进度条，不依赖角色图、字体文件或 React 完成加载。
- 加载公开角色目录、站点设置（Tips／角色加载文案）、所有公开角色及内置角色默认立绘（包括猪小仙）、登录吉祥物、加载条橘子和相关字体。
- 公共资源并发有界、单项超时跳过；接口失败使用内置目录与设置，不能永久挡住登录。
- 预加载结果直接供应用首帧使用；已有登录会话继续原来的恢复流程，不清除 token。
- 保留登录后账号资源预加载；不在进站阶段加载角色语音、音乐、商品和对局特效。
- 页面代码加载失败显示刷新重试入口；手机竖屏与桌面均无横向溢出。
- 同步系统设计与生成 HTML，保留未提交的莫宁语音变更和本地图片。

## Design
用户已选择极简进度条：纸白底、深棕正文、浅蓝进度填充；只显示“正在准备页面…”及百分比。无装饰图，不增加强制等待时长。

## Acceptance Criteria
- [x] 登录之前能看到进站加载状态，资源准备完毕才显示原登录表单。
- [x] 所有默认立绘、Tips、登录图与橘子图加载且成功立绘复用就绪缓存。
- [x] 失败与超时不会卡住；应用代码失败可重试；已有会话不被改变。
- [x] 单元与浏览器测试覆盖进度、完成顺序、失败、桌面和竖屏。
- [x] 更新系统设计与对应规范。

## Technical Notes
入口为 index.html 与 src/main.jsx。复用公开目录、站点设置、图片预加载及立绘就绪缓存。纯 CSS 首屏样式内联在 HTML，避免样式与应用包尚未下载时白屏。原应用挂载后用预加载公开数据初始化。
