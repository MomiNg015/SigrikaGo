# 正式接入观战纸卡与灰色结束状态

## 用户已确认

按上一轮已通过的观战样板实装。额外要求：已结束对局的卡片背景为灰色。

## 范围与验收

- 正式 `WatchModal` 使用纸卡、厚阴影、悬停抬起／按下下沉；已结束卡片为可读的浅灰，悬停和按下继续保持灰色语义，不禁用原观战入口。
- 搜索与好友纸框一致，无额外焦点边框，不增加按钮，继续输入即本地筛选。
- 保留所有原字段、共享头像和身份、刷新／错误恢复、房间准入、键盘操作及关闭行为。
- 手机每场一张卡，长名字完整换行；列表按可用空间停靠完整卡片，保留阴影余量。
- 样板改为正式组件预览，移除重复样式／测量逻辑。
- 回归桌面、800px、390／360／320px、短竖屏、多房间／长名字、实时搜索、灰色结束状态的常态／悬停／按下、滚轮和触摸。
- 同步观战规范、系统设计入口／主题分篇并生成 HTML；保存截图与测试证据，按范围提交。

## 技术决策

复用生产 `WatchRoomRow` 的 `finished` 类。将样板测量 hook 移入 `src/modals/watch/` 并直接绑定列表 ref，补充缺失布局／观察器守卫和清理。仓库 hook 只测固定最小行高，不用于观战动态名称高度，避免扩大无关公共抽象。更新现有两个观战 CSS owner；搜索与纸卡材质独立为一个小 owner，防止单文件超过 6000 字节。按确切增量记录 CSS debt，不吸收已有未提交的履历等修改。

## 开放问题

无。用户已经选定样板并授权实装。
