# 队际赛模式

## Goal

新增双方各选三名已拥有角色、按固定顺序接力完成同一盘棋的队际赛。grill-me 需求已确认，包含最终补充的逐阶段己方出战语音；按用户「开始实现」指令落实业务代码并验证。

## Confirmed requirements

- 点击队际赛，选择自己拥有的三个角色并决定出场顺序，确认后开始匹配，匹配成功进入队际赛对局。
- 阵容按点击角色的先后顺序填入 1、2、3 号位；再次点击已选卡片取消选择，重新点击后排到末位，不提供左右调整按钮，最后点击「开始匹配」。
- 记住上次选择的三人阵容及出场顺序；再次进入时自动填入，允许修改，仍须点击「开始匹配」才入队。
- 可用角色不足三名时，点击入口 toast 提示「需要至少拥有3名部员才能参加」。
- 对局分为 Round 1、Round 2、Round 3：第一角色负责 1–40 手，第二角色负责 41–80 手，第三角色负责第 81 手起至终局。
- 阶段计数沿用现有全局 moveNumber：双方普通落子、停一手、消耗手数的技能和额外落子均计入；第 40 / 80 手为换人阈值。
- 若到达第 40 / 80 手时旧角色仍有技能连下，允许旧角色完成剩余连下后，双方再同步换人并播放下一阶段五秒演出；旧角色可因此超出名义手数区间。
- 换人延迟不顺延后续阈值：即使第一阶段在第 43 手才结束，第二阶段仍以全局第 80 手为界；该节点若仍有连下，同样待连下完成后换人。
- 角色退场后，已经施加在棋盘上的持续效果保留并按原规则正常结束；退场角色不再触发新的技能或被动，允许跨角色接力配合。
- 三名角色的技能使用次数各自独立，每名角色登场时拥有自己完整的技能次数；前一名角色的消耗不影响后续角色。
- 「禁先」解锁状态每阶段重置：必须由对手当前角色在本阶段成功发动主动技能后，己方具有「禁先」的技能才能发动；不继承前一阶段的解锁状态。队际赛中的相关说明需准确表达阶段范围。
- 旧角色获得但尚未使用的派生技能随其退场，不传递给新角色；已经施加到棋盘上的效果仍按持续效果保留规则处理。
- 三名角色产生的超频扣分全队累计，换人不清除，整盘棋最终结算时统一扣除。
- 双方立绘区各均分为三块，从左到右对应出场顺序；当前角色显示彩色立绘，已退场角色显示灰色立绘。
- 己方未登场角色显示灰色立绘，不添加「待登场」标记；对方未登场角色显示问号。
- 对手不得提前知道未出场角色。
- 终局后公开双方完整三人阵容及出场顺序，包括提前结束对局时尚未登场的角色，供结算展示与复盘查看。
- 对局进行中，观战者看到的双方未登场角色均为问号，登场时才揭晓；终局后可见完整阵容。观战数据同样不得提前暴露候场角色身份。
- 每阶段开始前展示阶段名和双方当阶段角色立绘，持续五秒，复用现有对决动画。
- 每阶段五秒演出期间暂停双方对局计时，禁止落子和使用技能；演出结束后恢复计时与操作，不消耗玩家思考时间。
- Round 1 与现有开局猜先演出合并为一次五秒演出，同时展示阶段名、双方首发角色及执黑／执白结果，结束后直接开始对局，不追加第二段开场演出。
- Round 1、Round 2、Round 3 的阶段展示演出中，每位参赛玩家播放自己该阶段使用角色的「出战」语音；不播放对方角色的出战语音。语音使用当阶段阵容角色，不使用账号默认出战角色；Round 1 合并演出只触发一次。
- 棋盘、贴子和用时沿用星炬对弈：13 路，黑贴 2 又 3/4 子；每方整局 5 分钟，30 秒读秒 3 次。换人不重置主时间或读秒次数。
- 首版队际赛不计段位，胜负不影响任何现有段位积分；未来是否引入段位以及如何计算另行设计。
- 首版队际赛不发放对局金币奖励，奖励机制留待以后单独设计。
- 首版保留队际赛对局记录和棋谱供查看、复盘，但不计入现有个人胜率、角色胜场等战绩统计。
- 队际赛使用独立匹配队列，仅匹配队际赛玩家；首版按入队顺序配对，不参考段位。
- 首版仅开放随机匹配，好友房暂不支持队际赛。
- 移动端主要考虑竖屏。

## Confirmed edge cases

- 三个位置必须使用三名不同且当前可用的已拥有角色；记忆阵容中的失效角色移除并要求补选。
- 开始匹配后锁定阵容；取消匹配返回阵容选择并保留选择，修改后重新入队。
- 认输、超时、数子等终局规则沿用星炬对弈；任何阶段都可正常结束，终局优先于换人，不强制打满三轮。
- 重连恢复实际阶段与计时；若正处于五秒演出，只播放剩余时间，不重新开始五秒；已结束的阶段演出不补播。

## Implementation research follow-ups

- 复用 src/shared/systemVoices.js 的 SYSTEM_VOICE_EVENTS.sortie 与 src/shared/musicLibrary.js 现有角色出战音源映射，遵循现有音量、静音与播放策略；按对局和阶段去重，避免快照更新重复播放。语音不延长五秒阶段窗口。
- 新登场角色按自身原有条件触发被动，候场角色不提前触发；区分已产生的持续效果与退场后不得新增的被动触发，逐角色验证。
- server/roomSkillResolution.js 的 maybeStartPassiveSkill 在当前角色首次满足行动条件时启动 color-illusion-passive；换人需要正确初始化新角色状态，不能沿用旧角色 triggered 标记。
- 棋谱保存完整阵容、实际换人手数和阶段信息，确保终局后可正确复盘。

## Acceptance criteria

- [x] 不足三名可用角色时准确提示并阻止入队。
- [x] 三名角色及出场顺序在匹配和对局间保持一致。
- [x] 阶段边界准确，双方同步换人并展示五秒演出。
- [x] 未登场的对方阵容在客户端数据中同样保密。
- [x] 当前、候场、已出场三种立绘状态符合规则。
- [x] 每轮演出播放己方当阶段角色出战语音，Round 1 不重复，且不误播对手或账号默认角色语音。
- [x] 换人正确处理连下、技能次数、禁先、派生技能、持续效果和累计超频。
- [x] 演出暂停计时与操作，重连恢复剩余演出时间，提前终局不再触发下一轮。
- [x] 独立队列按入队顺序匹配，保存棋谱但不改变段位、金币与现有胜率／角色战绩。
- [x] 记忆阵容可修改，失效角色须补选，取消匹配保留阵容。

## Out of scope

- 首版不增加队际赛好友约战入口。
- 首版不实现队际赛段位积分机制，不预设未来采用共享或独立段位。
- 不加入尚未确认的额外玩法或奖励规则。

## 后续界面与规则修订

- 桌面使用纵向居中、左右裁切的大立绘，三格间采用略斜分隔线。
- 选人仅按卡片点击顺序；选中保留卡片边框、浅绿色、按下效果；空位不显示“选择部员”文字，右上角实心圆序号为细黑边、淡黄底、深黑字。
- 换轮保持换轮前的 BGM；后续技能与终局仍遵循原音乐规则。
- 手数范围为 1–40、41–80、81 起（第 40 手仍由 Round 1 完成），连下延迟规则保持。
