# 九名角色默认 Q 版立绘

## Goal
设计并生成猪小仙以外九名角色的默认立绘，通过 grill-me 逐项完善需求。

## Confirmed Requirements
- 达妮娅 v2 再次被否定：细节太多、AI 感重。v3 必须进一步压缩链环、裙褶、发丝与卷曲内线，去除渐变和泡泡光晕；装饰概括成少量色块/线条，以小尺寸 UI 可读性为准。
- 用户已选定两张上传的西格莉卡图作为画风基准，并要求按此画风制作达妮娅三张。参考已保存为 research/references/user-approved-style-a.png 和 user-approved-style-b.png；其优先级高于未获认可的首批精细立绘。达妮娅仍采用泡泡浮子、日常浅色衣装、简洁色块。
- 最新性格修订：用户指出西格莉卡不应如此得意自信。取消挑眉、抬颏、叉腰、挑衅与眨眼，改为认真思考、努力鼓劲、温和邀请。保留正确执子，性格依据以游戏档案中努力回应期待、容易给自己压力的学生为准。
- 2026-09-24 最新修订（优先于下列旧决策）：用户否定首批细节密集、AI 感偏重的画风；比例改为 3 头身。当前仅重新设计西格莉卡三张供查看，其余角色暂停扩展；采用更简练的大色块、克制阴影和手绘线条，保留关键身份特征。旧批次不作为新批次参考。
- 每名角色三张为明显不同的姿势方案：服饰、画风与比例一致，表情、动作、构图有明确区别。西格莉卡三张均自信夹子，达妮娅三张均泡泡浮子，爱弥斯三张均融入围棋元素。
- 最终数量为九名角色各 3 张，共 27 张独立透明 PNG，附整组预览和设计依据；本次仅交付素材，不替换或接入项目默认立绘。
- 生成与验收流程：助手直接逐个查证、设计并完成全部 27 张，检查整组一致性后集中展示，不设置中途样张或文字方案确认环节。
- 九人统一约 2.5 头身，按头顶至脚底计算，不含发饰，兼顾可爱感、服饰辨识度与手部动作表现。
- 构图采用透明底全身人物加少量悬浮元素：完整保留头发和鞋子，允许站立或轻微腾空，允许棋子、泡泡等小道具，不绘制桌椅或完整棋盘。
- 动作采用个性优先、按角色选择围棋元素的方案。西格莉卡、达妮娅、爱弥斯优先加入围棋元素：西格莉卡表现强烈自信地夹棋子（用户原话“超前自信地夹棋子”）；达妮娅用泡泡令棋子浮空；爱弥斯由助手结合查证资料设计。其余六人根据经历与个性选择动作和原作道具，不强制围棋主题。
- 服装采用忠实原作、适度简化方案：保留服装轮廓、配色、标志性饰物与纹身，仅简化 Q 版缩小后难以辨认的细节，通过表情和姿势体现个性；不改为统一校园装。
- 角色：西格莉卡、达妮娅、爱弥斯、琳奈、仇远、莫宁、长离、千咲、娜波摩。
- 2–3 头身，接近主界面 UI 人物，尤其当前匹配入口人物的画风。
- 每名角色生成前联网查证原作立绘、服饰、装饰物、纹身、经历和个性；用这些资料设计外观与姿势，体现角色个性。
- 若设计手夹棋子的落子动作，必须先查证正确落子姿势，不可凭空绘制。
- 不查看、参考或复用项目以前的角色设计图；当前在用的主界面 UI 素材是用户指定的风格基准。
