## 西格莉卡 Sigrika
**最新校正**：2026-09-24 用户否定过度自信表情。重新查阅 https://mc.appfeng.com/avatar/1412 的简介与鉴定报告：她努力满足他人期待，且会给自己较大压力。设计应表现认真、投入与温和，不用得意挑眉/抬下巴/叉腰/眨眼表达个性。下列旧姿势草案作废。新版 A 思考持子，B 鼓起干劲准备落子，C 温和邀请对弈。
来源：[角色档案转录](https://wutheringwaves.fandom.com/wiki/Sigrika/Backstory)、[中文游戏档案转录](https://mc.appfeng.com/avatar/1412)。
- 已核实：星炬学院学生、罗伊符文共鸣者；努力回应他人的期待，希望成为真正的日灵同行者，面对挑战投入认真。声痕在背侧。
- 个性处理：用户明确指定强烈自信的持子姿势，这是本作演绎方向，避免把“傲慢”当成原作事实。
- 当前 UI 可见：橙发、青绿眼、白色头饰，紫白服装；需用新检索原作图核对全部纹样和左右位置。
- A 草案：叉腰抬颏，另一手在肩侧标准夹子，笑得胸有成竹。
- B 草案：向前迈步、持子手朝前下方伸出，眉眼坚定。
- C 草案：侧身回望、手腕上举，持子靠近面侧但不遮脸，俏皮自信。
- 待核实：大腿纹样性质和形状、头饰结构、手套/鞋、背部声痕是否可见。

## 达妮娅 Denia
来源：[角色与服饰、档案](https://wiki.biligame.com/wutheringwaves/角色/达妮娅)、[语音与档案转录](https://mc.appfeng.com/avatar/1211)。
- 已核实：虚质科学部学生，懒散爱打盹，出席很多学生活动，以温柔笑容示人；能力与泡影相关。初始服饰名“壳外布景”，外观华丽，内衬有使用和缝补痕迹。
- 外形需区分日常布景之形与能力幻灭之形；当前入口是粉发、浅色衣装、红手套、蓝色饰物。
- A 草案：微歪头，张掌托起一颗装黑子的泡泡，慵懒微笑。
- B 草案：双手轻轻拨动两颗黑白子泡泡，轻微腾空，带一点捉弄人的眼神。
- C 草案：一手掩小呵欠，另一手引导棋子泡泡绕身侧上升。
- 待核实：头箍人形连饰、发饰、珠链、手臂纹样与声痕位置；不把另一形态的纹样挪到日常形态。

来源：[外观与身份介绍](https://wutheringwaves.notion.site/About-Aemeath-Appearance-1b5ef7f91e4b829c8b3681e28928aada)、[角色档案](https://wiki.biligame.com/wutheringwaves/角色/爱弥斯)、[设计综述](https://zh.wikipedia.org/wiki/愛彌斯)。
- 已查到：开朗亲切的外在表现，数字幽灵身份，伴随轻微数字失真；能力包含机兵融合。需进一步用游戏档案核实经历，避免引用搜索中的同人小说。
- 当前入口可见：粉色长马尾、金色眼、青色发饰与光环、白蓝服装、胸前青色心形核心。
- A 草案：双手向观者展示一黑一白两颗棋子，像邀请一起玩，真诚笑容。
- B 草案：一手抱小棋罐，另一手挥手邀请，身体略前倾。

- B 草案：轻快转身，手指扶耳机，喷罐垂于另一侧。
- C 草案：小幅跃起，一手将喷罐抛至手掌正上方，另一手平衡，少量彩色飞点。
- 待核实：声痕、袜鞋及左右手配件；不画整辆机车以免压缩人物占比。

## 仇远 Qiuyuan

- C 草案：侧身回望，左手掌心小火羽，衣摆轻旋。
- 待核实：左右臂衣装与灼痕显露方式、发饰和鞋，不擅自新增折扇。

## 千咲 Chisa
来源：[官方介绍及报告转录](https://wutheringwaves.fandom.com/zh/wiki/千咲/鉴定报告与故事?variant=zh-sg)、[游戏剧情转录](https://wuwa.wiki/zh-hans/codex/stories/100030)、[角色档案](https://wiki.biligame.com/wutheringwaves/角色/千咲)。
- 已核实：来自苇原，严谨冷静、珍惜人与人的联系；能洞察结构与弦线。声痕在右上臂，曾佩戴颈环式监管装置。经历新穗波危机，不能仅塑造成冷酷刀手。
- A 草案：抱住小本子，另一手整理领口，认真注视。
- B 草案：手持收拢的标志性剪形兵器在身侧，另一手向前伸出援手。
- C 草案：侧身观察指尖的一小段红线，眼神专注而柔和。
- 待核实：默认制服与领带/颈环细节、发饰、剪形兵器的真实结构和比例，右臂声痕显露程度。
