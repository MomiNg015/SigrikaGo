# 修复移动端窗口滚动穿透

## Goal

移动端打开窗口后，上下滑动只影响窗口内可滚动内容，不带动背后的主界面；关闭窗口后恢复原来的背景位置与滚动能力。

## Requirements

- 在公共窗口基础设施修复，覆盖主页窗口、房间窗口及嵌套弹窗。
- 覆盖内容不足一屏、列表到顶/到底、标题与遮罩区域的滑动。
- 保留窗口内部正常滚动、点击、输入和移动端原生缩放。
- 多层窗口按现有层级显示；关闭一层时仍有窗口则继续锁定背景。
- 保留桌面行为及现有无关工作区修改。
- 同步系统设计摘要及相关分篇，生成 HTML。

## Acceptance Criteria

- [x] 移动端有窗口时背景不随上下滑动改变位置。
- [x] 长内容窗口可正常上下滚动，到边界后不穿透。
- [x] 嵌套窗口关闭顺序不会提前解锁，最后关闭后滚动恢复。
- [x] 排行榜按住「我的排名」上滑时整窗位置不变，40 条名单末行可达，遮罩无虚假滚动范围。
- [x] 针对性回归、浏览器触摸、lint、构建与文档校验通过。
- [ ] 全项目门禁完全通过：已有 API 集成测试超时／文件监听错误及后台快照差异，详见 verification.md。

## Scope and Decisions

这是明确的缺陷修复，按用户所述行为直接处理，不涉及视觉重设计、后台移动适配或数据/API 修改。优先复用现有公共窗口机制；不逐个弹窗散落补丁。
