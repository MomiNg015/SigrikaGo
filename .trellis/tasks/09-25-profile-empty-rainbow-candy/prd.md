# 空角色战绩与西格莉卡糖果修复

## Goal / Requirements
- 履历和他人详细资料无角色战绩时，保留原区域边框并填满窗口正文剩余高度，仍显示暂无。
- 西格莉卡彩虹豆豆跳跳糖在生产环境可正常使用；使用剧情不提供跳转黑化的测试选项。
- 保留正常次数累计、效果中禁用、道具扣除和正常第八次剧情。

## Technical Approach
- 空状态提示嵌入独立的角色战绩 section，避免通用空状态清除外框；恢复弹性高度并兼顾手机他人资料正文滚动。
- 移除 server/items.js 的生产限制；仓库直接播放服务端剧情，不再注入测试选项。

## Acceptance / Done
- 两类资料空/非空切换正常，桌面与竖屏空战绩边框延伸到底部。
- production 道具使用成功且库存、效果和次数正确；仓库回调无测试跳转。
- 回归测试、项目检查和系统设计文档生成通过。

## Out of Scope
- 不改黑化正常触发规则、剧情文本、其他角色效果和已有开发服务端接口。
- 不部署或修改云端数据库。

## Open Questions
无；用户已明确两项预期。
