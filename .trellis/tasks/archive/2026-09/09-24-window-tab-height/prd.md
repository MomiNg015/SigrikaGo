# 窗口优先增高完整展示标签

## Requirements
共用侧边书签选项卡窗口根据全部标签的实际高度增高，优先完整展示标签，不受短内容或空状态影响。总高度以安全视口为限，确实放不下时才允许标签滚动。保留内容滚动、标签切换及其他主题的原布局。

## Approach
测量标签高度、间距与上下留白，以 CSS 变量驱动宿主最小高度；字体、视口和标签变化时重新测量。兼容已有窗口最小高度。

## Acceptance
- 多标签短内容窗口自动长高；屏幕足够时标签无滚动。
- 短屏仍可访问全部标签，不越过安全视口。
- 原有标签交互、主题退出及清理行为通过测试。
- 同步文档并生成 HTML。

## Result
共用书签组件按实际标签尺寸设置宿主最小高度，视口不足才滚动；主题退出清理变量。70 项定向测试、生产构建浏览器自适应检查、npm run lint 均通过，系统设计 HTML 已同步。未提交代码。
