# 修复角色读秒语音与倒计时同步

## Goal
让角色读秒的可听起点对齐倒计时，消除相邻数字明显不均匀的间隔。

## Requirements
- 用户补充：感觉所有角色都有，须全量检查所有角色读秒。
- 检查倒计时触发、音频播放链路与素材静音，依据测量修复。
- 保留角色音色、现有倒计时规则和音量设置。
- 覆盖换手、读秒重置、加载延迟，避免过期数字补播。
- 保留工作区其他未提交修改。

## Acceptance Criteria
- [x] 找到并记录可复现原因。
- [x] 针对原因加入回归测试并通过相关检查。
- [x] 同步系统设计文档并生成 HTML。

## Out of Scope
- 重新配音、改变角色台词、重构整个音频系统或修改对局规则。

## Technical Notes
- 当前分支 codex/mobile-battle-polish，已有界面相关 WIP。
- 已全量测量 9 个角色的 90 段音频，结果见 research/audio-audit.md。
- 共因：网络整数棋钟直接触发语音，无本地稳定节拍；未缓存路径重复下载且异步请求无过期保护。

## Decision
- 最后 10 秒使用显示与语音共用的本地一秒节拍；300ms 内到包抖动不重置相位。
- 最多预测一秒且停在 1，不推断超时或下一轮读秒；换手、history、period、phase、回放变化立即重置。大于 300ms 的偏差以服务器为准。
- 保留 10ms 起音余量，只跳过绝对幅值低于 -40dBFS 的片头；原始素材、语速、响度与轻声辅音保持。
- 统一预加载与播放的缓存；读秒启动超过 200ms 则丢弃，播放请求与房间清理均能取消旧请求。
- 浏览器 TTS 与无 WebAudio 的媒体 fallback 不保证相同起音精度。

## Validation
- 全部 9 个静态角色的 90 段素材经过 FFmpeg PCM 测量；原文件未变更。
- 相关 23 个测试文件、192 个测试通过；9 个角色均覆盖从 10 到 1 的完整抖动到包序列。
- lint、立绘检查、管理员快照检查、构建、生成 CSS 检查及生产配置检查通过。
- 首轮 npm run check：2588 通过、5 失败。其中本次文档生成时序导致的 HTML 断言已重新生成并通过复验；另外 4 个界面断言位于未修改的 HouseModal（2）、ShopModal（1）及原有 RoomScreen CSS 契约（1），与读秒无关，保留现状。
- 尚未在真实浏览器/音响设备上进行主观听测；实际平台 TTS、设备输出延迟和主线程严重阻塞仍是精度边界。
