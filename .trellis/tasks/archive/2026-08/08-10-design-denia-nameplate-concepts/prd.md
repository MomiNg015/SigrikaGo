# 设计达妮娅用户名背景三版

## Goal

沿用本轮已确认的紧凑用户名背景思路，为达妮娅探索结构明显不同的虚质主题候选；用户选定 v5 A「偏心珠光泡」后，将其处理为透明正式资产并接入现有精确资产 owner：左侧为不规则珠光泡，中部完整承载运行时用户名，右侧自然收束，不再为称号、徽章或段位预留独立区域。

## Requirements

- 角色资料必须以联网读取的官方库街区档案正文为主，并与项目角色、技能、成就和现有铭牌资料交叉核对。
- 用户明确要求三版，因此本轮以恰好三版覆盖项目 Skill 默认的四方向探索数量。
- 三版共同采用连续横向构图：左侧角色识别核心、中部安静用户名载体、右侧自然收束；不得出现分离的称号槽、徽章槽或段位槽。
- 左侧不得使用罗马数字、字母、数字、通用等级章或头像，分别由达妮娅的黯核、虚质方块、熵变/幻灭蚀域等角色证据驱动。
- 用户进一步澄清：达妮娅仍应以粉紫色调为主，泡泡可以作为左侧主元素；此前否决的是“整块铭牌都以泡泡/糖果泡膜为主体”，不是禁止左侧泡泡识别物。
- 用户在 v3 后提供新的配色参考：继承近黑靛蓝、钴蓝电紫、饱和紫与洋红尾光的暗到亮能量层次，但不继承参考图的机械圆环、装甲碎片、硬框或等级符号。
- v4 左侧泡泡必须是不规则有机轮廓：轻微偏心、鼓包、局部厚薄不一或自然并合；不得再生成完整正圆、同心环、眼睛、黑洞或传送门读感。
- v4 中段不再做整条发亮泡膜或圆角胶囊，而是深靛蓝、低细节的虚质载体；泡泡只做左侧识别锚点，右侧以柔软粉紫虚质折光和流质尾光收束。
- 用户否决 v4 的整体情绪：深色液态核心、空洞高光、破膜缺口和细长尾丝组合后产生眼窝、黏液、黑洞或触手联想，过于惊悚，与达妮娅年轻、慵懒、温柔、梦幻的外貌气质不符。
- v5 将“虚质”从黑暗异物校正为柔和空间折射：保留蓝紫—粉紫色阶，但提高薰衣草、珠光白、浅钴蓝和玫粉的面积，深靛蓝只承担用户名对比与薄层阴影。
- v5 左侧仍是不规则泡泡，但必须软糯、轻盈、珠光、无空洞；不得出现黑色中心、眼状高光、裂口、伤口、黏液、触手或锐利流丝。
- v5 右侧使用短而宽的极光带、柔雾折光或丝带回卷，不再用长而细的分叉尾丝。
- v3 必须重新对齐用户最早提供的参考结构：左侧强识别物、中部完整用户名载体、右侧一体化收束；参考的是结构与占比，不复制罗马数字、等级章、文字或机甲硬框。
- 虚质作为泡泡内部的黯核、折叠方块、熵变裂隙或尾部能量流出现，材质保持柔和、梦幻、半透明与轻微空间错位，不做黑暗恐怖侵蚀横幅。
- 不出现围棋盘、棋子、棋格、交叉点、落子轨迹或其它围棋图形。
- 不复用西格莉卡的星辉符印、金色符文、星形主核或紫色墨尾语言。
- 不复用现有达妮娅正式资产的“双端同权泡泡门＋大量相册页堆叠”构图；v3 允许左侧单个主泡泡，但不得在右侧再放一个同权泡泡门，也不使用相册或照片页。
- 沿用此前达妮娅方向中用户否决的约束：不出现玩偶、布料、缝补、补丁、针线或拼布。
- 候选图不烘焙用户名、角色名、字母、数字、品牌或 UI 标签；代表用户名只出现在独立预览图中。
- 交付画布为 `1125 x 240`（`4.6875:1`），运行时按现有达妮娅 owner 的 `150 x 32`、左 `40px` / 右 `25px` 内容区预览。
- 三版必须在左侧核心轮廓、载体边界、右侧收束与负空间策略上明显不同，而不是换色。

## Definition of Done

- 研究、三份独立提示词、源图、统一候选图、运行时缩略图和用户名预览均留存在本任务。
- 用户选定的 v5 A 已覆盖达妮娅正式 PNG，并完成精确资产 CSS 与动效接入。
- 正式资源通过资产校验、聚焦测试、生产构建、构建 CSS 检查与本地多视口预览。
- 不修改奖励数据、成就条件、通用 `UserIdentity` 或其它角色铭牌。

## Technical Approach

使用内置图像生成工具分别生成三个独立概念，要求单个横向铭牌置于统一可移除纯色底、无文字。随后在任务目录内去底、整体等比缩放并居中到 `1125 x 240`，再生成 `150 x 32` 运行时缩略图和按真实内容区定位的代表用户名预览。用户选定 v5 A 后，复用既有生产 URL 与精确资产 ID，替换透明 PNG，并以精确 owner CSS 叠加轻量位移/透明度动效。

## Decision (ADR-lite)

**Context:** 达妮娅已有一版以折光泡泡门和相册页为主的正式铭牌；用户在完成西格莉卡新方向后，希望按同一“左侧角色物件＋完整用户名背景”思路再看三版达妮娅。

**Decision:** v1 因糖果感与泡泡铺满主体被否决；v2 又因过度排斥泡泡、压成黑暗侵蚀风而被否决。v3 回到达妮娅的粉紫角色色调和用户最早给出的参考结构：左侧单泡泡主元素承载角色虚质识别，中部完整用户名载体，右侧自然收束，继续取消独立称号/徽章/段位预留。

v3 仍因规则正圆泡泡与整条发光胶囊式载体未通过。v4 以用户新参考图为配色与能量层次依据，只保留其深靛蓝到电紫、洋红的推进关系；左侧改为偏心、鼓包、并合或局部破膜的不规则泡泡，中段改为非泡膜的深靛虚质载体，右侧改为柔软流质尾光。

v4 又把“虚质”推得过暗、过液态：左侧像眼窝或黑洞，破膜和细长尾丝又产生伤口、黏液和触手联想。v5 保留虚质主题但恢复达妮娅本人的情绪温度，以珠光泡膜、柔和蓝紫折射、玫粉极光和短宽收尾表达力量，不再靠黑暗空洞或异物感表达虚质。

**Consequences:** 用户已选定 v5 A「偏心珠光泡」。正式资产沿用现有奖励 URL 与 `150 x 32` 精确 owner，替换旧双端泡泡门/相册页画面；动效围绕珠光膜面、柔和折射和短回卷展开，不修改奖励条件、资产 ID 或通用 `UserIdentity`。

- 在用户完成游戏内视觉验收前提交、推送或合并。
