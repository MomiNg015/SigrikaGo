# 残星会 Cosplay 商店舞台背景

## Goal

为残星会 Cosplay 商店绘制并接入一套深红色舞台商店背景：桌面端使用横版构图，移动端使用独立竖版构图。视觉语言基于可核实的残星会官方配色、符号与代表人物特征，同时严格适配现有服装商品舞台、看板娘、钱包、台词和 header 的实际布局。

## What I Already Know

- 用户明确要求先联网查找残星会相关配色、主题人物图片。
- 商店方向是深红色舞台商店，不是扎希拉商店的蜡笔帐篷复刻。
- 桌面与移动端分别制作，不机械裁切同一张图。
- 画面必须按当前残星会服装店布局安排商品区、看板娘区和 UI 留白。

## Assumptions

- 沿用当前残星会商店的深红、旧金与暗紫视觉基础，强化成剧场后台/换装舞台。
- 背景不直接复制官方角色立绘；只提炼服装轮廓、面具、帷幕、金属徽记和灯光语言。
- 输出保留版本化 PNG 源图，并生成运行时 WebP。

## Open Questions

- 无阻塞问题；视觉方向、布局约束和桌面/移动双资产范围已由用户明确。

## Requirements

- 研究并记录官方或可信一手资料中的残星会配色、符号、舞台感与代表人物视觉。
- 桌面背景按当前横向服装店的左侧约 34% 看板娘接待区、右侧约 65% 商品舞台构图。
- 移动背景按当前竖屏上方约 57% 商品区、下方约 43% 接待区独立构图。
- 主色为深红、酒红、黑紫、旧金；局部可用冷白/玫红舞台追光。
- 画面必须与扎希拉商店属于同一粗蜡笔手绘体系：蜡笔颗粒、粗糙纸纹、歪斜线条、简化色块和不规整边缘，不能是高精概念图或写实 3D。
- 使用帷幕、换装台、悬挂服装剪影、舞台框、金属三角纹样、面具或徽记等低干扰元素。
- 不包含角色本人、游戏 UI、文字、水印或可误认为按钮的高对比矩形。
- 商品、售价、看板娘、钱包、气泡和 header 在真实界面中保持清晰。
- 新运行时 WebP 进入商店预加载资产合同。

## Acceptance Criteria

- [x] 研究文件记录来源链接、可用配色和可提炼元素。
- [x] 桌面图能在 1440x900 商店窗口中与左侧看板娘、右侧商品布局对齐。
- [x] 移动图能在 375x812 与 375x600 中与现有上下分区对齐且无横向溢出。
- [x] 两张图属于同一深红舞台商店体系，但不是同图裁切。
- [x] 两张图的粗蜡笔颗粒与手绘精度和扎希拉商店一致，不呈现精细金属反射或电影级灯光。
- [x] 画面不包含角色、文字、UI 控件或水印。
- [x] 残星会页面使用新背景，扎希拉页面不继承。
- [x] 源 PNG、运行时 WebP、预加载注册、测试和系统设计文档完整。

## Definition of Done

- 完成联网研究并保存结论。
- 生成、筛选和保存桌面/移动背景。
- 接入当前服装商店并完成真实浏览器视觉检查。
- 聚焦测试与完整 `npm run check` 通过。
- 同步系统设计与相关前端规范。

## Technical Approach

先从官方资料中提炼残星会的深红、象牙白、旧金与暗紫配色，以及指挥家、破碎黄铜乐器、玻璃碎片、彼岸花和剧场帷幕语言，再用内置 ImageGen 生成无人物背景。桌面与移动端各自使用一套布局提示词，运行时以服装店 owner 和响应式断点选择相应 WebP；不改变商品卡、看板娘、钱包或购买流程。

## Out of Scope

- 不重绘残星会看板娘或商品服装立绘。
- 不修改服装商品数据、价格、购买逻辑或衣柜。
- 不把残星会背景应用到扎希拉商店。

## Technical Notes

- 研究结果位于 `research/fractsidus-visual-language.md`。
