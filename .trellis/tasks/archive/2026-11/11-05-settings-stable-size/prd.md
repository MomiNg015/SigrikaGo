# 固定设置窗口尺寸

## Goal
音量、界面、关于、碎碎念共用同一个稳定外框。高度只随视口适配，不随文字长度变化。

## Scope
- 保留现有标题、书签、边框、色彩、留白、音频与主题功能。
- 用音频页正常空间需求作为统一尺寸参考，桌面/手机均受既有安全高度变量约束。
- 长关于及碎碎念仅内部滚动，右下角切换按钮始终可达。
- 不修改文案配置或接口。

## Acceptance
- 桌面、800x600、390x844、320x568下，依次切换四种状态，外框 x/y/width/height 不变。
- 正文滚到末尾仍可返回，音量滑块和主题操作仍可访问。
- 提供同尺度切换截图、测量记录；同步系统设计与尺寸合同。

## Research
当前设置窗口用内容决定高度，普通书签窗口只有最小高度；长文把窗口撑到视口上限。
现有手机主题页也包含单页高度规则。统一尺寸应在最终设置外框 owner 中生效，并删除失效的单页尺寸要求。

## Implementation and verification
- 已完成：桌面 456px、手机竖屏 600px，并受既有可用高度上限约束；320x568 实测高度 492px。
- 四种视口的音频、界面、长关于、长碎碎念、返回、音频完整链路均保持外框位置及尺寸；正文末尾、返回按钮和最后一条音量滑块可达。
- Playwright 正常动效模式 4/4 通过。测量先等待面板入场及按钮 hover 完成，避免把既有反馈动效误判为滚动位移。
- SettingsModal 与 CSS 合同 35/35 通过；相关 ESLint、构建及 built CSS 合同通过。
- 更新系统设计入口、UI 分篇及窗口尺寸合同，重新生成系统设计 HTML。
- 同尺度实拍及 20 个状态的几何记录保存在 `.codex-run/settings-about/stable-*.png`、`stable-verification.json`；截图使用明确的长文测试内容。
