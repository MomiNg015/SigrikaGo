# 界面设置与关于三套交互样板

## 2026-11-05 用户修订：保留现有界面，仅调整关于
此前三个方向不采用。正式实现保持现有配色、边框、标题、书签、音频和主题页，只增加关于文本内边距及右下角“碎碎念／返回”切换。
碎碎念通过新增 aboutNotesText 独立管理，默认空字符串，原 aboutText 不拆分或覆写；管理后台提供文本框。
同一窗口替换正文，正文独立滚动，按钮留在右下角；重新进入关于时展示网站信息。
验收覆盖往返、空文本、旧配置兼容、后台保存读取、长文与 320/390px 竖屏。

## Goal
提供三套可点击比较的设置窗口设计，覆盖界面主题、网站信息和作者碎碎念。

## Requirements
- 关于默认展示网站信息；碎碎念作为独立按钮，在同一窗口内替换内容，可返回关于。
- 三种构图方向：校园手册、口袋控制台、社团来信；使用项目现有字体、纸张和墨色轮廓。
- 界面页使用现有三种主题名称，只有明亮校园可用，其余明确标注未开放。
- 桌面及手机竖屏可操作，长文在内容区滚动，返回与关闭始终可达。
- 仅新增隔离样板，不接入生产组件、账户、API或持久化。
- 网站资料来自默认配置；作者碎碎念使用明确标记的排版示例，不冒充作者原文。

## Acceptance criteria
- [x] 三种方向均可切换，界面、关于、碎碎念、返回完整可用。
- [x] 1440px 桌面及 390/320px 手机无水平溢出。
- [x] 图片和字体加载成功，无脚本错误、资源404或应用API请求。
- [x] 提供预览入口、截图、设计取舍说明，更新系统设计并生成HTML。

## Scope
文件位于 docs/design-samples/settings-about-2026-11-05/，不修改正式设置窗口。
不新增主题实现、后台字段或账号偏好。正式接入与最终作者文案待用户选择后处理。

## Research
当前 SettingsModal.jsx 的界面页只有三个纯文字按钮；关于直接输出一个 aboutText 段落。
网站名、版本、简介、页脚资料可从 DEFAULT_SITE_SETTINGS 获取。aboutText 目前没有网站信息与碎碎念的独立数据字段。
沿用项目既有独立 HTML 样板与 Vite 预览方式，不增加依赖。
