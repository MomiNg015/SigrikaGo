# 爱弥斯性格表情差分

## Goal
按用户提供的爱弥斯透明立绘和人物性格，制作与本会话前两套一致的8种常用表情，交付独立透明PNG、分层PSD、预览和核验记录。

## Requirements
- 用户已授权制作配套表情；沿用前两套已确认的独立工作包及交付方式。
- 表情：明快微笑、闭眼开心笑、俏皮眨眼、好奇惊讶、专注思考、无奈吐槽、轻微不满、坚定认真。
- 参考官方人物档案的活泼俏皮、喜欢分享快乐，及本地既有官方资料记录的认真与保护意志。
- 保持原画布、身体、服装、脸型、鼻子和Alpha；保留金橙色星形瞳纹。
- 闭嘴位置依据本角色原图重新测量，沿用上一套嘴部校准与清理边缘修复经验。
- 候选使用宿主原生 image_gen；固定原图组装使用已安装 vn-sprite-expression 工作流。
- 交付目录位于 visualization workspace 的 amis-sprite-expressions；不将图片接入项目资产体系。

## Acceptance Criteria
- [x] 原图与源文件hash一致。
- [x] 8种表情相互不同，符合人物性格。
- [x] 每张PNG保持原尺寸、Alpha和允许修改区域外RGBA精确一致，鼻子及身体像素一致。
- [x] 缩小后的立绘及面部总览无旧五官残线、刘海污染和嘴周灰圈。
- [x] PSD8组各含左右眉、左右眼、嘴；默认仅显示1种，备份和体底锁定。
- [x] 独立PSD逐组渲染核对通过，明确未进行Photoshop实机核验。
- [x] ZIP含8张PNG+原图、PSD、预览、完整提示词和报告。

## Definition of Done
制作和艺术检查完成，像素/PSD报告通过，ZIP内容核对并交付。

## Technical Approach
先研究人物设定和面部坐标；原生生成净脸及8个独立候选；局部提取眉眼嘴并恢复原图Alpha；先构建少量检查再扩全套；独立核验并打包。任务不涉及应用运行行为，项目lint/单元测试不适用。

## Decision
沿用用户在本会话确认的生产方式，不额外扩大到立绘姿势或项目接入。后续新表情可复用本包原生候选、校准配置和分层文件。

## Out of Scope
不修改游戏代码、已有素材、角色造型、服装、特效或前两套表情包。系统设计没有新增运行/资源事实。

## Open Questions
无需要用户回答的阻塞问题；几何坐标由原图测量确定。
