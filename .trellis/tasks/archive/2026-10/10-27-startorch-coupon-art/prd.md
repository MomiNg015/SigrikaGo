# 用户手绘星炬券接入

## Goal

按用户 2026-10-28 提供的蓝黄斜券原图，裁掉水平与垂直透明空白并替换金币图标；商店中的货币文字改成该图，所有缩放保持原比例。

## Requirements

- 使用用户原图，不继续生成候选美术；保留全部可见像素与透明度。
- 输出紧边透明 PNG 和无损 WebP；共享图标只设置宽度，高度自动计算。
- 替换商店、履历、招募、邮件、结算的金币图形。商店价格、详情、对白、余额不足和错误提示中的货币词显示图标。
- 内部 coins、奖励数值、价格、购买与装扮流程保持原逻辑。
- 同步系统设计与资源契约，检查桌面及手机竖屏，保留无关 WIP。

## Acceptance Criteria

- [x] 原图 1024×1024 按非透明边界裁为 827×746；两种输出可见像素和透明度差异为零。
- [x] 共享图标保留无障碍名称，商店货币文字转为券图。
- [x] 生产 CSS 下桌面与手机两家商店保持等比显示，购买、装扮和余额不足行为通过。
- [x] 项目检查通过，系统设计文档与 HTML 同步；全量 3399 项先通过，文档生成一致性失败在重新生成 HTML 后定向复验通过（4/4），其余检查门禁通过。

## Scope

此前四版候选探索已被本次选定原图替代，不进入运行时资源。保留未选候选的本地文件；本次提交限于选定美术、接入代码、回归验证、相关文档及任务记录。
