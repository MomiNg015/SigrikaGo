# 准时宝选角修复

## Goal
移除准时宝角色选择窗口的开始按钮，让对局技能、语音与所选角色一致。

## Requirements
- 角色选择窗口只保存角色，关闭后由难度窗口开始；保留难度与独立账号选角缓存。
- 选角服务端校验成功时，房间角色 ID 与角色配置同步来自已校验目录，不继承账号默认角色配置。
- 保留拥有权、禁用角色、糖果限制及账号默认角色；其他模式开始按钮保持现有行为。

## Acceptance Criteria
- [x] 准时宝选角窗口没有开始按钮；选角不会自动开始，难度窗口携带正确角色开始。
- [x] 账号默认西格莉卡、选择其他角色时，实际房间角色、技能状态和语音解析一致。
- [x] 覆盖普通陪练和吃子挑战，并保留不可用角色拒绝行为。
- [x] 相关测试、lint/build 通过；系统设计摘要与受影响规范同步更新，生成 HTML。

## Scope
只修复按钮和角色身份/配置不一致，不重设计窗口，不修改其他既有工作区改动。

## Technical Notes
`resolveMatchCharacter` 仅覆盖 selectedCharacter，`toRoomPlayer` 同时读取旧 characterConfig，造成角色 ID 和玩法/语音快照分裂。修复应位于公共选角解析边界。
用户请求已明确，无需新增产品决策。

## Validation
相关 9 个测试文件共 117 项通过；进一步校正语音事件常量并断言最终音频 URL 后，17 项 practice socket 测试重新通过。全项目 lint、生产构建、构建 CSS 合同、角色资源、后台默认快照、生产配置与系统设计 HTML 生成通过。
全量测试另外发现未修改区域的 CSS 基线、部员手册样式和糖果立绘测试失败，详见 verification.md；不扩大修复范围，不提交或覆盖既有工作区改动。
