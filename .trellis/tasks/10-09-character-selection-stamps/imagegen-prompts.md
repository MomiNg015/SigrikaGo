# Imagegen prompts

Built-in image_gen, transparent_background=true. Outputs copied unchanged to public/assets/home/selection-stamp-{flag,1,2,3}.png. All four images have alpha, transparent corners and hollow interiors.

## Flag

Use case: logo-brand. Generate ONE square game UI selection stamp PNG with actual transparent background. Center a red circular rubber-stamp ring, diameter about 80% of canvas. Inside the ring place ONE simple hollow red outline waving flag icon with pole. All areas except red ink strokes MUST be fully transparent, including inside the circle and inside the flag. Single vermilion red ink #cf383b, medium bold strokes readable at 48px, restrained slightly imperfect rubber stamp texture, mostly continuous crisp ink. No solid disc, no white fill, no paper, no shadows, no additional text or symbols. Circle centered exactly, ample equal transparent margin. Flat front view.
