# 修复主界面引导重复对话与首次定位

## Goal
用户指出同一句讲解首次遮挡目标，点击后才换到正确位置，额外点击才能继续。只修复该行为，保留原文案和其它引导机制。

## Findings
homeOnboardingScript 中 handbook-intro/sigrika、match-intro/spark、team-intro/team-select 各由有文本的介绍步加空文本操作步组成。HomeOnboarding 的前文回退使空操作步重复显示上一句，且目标从整窗或卡片改为具体按钮，导致用户看到同一句话点击后搬家。

## Requirements
- 合并三对介绍/操作步，首次展示即采用实际操作目标。
- 原文案、表情、窗口打开顺序、禁止误匹配购买和逐字阅读行为保持。
- 补充真实动画下的首次定位及单次目标点击进入下一句的回归。
- 同步设计文档，不扩展本轮审查发现的其它问题。

## Acceptance
- [x] 不再存在依赖上一句文本的空操作步。
- [x] 三处讲解首次出现即可看到正确高亮，点击真实目标代理一次即进入下一句。
- [x] 桌面与手机竖屏验证，相关单元/浏览器回归及 lint/build 通过。
- [x] 设计文档与生成 HTML 同步。

## Decision
用户已明确要求先解决此问题，无待确认范围。采用现有脚本的 action 结构直接合并，不改逐字显示的一般点击规则。
