# 恢复部员手册角色详情视口浮层

## 背景

桌面端“部员手册”打开角色详情后，详情浮层被限制在手册父窗口内部，右侧与底部发生裁切。回归来自父窗口入场动画在结束后仍保留 `translate` / `scale` 结束态，使父窗口持续成为内部 `position: fixed` 浮层的包含块。

## 目标

恢复原先正常行为：角色详情始终相对浏览器视口居中并覆盖完整页面，同时保留现有窗口打开动效。

## 需求

- 桌面端部员手册的父窗口入场结束后不得继续保留会改变固定定位包含块的变换属性。
- 角色详情的 `.nested-modal-backdrop` 继续使用视口级固定定位，不改成父窗口内布局。
- 保留现有窗口入场的位移、缩放、透明度、时长和缓动观感。
- 同类窗口入场规则使用不会保留结束态变换的填充模式，避免其他嵌套详情出现同类回归。
- 不改移动端布局，不改角色详情视觉设计，不处理关闭动画。
- 不吸收当前工作树中教程操作面板的并行改动。

## 验收标准

- 部员手册打开动画结束后，`.house-modal` 的计算 `translate` 与 `scale` 回到未设置状态，而不是由动画持续占用。
- 从部员手册打开角色详情时，详情遮罩的边界与浏览器视口一致，不被手册窗口裁切。
- 详情窗口的右侧、底部和关闭控件均完整可见。
- 部员手册及其他已有桌面窗口仍保留当前打开动效。
- 样式契约测试明确禁止窗口入场使用会保留结束态的 `both` / `forwards` 填充模式。
- 相关测试、构建和系统设计文档生成通过。

## 实现约束

- 优先将窗口入场动画填充模式改为 `backwards`：延迟阶段仍应用首帧，动画结束后释放 `translate` / `scale`。
- 不通过增加 `overflow`、提高 `z-index` 或复制角色详情到其他 DOM 节点绕过根因。
