# 瑝珑黑化西格莉卡剧情二审

## Goal

在现有《黑化西格莉卡剧情审阅稿-瑝珑小说重写版》上做一次人物与情绪优先的深度二审，保留用户已认可的剧情方向和文档格式，解决台词生硬、论点宣讲、旁白缺少人物反应与场景变化、整体 AI 腔明显的问题，最终只交付新的 Word 审阅稿，不实装到项目。

## Requirements

- 原始文档与上一版审阅稿均保留，另存为新的二审文件。
- 通用吃糖剧情逐字保留，不参与改写。
- 保留糖果剧情 1 至 8、黑化挑战、决战胜负分支与各自醒来尾声的现有结构。
- 第 7 段停在七宿青年联弈开赛或结果揭晓前，第 8 段才出现最终败局。
- 梦境与黑化是玩家悲观思考的投影，现实中的西格莉卡没有黑化。
- 西格莉卡不称玩家为“前辈”。
- 决战后的剧情不再引用《星枰旧响》或其人物、赛事和桥段。
- 黑化西格莉卡必须表现四个悲观命题，但不能像论文一样依次宣读；命题要从她的试探、诱导、停顿与玩家的反应中自然显露。
- 胜利分支保留四轮双选项且每轮立即汇合。两个选项语气不同，立场一致，不承诺努力必然成功或世界公平。
- 失败分支冷静、有诱惑性，不辱骂玩家，落点是“不参与便不会受伤”。
- 胜利醒来后玩家主动邀请下棋；失败醒来后玩家说累并回避棋盘。两边都没有超自然证据。
- 只使用旁白和人名或对话正文，不加入研究、说明、节点编号、实现备注、来源或第四墙内容。
- 旁白优先写可见动作、表情、目光、呼吸、手指、空间距离与环境声响；动作已经传达感情时，不再补一句解释。
- 西格莉卡的正常语气保持聪明、热心、会替人想办法，但面对期待与失误时会先把责任揽到自己身上；避免口号式金句与过度稳定的哲理表达。

## Acceptance Criteria

- [x] 通用吃糖剧情与上一版逐字一致。
- [x] 第 7 段无赛事最终结果，第 8 段明确承担最终败局。
- [x] 文档中不出现“前辈”、项目发布、成本、观众、NPC、脚本或其他第四墙词。
- [x] 决战后的正文不出现《星枰旧响》及其人物、赛事、旧棋谱等相关内容。
- [x] 四个悲观命题均可从梦境对话中辨认，但没有四段同构的论点陈述。
- [x] 胜利分支有四轮双选项与四次立即汇合，选择之间是人物语气差异，不是观点正误差异。
- [x] 每个主要场景至少发生一项动作、信息、关系、情绪或选择上的变化。
- [x] 对话朗读自然，人物不会轮流替作者总结主题。
- [x] Word 只含剧情正文，格式沿用用户稿，逐页渲染检查无溢出、截断、异常空页或表格错位。
- [x] 最终二审 Word 与中间文件分开保存，上一版文件不被覆盖。

## Definition of Done

- 使用 `story-sense` 完成叙事状态诊断，并把结论保存到任务目录。
- 使用 `human-writing` 的虚构、剧本对白与修订规则完成重写与禁用句式检查。
- 使用 `documents` 的渲染校验流程生成并逐页检查 DOCX。
- 仅交付新的 Word 审阅稿，不修改应用代码、默认剧情脚本、数据库、快照或系统设计文档。

## Technical Approach

先从现有 Word 提取正文并做场景级诊断，锁定真正需要重写的片段。保留文档的段落、表格和样式骨架，用脚本只替换剧情文本。重写顺序为糖果 1 至 8、黑化开场、败北分支、胜利分支与两段醒来剧情。初稿完成后运行中文模板腔检查，再导出 PDF 并逐页查看。

## Decision

**Context**：上一版的结构和观点方向基本正确，但仍以概述和观点陈述推动，人物常常说出作者想表达的结论。

**Decision**：本轮不重搭结构，也不增加新世界观。把修订重点放在人物当下想做什么、说不出口的部分、动作造成的关系变化，以及决战中“保护自己免受伤害”的诱惑感。

**Consequences**：部分漂亮但过于工整的句子会被改成更短、更迟疑、更贴近现场的表达。主题会少说一些，由玩家的选择和最后的动作承担。

## Out of Scope

- 不实装剧情，不更新应用、API、数据库、状态机、默认脚本或发布快照。
- 不改通用吃糖剧情。
- 不增加立绘、音频、奖励、成就或第三结局。
- 不把用户现实中的项目、成本与发布焦虑直接写入剧情。
- 不将文档扩展成策划案、节点表或带批注的审校报告。
