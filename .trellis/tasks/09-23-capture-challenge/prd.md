# 准时宝吃子挑战赛与排行榜

## Goal

在准时宝陪练中增加限手数的吃子挑战，并通过排行榜展示玩家提子成绩。需求已通过 grill-me 逐项确认并完成实现。

## Confirmed requirements

- 准时宝陪练增加“吃子挑战赛！”选项，点击进入高级准时宝陪练。
- 挑战禁用数子按钮，对局到 100 手结束，统计并记录玩家提子。
- 排行榜新增“吃子赛”选项卡，展示排名、用户名、用户段位、提子数，提子数越高排名越前。
- 排行榜使用每位玩家的单局最高提子纪录，每人只占一行；较低的新成绩不覆盖最高纪录。
- 吃子赛榜单的角色立绘展示创造该最高提子纪录时使用的角色，不使用常用角色。角色 ID 随有效最高提子纪录保存，刷新最高提子数时同步更新角色；较低成绩及用户之后切换角色不改变该纪录对应角色。
- 使用不同角色打平最高提子纪录时，保留首次创造该纪录的角色；只有提子数严格超过个人最高纪录才更新纪录对应角色。
- 100 手按双方合计的现有 `moveNumber` 计算：落子、停一手、消耗回合的技能计数；额外落子每次计一手，不消耗手数的技能不额外计数。第 100 手动作及其效果结算完成后结束挑战并统计成绩。
- 挑战成绩只取玩家现有“提子”统计，技能效果中单独计为“除子”的数量不计入挑战成绩。
- 仅完成 100 手的挑战成绩有效并可更新榜单；玩家认输、超时或异常造成的提前结束不计入榜单。断线后仍可恢复的对局允许继续挑战。
- 挑战模式取消普通陪练的 22 子自动认输规则。
- 榜单同提子数并列名次，采用竞赛排名（例如 1、2、2、4）；段位与纪录达成时间不影响名次。
- 完成 100 手后只展示挑战成绩，不判双方胜负。结算文案为：“你这次提了x个子，位列总排名中的第x位，可喜可贺！”，分别替换本局提子数和本次成绩排名。
- 本次成绩排名以本局提子数对比其他玩家的最高纪录，排除自己的历史纪录，名次为 1 + 最高提子数严格高于本局成绩的其他玩家数量。即使未刷新个人提子纪录，也显示本次成绩对应名次；榜单仍保留个人最高提子纪录。
- 突破个人历史最好名次时，结算界面以红字重点提示“突破个人最高排名！”。以有效挑战结算时取得的名次建立历史纪录；只有本次名次数字严格小于历史最好名次才提示，打平或仅恢复之前名次均不提示。首次成功完成（包括零提子）也显示突破提示；红字做成印章，并有盖章入场动画，遵循减少动态效果设置。

## Existing behavior verified

- `src/shared/practiceMode.js`：高级为 GNU Go level 10，现有提子认输阈值为 22，普通陪练 recordPolicy 为 none。
- `.trellis/spec/backend/practice-room-contract.md`：现有入口直接选择难度并随机猜先；陪练无普通战绩和成长奖励，机器人无角色技能，复用 Spark 权威对局流程。
- 排行榜入口与服务：`src/modals/LeaderboardModal.jsx`、`server/leaderboard.js`。

## Confirmed scope defaults

- 吃子赛为永久总榜，不设赛季、不定期清零；完成有效挑战即入榜，0 提子也可记录。
- 用户名与段位使用当前资料，段位取星炬围棋模式段位，不取挑战完成时的快照。
- 沿用高级陪练的随机猜先、角色技能、棋盘与计时设置；停一手继续按现有规则计手，挑战不通过数子提前结束。
- 保持普通陪练不影响段位、普通胜负战绩和成长奖励的边界，只增加挑战成绩及历史最佳名次记录。
- 对局中明确显示挑战进度（当前手数 / 100）与玩家提子数，数子按钮呈禁用状态且服务端拒绝数子请求。
- 榜单中的“我的排名”展示个人最高提子纪录的当前排名；结算文字展示本次成绩在结算时计算的排名，不随榜单后续变化改写。
- 服务端权威计算、持久化成绩与名次，重复结算不得重复记录或重复触发突破提示。

## Acceptance criteria

- [x] 新选项可进入高级难度的独立挑战模式。
- [x] 数子不可用，达到确认后的 100 手条件自动结束。
- [x] 双方共用现有手数计数，第 100 手的提子计入最终成绩，结束后不能继续行动。
- [x] 服务端记录确认口径的提子成绩。
- [x] 成绩与玩家“提子”计数一致，不叠加“除子”计数。
- [x] 提子达到 22 颗不会触发挑战模式认输；未满 100 手的结束不能更新榜单。
- [x] 可恢复的断线对局继续使用原手数和提子计数，完成后正常结算。
- [x] 吃子赛榜单按已确认规则排序并展示排名、纪录角色、用户名、段位和提子数。
- [x] 同一玩家多次挑战只展示单局最高提子数，较低成绩不覆盖纪录。
- [x] 吃子赛展示最高提子纪录所用角色立绘，刷新纪录同步更新角色，较低成绩与之后切换角色不会改写纪录角色；普通排行榜继续使用原角色展示规则。
- [x] 不同角色打平最高提子纪录时，仍展示首次创造该纪录的角色立绘。
- [x] 同分玩家显示相同名次，后续名次跳过被并列占用的位置（1、2、2、4），“我的排名”保持一致。
- [x] 挑战完成不显示胜负结论，按指定文案展示本局提子数及确认口径的本次成绩排名。
- [x] 未刷新提子纪录时，结算按本局成绩比较其他玩家最高纪录，不把自己的历史纪录算作竞争者，且不覆盖榜单最高提子数。
- [x] 满足确认后的突破条件时，红字显示“突破个人最高排名！”。
- [x] 原有普通陪练和其他排行榜行为保持兼容。
