# 对弈信息区立绘出框样板

## Goal
独立 HTML 交互样板探索更有层次的对弈信息区。用户希望人物立绘越过卡片区域，不再困在边框中。

## Design
- 用户认可出框效果，第二版仅调整信息面板：身份铭牌、深色棋钟与统计底座、角色色技能按钮；保留出框立绘。
- 保留 Bright School 纸面、深棕描边与本地透明 Q 版立绘；角色背板、立绘、前景信息纸分层。
- 桌面双侧大立绘，手机竖屏上下横向信息条，立绘从左上探出。
- 提供出框开关、换手、棋盘试下、技能演示与重置，数据仅在页面内模拟。
- 后续用户批准接入正式 React 组件，先创建 `codex/battle-paper-panels` 分支。棋钟采用现有米色，当前行棋方变黄；保留计时规则、棋局逻辑及 API。

## Runtime integration
- 移动端独立紧凑布局：信息条由 158px 改为 94px，采用立绘／身份技能／棋钟统计三列；取消手机铭牌倾斜及技能搭叠，保证狭窄宽度可读。棋盘结合 dvh 和安全区计算尺寸，行间距 8px。440×956、440×800、390×844 的 RoomScreen clientHeight 与 scrollHeight 相等，全部操作一屏可见；360×640 保留最小棋盘并滚动，棋盘上下各 8px 间隙，无横向溢出。桌面 owner 未变。
- 第三次视觉调整：取消等宽纵向堆叠，身份铭牌与技能签缩进、轻微反向倾斜并搭叠棋钟边缘，双方镜像错位。隐藏 Bright School 计时条，保留数值时间、读秒次数和原计时语义，提子统计列置于数字右侧。360×640 浏览器确认上下间隙仍为 16px、无横向溢出；Arial 延续 DESIGN.md 的数字可读性约定，未添加忽略规则。
- 第二次修正：原先最小棋盘行仍与剩余高度分配耦合；改为四个 max-content 自然行，158px 信息条、屏宽决定的棋盘高度、16px 行间距。360×640 与 390×844 实测棋盘上下均留 16px，页面滚动访问操作区。恢复大幅出框立绘、姓名纸贴和倾斜背板，米色／黄色棋钟及角色色技能区增加纸纹与明暗；立绘样式拆为独立 owner。22 个 PlayerInfo 相关测试、lint、build、built CSS 检查通过。Arial 为已记录的棋钟可读性字体，旧配色及旧圆角提示不属于此次新增问题，未增加忽略项。
- `PlayerInfo` 增加棋钟统计组合容器，保留原计时器、装扮解析、队际阵容、观战视角及技能说明交互；黑化剧情外观独立。
- 最终 Bright School 样式拆为桌面与竖屏两个文件。130px 手机信息条给角色出框与阴影留出空间，短屏保留至少 254px 棋盘行并允许纵向滚动。
- 设计检查：图片 src 来自既有 `playerCandyPortraitProps`，缺失 src 提示为展开属性误报。旧基础文件及测试中的配色提示不属于新增变更。棋钟黄色沿用原回合色；清晰数字字体和铭牌纸角是获批样板接入，补入 DESIGN.md，不添加忽略规则。

## Verification
- 正式组件验证：42 个相关测试、lint、生产构建和 built CSS 检查通过；系统设计 HTML 已生成。1280×900、390×844、360×640 实际 RoomScreen 检查，无横向溢出；换手确认米色／黄色和棋钟阴影对调。短屏改为纵向滚动，避免 254px 最小棋盘穿入信息条。
- 第二版 1280px 与 390px 浏览器截图检查通过，姓名及棋钟无内容溢出；新增圆角用于独立样板的拼接面板，属于有意视觉探索，未改变正式设计系统。去掉多余单侧彩色粗边，不新增 lint 忽略。
- 1280px 桌面与 390px 竖屏全页截图检查；素材加载正常、无横向溢出。
- 换手改变角色抬起状态；棋盘试下增加手数并换手；出框开关与技能演示可用。
- 字体 Marker/Digits 是现有本地项目字体的样板别名；角色浅底色和棋盘木色服务于明确的视觉探索，非正式设计系统新增。移除无意义编号；不写忽略规则。
- 本样板允许竖向滚动，顶部演示控件不属于拟接入的对弈界面。
