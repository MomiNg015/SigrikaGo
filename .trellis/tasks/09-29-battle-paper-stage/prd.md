# 对弈信息区立绘出框样板

## Goal
独立 HTML 交互样板探索更有层次的对弈信息区。用户希望人物立绘越过卡片区域，不再困在边框中。

## Design
- 用户认可出框效果，第二版仅调整信息面板：身份铭牌、深色棋钟与统计底座、角色色技能按钮；保留出框立绘。
- 保留 Bright School 纸面、深棕描边与本地透明 Q 版立绘；角色背板、立绘、前景信息纸分层。
- 桌面双侧大立绘，手机竖屏上下横向信息条，立绘从左上探出。
- 提供出框开关、换手、棋盘试下、技能演示与重置，数据仅在页面内模拟。
- 正式 React 组件、棋局逻辑及 API 不变。

## Verification
- 第二版 1280px 与 390px 浏览器截图检查通过，姓名及棋钟无内容溢出；新增圆角用于独立样板的拼接面板，属于有意视觉探索，未改变正式设计系统。去掉多余单侧彩色粗边，不新增 lint 忽略。
- 1280px 桌面与 390px 竖屏全页截图检查；素材加载正常、无横向溢出。
- 换手改变角色抬起状态；棋盘试下增加手数并换手；出框开关与技能演示可用。
- 字体 Marker/Digits 是现有本地项目字体的样板别名；角色浅底色和棋盘木色服务于明确的视觉探索，非正式设计系统新增。移除无意义编号；不写忽略规则。
- 本样板允许竖向滚动，顶部演示控件不属于拟接入的对弈界面。
