# Visual Direction Review

## Current effect diagnosis

- The dominant conic-gradient ring is circular and therefore unrelated to the orthogonal Go grid.
- The dashed white orbit adds a generic loading/radar association.
- Box-shadow particles have no shared origin or travel path, so the effect reads as random confetti.
- All seven hues have equal visual authority; Aemeath's cyan/pink electronic identity is missing.
- The source intersection is not the compositional anchor once the ring expands.

## Selected direction

- Use a tiny white/cyan source flash to make the played intersection the unmistakable origin.
- Send horizontal and vertical spectral traces outward through transforms, aligned to the board lines.
- Represent seven hues as discrete pixel echoes with staggered offsets, not a smooth circular gradient.
- Use cyan and magenta glows as the supporting electronic material while keeping all seven rainbow colors visible.
- End quickly and cleanly so the board regains visual priority.

## QA inventory

1. Desktop peak frame: source, orthogonal propagation, seven discrete colors, stone visibility.
2. Desktop late frame: clean exit with no stuck overlay.
3. Portrait-mobile peak frame: same motif remains legible without overwhelming adjacent intersections.
4. Reduced-motion frame: compact static grid response; no animation.
5. Interaction safety: root and children remain pointer-transparent.
6. Exploratory edge cases: effect on a board edge/corner; white and black stones remain readable.
