# 设计爱弥斯用户名背景三版

## Goal

沿用本轮已确认的紧凑用户名背景结构，为爱弥斯设计三版新的角色专属候选，并把用户选定的 v2 A「纸翼航标」正式接入现有爱弥斯成就铭牌：左侧以可辨识的纸飞机取代等级块，中部完整承载运行时用户名，右侧以粉青流光自然收束。

## Requirements

- 用户先要求一版，看到 A「纸信启航」后追加两版，因此本任务最终交付恰好三版候选，覆盖角色铭牌工作流默认的四方向探索数量。
- 新增 B/C 两版都必须让粉色与天蓝色成为可见主色，不能再像 A 一样只有少量粉色点缀。
- 用户否决首轮 A/B/C 的整体风格：它们逐渐变成横向插画、散开的羽片/像素或细航线，偏离最早参考的紧凑一体用户名铭牌。
- v2 完全重新起稿，继承西格莉卡三版已经得到用户认可的感觉：柔和手绘能量边界、完整连续轮廓、左侧强识别核心、中央稳定深色用户名载体、右侧明确但不独立的光效收束。
- v2 只继承西格莉卡候选的结构密度、边缘处理和一体感，不复制其紫金配色、星形符核、符文或魔法语言。
- v2 三版统一使用粉色与天蓝色双主色，深青蓝只作为中央用户名对比底；不得重新变成浅色空白横幅、硬质电竞框、散落贴纸或过细线框。
- 角色事实以 2026-07-17 已完整读取并保存在仓库的库街区官方档案研究为主；2026-08-11 复核官方条目仍在线，但公开抓取只能取得动态页面壳。
- 保留爱弥斯的天青、冰白、暖粉与极少量星金色；不得直接复用达妮娅的珠光泡或西格莉卡的紫金符文语言。
- 左侧主元素使用“珍贵纸飞机＋电子雪绒/数据残影”的一体化轮廓，不使用罗马数字、等级章、头像或通用圆形徽章。
- 中段是低细节用户名载体，不预留独立称号、徽章或段位区域。
- 右侧使用短促的像素雪绒、纸飞机航迹与星点自然收束，不做第二个同权端头。
- 结构参考用户最早给出的竞技铭牌比例与阅读效率，但不复制机甲框、文字、数字、品牌或游戏 UI。
- 爱弥斯具有机械/数据能力，但整体应轻盈、活泼、亲和；允许少量纸折装甲切面，不做厚重机械壳或冷硬电竞框。
- 不出现围棋盘、棋子、棋格、落子轨迹、奖杯、桂冠、数字 `100`、角色名字或烘焙用户名。
- 候选使用可去除的纯色底，完成去底后统一落在 `1125 x 240` 画布，并生成 `150 x 32` 用户名预览。
- 候选生成阶段按当时 owner 预留约 `42px / 20px` 用户名安全区；最终游戏内学生证复核后，正式运行 owner 在保持 `62px` 安全宽度不变的前提下重分配为 `34px / 28px`。

## Definition of Done

- 角色研究、提示词、源图、透明候选、运行时缩略图和用户名预览均留存在本任务。
- 正式接入只覆盖爱弥斯既有 PNG 与精确资产 CSS；奖励数据、成就条件和通用 `UserIdentity` 保持不变。
- 完成运行态预览后停在用户视觉验收门，不自行提交、推送或合并。

## Technical Approach

使用内置图像生成工具分别生成三张无文字、单一横向铭牌的纯绿幕源图；随后在任务目录去底、整体等比缩放并居中至 `1125 x 240`，生成 `150 x 32` 缩略图与真实安全区用户名预览。候选阶段不改变生产 URL。

## Decision (ADR-lite)

**Context:** 爱弥斯已有一张天青主色的正式铭牌，使用舞台纸扇、大面积锐角速度面、两架纸飞机和像素雪绒圆脸。用户在确认西格莉卡与达妮娅的新紧凑用户名背景方向后，要求爱弥斯也设计一版。

**Decision:** 新稿仍以纸飞机作为最强文字证据，但将其改为左侧单一识别锚点，并与不封闭的电子雪绒/数据残影结合；中部改为更安静、柔和的天青数据丝带，右侧只留短航迹、碎像素和星点收束。保留少量纸折切面表达她的机械/数据能力，不重复旧稿的舞台扇面、圆脸雪绒与双飞机端头。

**Consequences:** 新候选能够沿用当前 `150 x 32` 用户名槽与角色色彩，但在用户选择前不会覆盖正式资源或改动 CSS。

**Concept result:** 内置图像生成得到单一绿幕源图；去底后统一缩放至 `1125 x 240`。最终 Alpha bounds 为 `x=40..1084`、`y=14..226`，安全区 `x=315..975` 占画布 `58.67%`，透明角点与四边最小边距校验通过。

**Additional concepts:** 用户要求再增加两版并强化粉色与天蓝色。B「雪绒回信」用双色雪绒翼片、小纸飞机和柔软波形载体，Alpha bounds 为 `x=86..1039`、`y=8..231`；C「双频长航」用蓝粉双纸飞机残影、修长双航线和合流箭尖，Alpha bounds 为 `x=40..1084`、`y=25..215`。两版均保留 `x=315..975` 安全区并通过透明角点与边距校验。

**Style reset:** 用户指出三版与最早参考以及西格莉卡成功稿的感觉越来越远。首轮 A/B/C 因此全部降级为过程稿，不在其上继续换色或修边；v2 以西格莉卡三张高分辨率候选作为“结构与手绘密度参考图”，重新生成三个爱弥斯方向。

**v2 result:** A「纸翼航标」、B「粉蓝数据结」、C「电子雪绒共鸣」均完成绿幕去底、统一等比缩放、`1125 x 240` 候选与 `150 x 32` 用户名预览。首张 C 因生成成四角星核心被主动判废并保存在 `rejected/`，重新生成的 C 改为不对称纸折雪绒碎片与小纸飞机。A/B 为避免左侧核心侵入真实 `42px` 用户名起点，整张等比画面统一左移至 `40px` Alpha 边距，未拆分或拉伸元素，也未手工移动预览文字。

**Selection:** 用户回复 `1`，正式选择 v2 A「纸翼航标」。生产接入保留现有 `reward-aemeath-spark-100-wins-nameplate` 资产 ID、`150 x 32` 精确槽位和 `42px / 20px` 用户名安全内边距，仅替换 PNG、精确 owner 的深色载体文字处理，以及与纸飞机、上下粉青边流和右尾闭合绑定的局部动效。

**Production result:** 正式 PNG 已替换为所选候选，Alpha bounds 复验为 `x=40..979, y=8..231`。精确 owner 使用冰白斜体 UI 粗字、深青暗投影与柔和天青辉光；纸飞机航迹、上下粉青边流、两条右尾细光与三枚稀疏方形闪点均只改变 `transform` / `opacity`，不再使用径向雪绒核、缩放呼吸或宽泛速度面。后续针对游戏内可读性与视觉高度的反馈，将 Sigrika、Danya、Aemeath 纳入同一个最终精确 owner：三者共享缩放后的 `150 x 32` 槽位、斜体 `800` UI 文字骨架和可见局部光效溢出，颜色/投影仍按角色区分；Danya 实测 Alpha 高 `216px`，Sigrika/Aemeath 为 `224px`，因此只修复裁切与文字赢家，不纵向拉伸素材。最终 Aemeath 定位修正不再全局同步移动文字与背景：内边距由上一轮 `45px / 17px` 改为 `34px / 28px`，使用户名相对素材左移 `11px * scale`；仅在真实首页学生证中把完整铭牌右移 `12px * scale`。Danya 继续使用增强后的原有 Alpha 投影以及珠光、折射、回卷和梦光点明暗区间，结构和动效家族不变。桌面、窄屏、竖屏及减弱动效预览均完成，正式文件保持在单文件 `6000` 字节质量上限以内。

**Legal-name clipping follow-up:** 真实 `PlayerPlaque` 中 `Alice_12` 与 `星辉旅者` 都未触发省略号，但 Chromium 测得斜体右侧墨迹分别比文字 advance box 多伸出 `2.330px / 2.320px`，此前被 `.user-identity-name { overflow: hidden }` 裁掉。最终共同精确 owner 保留原 overflow/ellipsis，增加 `3px * scale` 行末绘制缓冲并用等量负外边距抵消布局宽度；首页仍为 `168 x 35.83px` tag 和 `15.68px` 字号，文字中心与安全区不变。

## Out of Scope

- 修改爱弥斯奖励或成就种子。
- 替换其它角色铭牌素材、修改通用用户名 DOM 或称号/徽章逻辑。
- 提交、推送或合并。
- 继续细化或生产接入首轮 A/B/C。
