# 重写黑化西格莉卡“对抗虚无”梦境剧情

## Goal

将西格莉卡彩虹豆豆跳跳糖的占位剧情替换为完整的《棋魂》阅读线、梦境黑化挑战和胜负恢复分支。主题承认期待压力、天赋差距、慕强与竞技残酷真实存在，但反驳“因此一切都没有意义”的绝对化推论。

## Review Gate

- 当前阶段只提交完整剧情审阅稿，不修改运行代码、状态机、数据库或管理员默认快照。
- 必须先取得用户对剧情文案的明确确认，之后才能开始实装与测试。

## Requirements

- 第 1–7 次依次覆盖相遇与借力、`sai` 与自己的棋、院生连败、定段失常、佐为对塔矢名人、佐为消失与重新落子、北斗杯组队及开赛前夕；第 7 次不得透露最终赛果。
- 第 8 次才读完北斗杯：日本队负于中国与韩国，进藤光两战皆负。现实西格莉卡只作克制感慨，吃糖后玩家视野模糊并进入梦境。
- 黑化西格莉卡是玩家悲观思考的投影，不是真实西格莉卡；剧情保持星炬学院世界观内，不出现项目发布、成本、观众、游戏脚本、NPC 或第四墙内容。
- 黑化开场依次把期待、天赋、慕强、竞技残酷绝对化，以“只要不落子，就永远不会输”发出决战邀请。
- 失败分支采用冷静判决式语气，逐条用败局强化四个负面观点；玩家无法反驳并在梦中昏倒。
- 胜利分支先让黑化西格莉卡承认现实没有被一盘胜局改变，再进行四轮玩家回答。每轮有两个语气不同但立场一致的选项，并在一个反应节点后汇合；不承诺努力必然成功或社会公平。
- 两个分支分别进入 `recovery-win-wake` / `recovery-loss-wake`。退出黑化后，玩家醒在活动室，西格莉卡担心低血糖并提议找陆医生，达妮娅怀疑玩家通宵。
- 胜利后玩家主动提出“陪我下一局吧”；失败后只说“我有点累”并回避棋盘。两边都不留下超自然证据。
- 保留现有计数、房间、结果与恢复状态机，不改变 API、数据库字段、决战规则、奖励或资源体系。

## Technical Approach

- 扩写 `defaultRainbowBeanCandyStoryDraft("sigrika")`，保留现有语义入口和前七次汇入共享糖果效果的合同。
- 在共享剧情节点常量中新增胜负醒来节点 ID。
- 恢复剧情通过现有 `onNavigate` 拦截“梦中倒下 → 醒来”：先执行恢复接口和退出黑化转场，成功后把当前脚本起点切到醒来节点并清除 `onExit`；失败则留在倒下节点以便重试。
- 同步本地 `StoryScript` 草稿/发布内容，并仅导出 `item.rainbow-bean-candy.sigrika` 到管理员默认快照，避免吸收其它后台配置漂移。
- 更新系统设计中的西格莉卡糖果剧情与恢复转场事实并重新生成 HTML。

## Acceptance Criteria

- [ ] 第 7 次只有北斗杯选拔/开赛前信息，第 8 次才出现最终败局。
- [ ] 第 1–7 次均能进入共享效果，第 8 次必经 `corruption-climax`。
- [ ] 胜利分支包含四轮双选项并逐轮汇合；失败分支完整呈现四个负面命题。
- [ ] 胜负分支均只在恢复接口成功后进入正常界面的醒来段；失败可重试且结尾不重复恢复。
- [ ] 默认脚本、管理员快照草稿与发布内容一致且可通过剧情内容校验。
- [ ] 相关测试、文档生成与可运行的仓库质量门通过；无关既存失败单独报告。

## Out of Scope

- 新立绘、音频、CSS、奖励、成就、第三结局或决战规则调整。
- 把现实创作经历直接写入剧情。
