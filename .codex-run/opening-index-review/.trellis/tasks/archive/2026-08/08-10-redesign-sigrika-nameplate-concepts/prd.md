# 重设计西格莉卡用户名背景概念

## Goal

重做西格莉卡的成就用户名背景，使用户名背景本体承担完整的角色识别和横向构图，不再为独立徽章、称号或段位块预留视觉区域；用户已选择 A「辉星符印」，本轮继续将其制作成正式透明资产、接入现有精确资产 owner，并验证真实游戏界面。

## Requirements

- 参考用户提供的九张横向游戏铭牌：采用“左侧高识别角色物件/元素 + 中央用户名载体 + 右侧收束”的紧凑结构。
- 删除旧思路中对独立徽章、称号、右侧等级/数字标记的视觉预留；铭牌必须作为一个连续整体。
- 左侧不得出现罗马数字、段位数字或字母徽标，改为西格莉卡的标志性物件或元素。
- 三版都要基于项目文本证据，但本轮只使用“星辉符文”、星光、暖明金辉和角色头饰中可见的星形符印语言；不得把技能的作用对象转画为围棋图案。
- 任何围棋盘、棋子、棋格、交叉点、落子、棋谱或类似网格的元素都禁止出现。
- 西格莉卡不是机甲风角色：装甲片、机械夹具、机甲底盘、金属喷口、硬质电竞外框和机械连接结构都禁止出现。
- 铭牌轮廓应由柔和的符文织带、手绘魔法墨迹、星辉术式、半透明光幕或流动的金色咒纹自然形成；边缘可以清晰，但不能读作金属机框。
- 符文必须成为三版的主要识别语言，而不是只在硬边框上点缀少量星形。
- 三版不能只是换色，至少在左侧核心轮廓、载体框架、尾部收束和负空间策略上形成明显差异。
- 角色主色采用项目角色数据中的暖橙色，并由角色立绘的白、金、深紫与少量薄荷青作可见设计事实补充。
- 候选图不烘焙用户名、角色名、字母、数字、品牌或 UI 标签；中央区域必须保留给运行时 DOM 用户名。
- 所有候选保持现有西格莉卡专属铭牌 `1125 x 240`、运行时 `150 x 32` 的 `4.6875:1` 比例和近似安全区。
- 只将九张用户图片作为结构与节奏参考，不复制其中的品牌、段位标识、文字或具体造型。

- [x] 三版在结构上可一眼区分，并在缩小到 `150 x 32` 后仍保留左侧识别轮廓。
- [x] 候选只保存在当前 Trellis 任务内，不覆盖生产资源，不修改 CSS 或奖励数据。

- [x] 将旧柑橘/日轮动效替换为与辉星符印一致的持续符核光、局部符文呼吸和稀疏星点；连续动画仅修改 `transform`/`opacity`。
- [x] 保持标题、独立徽章、成就条件、奖励 ID 和所有通用铭牌不变。

- [x] v3 虽已改为横向位移，但整块高密度多边形载体仍被用户判断为“实体光球从左边到右边”，因此该实体载体已移除。
- [x] v4 将横穿载体的光拆为三条不足 `2px`、彼此留有透明空隙的断续金/薄荷细流，并保留上下轮廓跟流和右端分叉甩线；主动画不含缩放或填满中心的移动色块。

## Definition of Done

- 角色证据矩阵、证据到设计映射、视觉语言卡和三版提示词已留存在任务研究目录。
- 三版候选源文件与统一比例展示图保存在任务目录。
- A「辉星符印」已作为正式透明资产接入，真实 DOM 用户名、动效与多界面静态合同完成验证；游戏内最终观感等待用户确认。

## Technical Approach

概念阶段使用内置图像生成工具生成三个独立方向；用户的九张截图全部标记为“结构参考图”，不是编辑目标。A 入选后，仅编辑其外部工作底并通过色键软遮罩生成透明 RGBA，再整体等比缩放到 `1125 x 240` 正式画布；运行时继续复用现有 `UserIdentity` DOM 和精确资产 owner，任务预览直接导入真实项目 CSS。

## Decision (ADR-lite)

**Context:** 旧版西格莉卡铭牌采用柑橘、日轮和长飘带构图，用户认为没有充分利用用户名背景，并要求参考更紧凑的游戏铭牌结构。首轮参考图提炼过度继承了硬质装备框架，并错误加入围棋元素。

**Decision:** 把左侧等级章位置改为西格莉卡的星辉符文核心，取消所有独立称号/徽章/段位预留；第二轮完全排除围棋与机甲语言，以符文织带、魔法墨迹和星辉术式探索三个柔和方向。

**Selection update:** 用户选择 A「辉星符印」继续细化。概念预览中的用户名必须复用当前精确资产 owner 的真实布局：运行时 `150 x 32`，左内边距 `39px`、右内边距 `18px`，文字在剩余内容区居中；不得为了概念展示把用户名手工左移到星符印上。

**Integration update:** 用户已明确要求把 A 应用到游戏中试用。现在允许覆盖西格莉卡现有 `semantic-nameplate.png`、重写其精确资产 CSS/动效、更新合同测试与系统设计文档；仍不改变奖励数据和通用 `UserIdentity` DOM。任务侧提供真实样式预览，游戏内主观视觉由用户自行验证。

**Motion refinement v2 (rejected):** 用户反馈首轮正式动效不明显且尾部没有光效后，曾提高持续轮廓光、左侧符核和三条符文轨迹的幅度，并在尾部增加呼吸光晕。用户随后明确指出该结果像“一个光蛋变大变小”，因此 v2 只作为过程证据保留，运行时实现完整撤回其缩放脉冲、椭圆光晕和径向尾光。

**Motion refinement v3 (rejected):** 回到横向位移后，曾用一个窄幅高密度多边形载体从左向右穿过中央区域。它虽然没有缩放和径向渐变，但在连续运动中仍读作“实体光球从左边到右边”，因此只保留为过程证据。

**Motion refinement v4:** 横向主光改为三条不足 `2px` 的开放细丝：三条线长度、垂直位置和亮点不同，之间完全透明；它们与另外三条上下符文轮廓线共同向右推进，最后由右尾两条金紫/薄荷紫细线分叉甩出。所有连续关键帧只修改 `transform` 与 `opacity`，不再存在填满中心的移动多边形、`scale(...)`、局部径向光团、整牌雾化，也不新增 DOM或移动用户名。

**Consequences:** 正式图必须通过 Alpha/安全区验证；旧柑橘、日轮和风尾动效语义将被符印、符文呼吸和稀疏星辉替代。若真实界面暴露位置或缩放问题，应优先修改精确资产 owner，不污染通用铭牌几何。

## Out of Scope

- 本轮不修改 `UserIdentity` DOM、标题/徽章数据结构、装备逻辑、成就条件或奖励元数据。
- 本轮不为其它角色同步设计。
- 不重设计通用铭牌、丹雅或艾梅丝铭牌。
