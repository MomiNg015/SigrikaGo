# 新增神奇小钟表招募加速道具

## Goal

新增可由邮件发放、在招募倒计时等待界面使用的消耗型道具“神奇小钟表”。玩家使用后，当前招募的剩余时间通过明确的加速动画缩短到 3 秒，同时为未来更多招募加速道具保留清晰的扩展边界。

## What I Already Know

* 道具名称：神奇小钟表。
* 道具描述：只要一拨指针就能加速现实时间流逝，很方便吧~
* 使用入口位于招募倒计时等待界面。
* 使用效果是让当前招募剩余倒计时缩短至只剩 3 秒。
* 使用过程需要有倒计时加速动画效果。
* 暂时不进入商店；未来计划通过邮件发放。
* 道具图片暂用闹钟图标占位。
* 现有招募倒计时以服务端 `RecruitmentTask.readyAt` 为权威来源，修改后天然支持刷新与重连恢复。
* 项目已有仅开发环境可见的 5 秒快速计时按钮和接口，但它不消耗道具；本功能可复用其窄入口并改成正式的服务端事务。
* 现有邮件附件会在领取时把道具数量写入 `ownedItems`，后台邮件道具选项来自道具目录。
* 已有“可被邮件/仓库识别、但玩家商店隐藏”的内置招募道具模式。

## Confirmed Constraints

* “缩短至 3 秒”只影响当前这一笔正在等待的招募，不影响账号的其他计时器。
* 道具是有库存数量、使用后会扣除 1 个的消耗品。
* 服务端应权威地确认库存扣除与招募完成时间更新，避免刷新页面后效果丢失或重复消耗。
* 本次不会向现有玩家自动赠送神奇小钟表；管理员可通过本次打通的邮件附件功能发放。

## Open Questions

* 无。

## Requirements

* 在招募等待界面展示神奇小钟表的可用入口和当前持有数量。
* 成功使用后，当前招募剩余时间被缩短至 3 秒，并播放倒计时加速动画。
* 本次不在商店中出售或展示该道具。
* 使用闹钟图标作为临时道具图。
* 本次同步打通正式邮件发放链路：后台邮件附件可以选择神奇小钟表，玩家领取后增加对应库存。
* 神奇小钟表作为隐藏且不可购买的目录道具存在，不能从玩家商店浏览或购买。
* 神奇小钟表仅适用于普通倒计时招募；带专属演出的特殊招募不提供使用入口。
* 普通招募剩余时间不超过完整 6 秒展示窗口时，神奇小钟表入口直接隐藏，不消耗道具，避免使用后反而延长等待。
* 使用入口为单击立即使用，不弹出二次确认。
* 使用按钮右上角显示神奇小钟表当前持有数量角标。
* 点击发起请求后立即锁定按钮，服务端成功返回后播放加速表现并同步扣减后的数量，避免连续点击重复消耗。
* 在普通招募剩余时间大于完整 6 秒展示窗口时，即使库存为 0 也显示神奇小钟表按钮和 `0` 数量角标，但按钮整体变灰且不可用。
* 成功使用后播放完整 3 秒的“拨针快进”动画：闹钟指针快速旋转，倒计时数字带残影高速跳动并收束到 `00:03`，倒计时面板持续出现时间波纹，随后恢复正常逐秒倒计时。
* 本功能不单独提供 `prefers-reduced-motion` 或其他减少动态效果替代模式。
* 3 秒加速动画结束并明确显示 `00:03` 后，再开始完整的三秒正常倒计时；动画时间不占用这三秒。
* 动画期间关闭窗口、刷新或断线时，不重播动画、不退还道具、不恢复原倒计时；重新进入后直接显示服务端权威剩余时间，若已经结束则显示可领取状态。
* 同一笔普通招募最多成功使用一次神奇小钟表；首次成功后服务端持久记录已加速状态，入口立即隐藏，刷新或重进也不能再次使用。
* 神奇小钟表正常显示在玩家仓库中，展示名称、描述、闹钟图标和持有数量，但卡片不显示任何使用按钮；唯一使用入口位于符合条件的普通招募倒计时界面。
* 为 3 秒拨针快进动画制作并播放同步的“时间快速流逝”专用音效；音效只在服务端确认使用成功后播放，并服从现有音效音量与静音设置。
* 专用音效采用“魔法钟表快进”方向：密集滴答与齿轮拨动逐渐加速，叠加轻盈的时间掠过声，最后以清脆咔嗒收束到 `00:03`；总长约 3 秒、不可循环、无语音、无刺耳闹铃。
* 不向现有玩家自动发放道具；获得方式仅为管理员邮件附件，直到未来另行扩展。

* [x] 页面刷新、断线重连后仍以更新后的服务端结束时间继续倒计时，不恢复到原倒计时。
* [x] 使用过程有可感知的倒计时加速动画，并防止重复点击导致多次消耗。
* [x] 商店中不出现神奇小钟表。
* [x] 道具名称、描述和闹钟占位图在相关界面正确显示。
* [x] 后台发送邮件时可以选择神奇小钟表作为道具附件，玩家领取后库存按附件数量准确增加。
* [x] 带专属演出的招募过程中不显示神奇小钟表入口，也不会调用加速接口或消耗库存。
* [x] 普通招募剩余时间不超过完整 6 秒展示窗口时不显示使用入口；若请求与倒计时发生竞态，服务端拒绝请求并保证库存不变。
* [x] 可用入口的按钮右上角显示准确的持有数量，单击后不出现确认弹窗。
* [x] 请求处理期间按钮不可再次触发；快速连点和并发请求最多成功一次、最多扣除一个道具。
* [x] 普通招募剩余时间大于完整 6 秒展示窗口且库存为 0 时，按钮和 `0` 角标仍可见，但按钮呈灰色禁用态且无法触发请求。
* [x] 成功使用时，加速动画持续约 3 秒，包含指针旋转、数字残影快进、时间波纹和向 `00:03` 的明确收束。
* [x] 动画结束时先稳定显示 `00:03`，此后才按正常节奏倒数完整的三秒并进入可领取状态。
* [x] 动画期间关闭窗口、刷新或断线后重新进入，不会重复播放或重复扣除道具，并继续显示权威剩余时间或可领取状态。
* [x] 同一招募任务首次成功使用后，后续请求均被服务端拒绝且库存不变；刷新和重新登录后入口仍保持隐藏。
* [x] 仓库能够展示神奇小钟表的名称、描述、图标和数量，但该道具卡片不渲染使用按钮。
* [x] 成功动画播放与其长度匹配的专用时间快速流逝音效；失败、零库存、特殊演出和恢复进入时均不播放。
* [x] 音效包含可辨识的加速滴答、齿轮拨动、轻盈时间掠过声及结尾咔嗒，约 3 秒且不循环，没有语音或刺耳闹铃。
* [x] 新旧用户默认持有数量均为 0，管理员可通过邮件发放任意正整数数量。

## Technical Approach

* 使用稳定道具 ID `magic-clock`，在招募领域目录中标记为“等待阶段加速道具”，与用于发起招募的招募券分离。
* 为该道具提供通用闹钟占位资源，使招募按钮、仓库和邮件附件展示一致；正式美术以后可保持 ID 不变直接替换。
* 建立隐藏且不可购买的目录记录，供仓库与后台邮件选择器读取；玩家商店接口必须始终过滤该道具。
* 将现有开发环境快速计时能力收敛为正式的道具使用事务：校验普通待完成任务、未使用过、剩余时间大于完整 6 秒展示窗口且库存大于 0，然后原子地扣除一个道具、记录已加速标记并更新 `readyAt`。
* `readyAt` 包含 3 秒动画窗口和其后的完整 3 秒；响应携带更新后的用户、道具数量与任务状态，前端以服务端时间为权威。
* 在 `RecruitmentTask` 持久化加速使用时间或等价状态，运行时建表兼容逻辑、Prisma 模型和数据库迁移保持一致。
* 前端在普通 `pending`、未加速、剩余时间大于完整 6 秒展示窗口时展示闹钟按钮；库存为 0 时保留灰色禁用按钮，特殊演出或已加速任务隐藏按钮。
* 成功响应后同步播放一次本地 3 秒视觉动画与专用音效；失败时不播放动画或音效、不扣库存，恢复按钮并展示既有错误通知。
* 动画中断后不恢复本地演出，重新进入时仅按服务端任务状态渲染。
* 使用 `sound-effects` 工作流生成约 3 秒的一次性音效，落为仓库现有音效管线可直接播放的压缩资源，并接入资源预加载与音效音量控制。
* 桌面和竖屏移动端共同验证按钮、角标和动画的布局；后台管理界面仅按桌面布局验证。

## Out of Scope (Explicit)

* 将神奇小钟表上架商店。
* 绘制正式道具美术资源。
* 改变招募完成后的既有领取/揭晓流程。
* 为神奇小钟表加速动画提供减少动态效果版本。
* 自动赠送、签到赠送、活动掉落或其他获取渠道。

## Decision Log

### D1 — 本次打通邮件发放

* **Decision**：神奇小钟表在本次 MVP 中即作为后台邮件的正式可选附件。
* **Consequences**：需要提供隐藏、不可购买的稳定道具目录元数据，并覆盖邮件领取入库测试；玩家商店仍不得展示它。

### D2 — 不加速特殊演出招募

* **Decision**：神奇小钟表仅对普通倒计时招募生效，带专属演出的特殊招募不显示入口。
* **Consequences**：保留现有特殊演出的时间轴、音效同步和中断恢复契约；服务端仍需拒绝绕过界面发起的特殊招募加速请求。

### D3 — 剩余不超过完整 6 秒展示窗口时隐藏入口

* **Decision**：当普通招募的服务端剩余时间不超过完整 6 秒展示窗口时，界面直接隐藏神奇小钟表入口。
* **Consequences**：避免道具把原本更短的等待反向延长；服务端必须再次校验剩余时间以处理客户端显示后才跨过阈值的竞态。

### D4 — 单击使用并显示库存角标

* **Decision**：点击按钮立即使用，不弹二次确认；按钮右上角显示持有数量角标。
* **Consequences**：交互更直接，但必须在点击瞬间锁定入口，并由服务端事务保证并发幂等边界，避免误触后的连续重复消耗。

### D5 — 零库存时显示灰色禁用按钮

* **Decision**：库存为 0 时保留神奇小钟表入口和 `0` 角标，但按钮整体变灰且不可用。
* **Consequences**：玩家能提前理解这一能力的存在；零库存态不能发出网络请求，并需要明确的禁用语义和无障碍标签。

### D6 — 采用 3 秒拨针快进动画且不提供减弱动效模式

* **Decision**：使用完整 3 秒的指针快速旋转、数字残影快进和面板时间波纹组合动画，最终收束到 `00:03`；不为本功能提供减少动态效果模式。
* **Consequences**：需要在桌面与竖屏移动端保持数字可读、动效不溢出倒计时面板，并避免动画期间出现可重复触发的按钮状态。

### D7 — 三秒动画结束后再完整倒数三秒

* **Decision**：3 秒加速动画不计入最后三秒；动画收束到 `00:03` 后才开始正常倒数。
* **Consequences**：一次成功使用从演出开始到招募就绪约需 6 秒；服务端权威结束时间需要包含动画演出窗口与三秒倒计时，前端显示必须与该时间点保持一致。

### D8 — 中断后不重播动画

* **Decision**：关闭窗口、刷新或断线会终止本地动画；重新进入后直接服从服务端倒计时或可领取状态，不重播、不退款。
* **Consequences**：道具扣除和结束时间更新必须在同一服务端事务中完成；客户端动画只是一次性的成功反馈，不能作为状态权威。

### D9 — 每笔招募最多使用一次

* **Decision**：一笔普通招募最多成功消耗一个神奇小钟表，成功后永久隐藏该任务的使用入口。
* **Consequences**：招募任务需要可持久化的加速使用标记；服务端事务必须同时校验标记、扣除库存、更新结束时间并写入标记。

### D10 — 仓库只展示、不提供按钮

* **Decision**：仓库显示神奇小钟表完整资料和库存，但卡片不显示使用按钮。
* **Consequences**：仓库道具负载需要区分“不可在此使用且不展示操作”的招募辅助道具，不能沿用现有统一渲染灰色按钮的唯一分支。

### D11 — 制作时间快速流逝专用音效

* **Decision**：为 3 秒拨针快进动画制作同步的时间快速流逝专用音效，并只在服务端确认道具使用成功后播放。
* **Consequences**：音效方向为逐渐加速的密集滴答与齿轮拨动、轻盈时间掠过声、结尾清脆咔嗒；需要新增音频资源、预加载与播放接线，服从现有音效音量/静音设置；动画中断时停止，刷新恢复时不重播。

## Technical Notes

* 当前工作区已有多项未提交改动，本任务必须保持窄范围并避免覆盖无关 WIP。
* 需要从现有代码确认招募计时权威来源、库存/邮件附件模型、道具展示约定和等待界面动画所有者。
* 调研记录见 `research/existing-recruitment-item-flow.md`。
* 新道具属于招募等待阶段的辅助道具，不是用于发起招募的招募券；目录模型必须区分这两类用途，避免它进入空闲阶段的招募券选择列表。
* 为确保刷新后仍不能重复使用，不能只依赖客户端锁或剩余时间阈值，需要在 `RecruitmentTask` 上保存加速使用状态并同步迁移/运行时建表兼容逻辑。
