# 爱弥斯彩虹豆豆跳跳糖剧情与彩虹落子模式

## Goal

为爱弥斯补齐彩虹豆豆跳跳糖成功/拒绝剧情，并在成功使用后提供可见、无数值加成的“彩虹落子模式”。

## Requirements

* 爱弥斯使用彩虹豆豆跳跳糖时有 35% 概率拒绝，65% 概率接受。
* 拒绝时不消耗道具、不应用效果；接受时消耗 1 个道具并应用爱弥斯专属状态。
* 成功与拒绝剧情的台词、玩家选项和叙述文字严格采用用户在本任务中给出的定稿。
* 所有标注“角色区域留空”的叙述节点都保持空 `speakerName` 与空 `characterId`，剧情窗口不得显示“旁白”字样或角色立绘。
* 成功后，爱弥斯落子时在交叉点播放约 0.6 秒的七彩像素光纹；棋子本身仍保持正常黑白外观，不改变棋力或数值。
* 彩虹光纹只由带有效果的爱弥斯本人落子触发，不应由对手落子、非落子事件或其他角色触发。
* 爱弥斯完成一盘有效对局后清除该状态，与已有糖果效果的清理边界一致。
* 仓库角色选择、角色效果展示、服务端持久化与默认后台剧情快照都要识别爱弥斯的新状态与剧情。

## Acceptance Criteria

* [x] 可注入随机值的服务端测试证明爱弥斯 `< 0.35` 拒绝、`>= 0.35` 接受。
* [x] 拒绝时道具数量、用户效果和角色状态均不变化，并播放拒绝剧情。
* [x] 接受时消耗道具、应用爱弥斯专属效果并播放成功剧情。
* [x] 所有叙述节点角色名和角色 ID 均为空，终局用户名占位符可正常替换。
* [x] 只有当前最后一步由带有效果的爱弥斯落子时，棋盘对应交叉点才播放七彩像素光纹。
* [x] 动效不改变棋子样式与棋盘交互，并尊重 `prefers-reduced-motion`。
* [x] 完成一盘有效的爱弥斯对局后清除效果；其他角色的有效对局不误清除。
* [x] 默认剧情种子、后台默认快照、系统设计文档与生成版文档保持同步。
* [x] 相关测试及仓库质量门通过。

## Definition of Done

* 服务端概率、消费、持久化、剧情选择和对局后清理均有回归测试。
* 前端目标选择、效果展示和棋盘触发判定有回归测试。
* 默认快照测试覆盖爱弥斯成功/拒绝节点及空叙述角色区域。
* `docs/system-design.md`、相关分篇和 `docs/system-design.html` 已更新。

## Technical Approach

* 扩展现有彩虹豆豆跳跳糖角色白名单与单脚本双分支协议，不新增数据库模型。
* 在规范化后的 `itemEffects` 中加入爱弥斯布尔状态，并复用有效对局结算清理通道。
* 由房间展示层根据当前可见的最后一步、落子方角色和用户效果计算一次性棋盘特效描述，再向棋盘点位传递稳定的落子键值。
* 使用棋盘 CSS 伪像素光纹实现短时特效，保持 DOM 点击区、棋子和落子合法性逻辑不变。

## Decision (ADR-lite)

**Context**: 彩虹豆豆跳跳糖已经使用同一角色脚本内的成功/拒绝双起点，角色效果也由统一的 `itemEffects` 持久化并在有效对局后清理。

**Decision**: 爱弥斯沿用既有随机与剧情协议，新增独立的效果标志；棋盘动画根据最后一手的实际落子方和该标志按需渲染。

**Consequences**: 不需要新的数据表或游戏规则字段；动画只是表现层效果，但房间玩家数据与棋盘最后一手之间的映射需要测试保护。

## Out of Scope

* 不修改用户给出的成功或拒绝文案。
* 不给彩虹落子模式增加棋力、计分或技能收益。
* 不为其他尚未支持的角色新增糖果剧情。
* 不制作新的爱弥斯立绘或 GIF 资源。
