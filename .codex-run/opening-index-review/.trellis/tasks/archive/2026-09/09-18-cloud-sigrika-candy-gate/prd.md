# 云端测试禁用西格莉卡跳跳糖

## Goal
云端测试期间，阻止彩虹豆豆跳跳糖触发尚未完成的西格莉卡剧情。

## Requirements
- 服务端 NODE_ENV=production 时禁止对西格莉卡使用该道具，本地开发保留剧情测试能力。
- 仓库使用服务端返回的角色限制禁用选择，提供暂不可用提示。
- 直接调用接口同样拒绝，拒绝前不扣道具、不写效果、出战角色或剧情进度。
- 其他角色保持原行为；不删除剧情、后台配置或已有玩家进度。

## Acceptance Criteria
- 生产限制和开发放行均有测试，覆盖库存响应、前端禁用和服务端拦截。
- 更新系统设计和部署说明，生成 HTML，运行项目检查。

## Technical Approach
server/items.js 统一生成 disabledCharacterReasons，同时用于库存投影和使用校验；仓库复用现有 disabled 样式。以现有生产环境标志控制，无新增数据库字段或前端构建开关。

## Out of Scope
实际登录云服务器部署、补完剧情、清理已有剧情状态、改动其他道具或角色。

## Decision
生产默认关闭未完成入口；本地开发继续测试。后续剧情发布时移除这一临时限制。已有剧情恢复和取消效果接口保持可用。
