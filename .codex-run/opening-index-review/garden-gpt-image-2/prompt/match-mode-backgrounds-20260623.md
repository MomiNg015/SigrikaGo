# Match Mode Background Prompts

Shared constraints for all images:

- Use case: stylized-concept
- Asset type: horizontal UI button/card background for match mode tabs and match entry buttons
- Style: Bright School academy UI, light paper texture, classroom stationery, soft anime-game polish, clean readable negative space
- Composition: wide horizontal banner, centered symbolic motif, safe empty area for overlaid DOM text, simple silhouettes, no UI chrome
- Constraints: no readable text, no logos, no watermark, no characters, no complex scene, no dark full-screen terminal panel, keep contrast moderate so white/dark button labels remain legible
- Avoid: photorealism, busy board positions, full illustration scenes, excessive gradients, neon overload, horror/dark mood

Mode motifs:

- Spark battle: magical academy go duel, star torch spark, cyan-gold star points, subtle skill energy, dynamic but not chaotic.
- Standard battle: calm orthodox go, wooden board grid, balanced black/white stones, notebook-paper order, quiet strategic tone.
- Gomoku: five-in-a-row clarity, playful red/coral diagonal winning line, 13x13 board hint, simple school-club competition tone, no capture/territory motifs.

- Standard: warm paper badge background with a clean wooden board grid fragment, balanced black/white stones, ruler and notebook grid accents.
- Gomoku: pale paper badge background with five stones in a gentle diagonal, coral highlight ribbon, small pencil/check mark shapes.
