# 技能释放横幅审查

推荐「漫画必杀技切入 × 学园剪纸」：正常比例全身立绘独立置于横带前景，头发与脚部同时突破上下边框；技能名在右侧稳定可读。当前只审查，未修改游戏代码。

## 现状与判断

当前 SkillBanner.jsx:24 请求 avatar，base-result-skill.css:97 将其限制为 140×116，手机进一步缩为 96×88。横幅采用五色流动渐变、白边、90px 模糊阴影与整体 scaleX 入场。风格更接近通用彩色通知，人物和技能缺少专属表现。

优点：角色、技能两级信息简洁；语音与装扮快照已有接入；pointer-events:none 与减少动态效果已有基础。

检测器对 src/modals/SkillBanner.jsx 返回 []，退出码 0，无误报；不能据此判定关联 CSS 或视觉表现合格。未完成战斗实机观察：本地浏览器停在尺寸守卫，视口设置及重载后仍未解除。已直接查看西格莉卡标准与 Q 版全身资源。

## 优先问题

1. P1 全身构图缺失。当前头像和小图框无法满足上下破框。人物应独立定位，以全身可见高度控制，底带保持窄高。仅切换 variant:full 仍得到 Q 版，正常比例资源已有 resolveHandbookPortrait 路由。保留服装、糖果、自定义资源优先级。
2. P2 背景抢主体。通用流动彩虹弱化角色辨识度。改为纸面、墨线和角色主色，使用斜切端部、局部网点及少量速度线，减少宽模糊阴影。彩虹效果可留给有此身份特征的角色。
3. P2 人物随整块 scaleX 横向变形。拆分底带展开、人物等比滑入、技能名落定三个运动层。保留既有 2000ms 阶段，避免影响棋盘特效与语音衔接。
4. P2 手机文字空间不足。独立保留文字安全区，技能名允许最多两行；不能仅等比缩小桌面，也不能让武器、头发盖住标题。共用 skill-burst 的腐化对局演出须单独核对。

## 推荐构图与节奏

|项目|桌面起始值|手机竖屏起始值|
|---|---|---|
|底带高度|140px|110px|
|完整人物可见高度|320px|230px|
|上方/下方突出|100px / 80px|65px / 55px|
|技能名字号|44–52px|28–32px|

以上为待实机校准的建议值。透明留白、武器横向跨度和服装 scale/translate 必须逐类核对。

0–180ms 底带快速展开；60–260ms 人物保持比例滑入；120–280ms 技能名落定；280–1650ms 稳定阅读；1650–2000ms 收束退场。边缘可有一次短促亮线，不做持续闪光。减少动态效果时静态展示并沿用父级结束生命周期。

层级：外层允许溢出；背景装饰层自行裁切；全身人物层不裁切；文字层拥有安全区。优先 transform/opacity，避免大图持续滤镜、持续漂浮和全屏模糊。
